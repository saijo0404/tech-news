# NVIDIA Announces Financial Results for Third Quarter Fiscal 2027

- **來源**: NVIDIA Newsroom
- **發布日期**: 2026-11-17
- **原文連結**: https://nvidianews.nvidia.com/news/nvidia-announces-financial-results-for-third-quarter-fiscal-2027

## 核心主題
NVIDIA 財報顯示第三季營收達 1158 億美元，同比增長 103%，推出 Vera Rubin NVL72 平台並宣布收購 Hugging Face。

## 關鍵重點
- 第三季營收 1158 億美元，同比增長 103%
- 數據中心營收 1076 億美元，同比增長 110%
- 毛利率 GAAP 74.8%、非 GAAP 74.9%
- 每股盈餘 GAAP $2.70、非 GAAP $2.68
- 推出 Vera Rubin NVL72 平台，最快產品上線
- 宣布將買回授權增加 1500 億美元
- 本季度回購 281 億美元，剩餘授權約 2273 億美元
- 下一季營收預期 1300 億美元
- 推出 NVIDIA Open Agent Safety Platform 與 OpenShell 參考架構
- 宣布收購 Hugging Face 計畫

## 結論
NVIDIA 財報展現強勁增長，數據中心業務持續擴張，生態系擴展加速，並透過收購 Hugging Face 進一步強化 AI 平台能力。
