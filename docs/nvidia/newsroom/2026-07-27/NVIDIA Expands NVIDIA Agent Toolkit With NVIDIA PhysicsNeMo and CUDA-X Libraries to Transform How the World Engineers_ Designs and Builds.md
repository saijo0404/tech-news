# NVIDIA Expands NVIDIA Agent Toolkit With NVIDIA PhysicsNeMo and CUDA-X Libraries to Transform How the World Engineers, Designs and Builds

- **來源**: NVIDIA Newsroom
- **發布日期**: 2026-07-26
- **原文連結**: https://nvidianews.nvidia.com/news/nvidia-expands-nvidia-agent-toolkit-with-nvidia-physicsnemo-and-cuda-x-libraries-to-transform-how-the-world-engineers-designs-and-builds

## 核心主題
NVIDIA 擴充 NVIDIA Agent Toolkit，加入重新架構的 NVIDIA PhysicsNeMo 庫和更新後的 CUDA-X 庫，使開發者能夠建立具備 AI 物理技能、加速求解器和量子化學能力的自主 AI 工程師。

## 關鍵重點
- **AI 物理技能**：NVIDIA PhysicsNeMo 庫幫助 AI 工程師訓練和部署可自訂的 AI 物理模型，用於複雜設計與模擬任務，將模型架構轉化為工程工作流的可呼叫工具。
- **加速求解器**：新推出的 cuISS（CUDA Iterative Sparse Solvers）和 cuDSS（CUDA Direct Sparse Solvers）庫加速大型稀疏線性系統，適用於電子設計自動化（EDA）和科學模擬。
- **量子化學能力**：cuEST（CUDA Electronic Structure Theory）庫將高精度量子化學模擬擴展至設備相關規模，支援密度函數理論（DFT）和後 DFT 方法，使大型基態和激發態模擬在 NVIDIA GPU 上可管理。
- **NVIDIA Nemotron 3 Ultra**：在自主寄存器轉移級別（RTL）編碼中領先，幫助企業建立可自訂的 AI 工程師，支援晶片設計與驗證，可透過本地或現場部署提供更大控制權。
- **業界合作成果**：Cadence、Siemens、Synopsys、Samsung 等企業已使用這些技術實現 10-20 倍的性能提升，開發自主 AI 工程師進行晶片設計、驗證和系統優化。

## 結論
NVIDIA Agent Toolkit 的擴充標誌著工程領域的轉折點，AI 現在可以與物理、模擬和設計工具協同工作，成為晶片和系統設計的新創新引擎，幫助工程師應對日益複雜的設計週期。
