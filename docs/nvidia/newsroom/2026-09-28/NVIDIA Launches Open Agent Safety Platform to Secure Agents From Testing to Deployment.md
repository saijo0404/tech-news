# NVIDIA Launches Open Agent Safety Platform to Secure Agents From Testing to Deployment

- **來源**: NVIDIA Newsroom
- **發布日期**: 2026-09-28
- **原文連結**: https://nvidianews.nvidia.com/news/open-agent-safety-platform

## 核心主題
NVIDIA 推出開放式 AI 安全平台，整合 OpenShell 軟體與 Sentry 參考系統設計，提供從測試到部署的全堆疊治理與控制。

## 關鍵重點
- OpenShell 提供安全運行時邊界，可在 NVIDIA Vera CPU 上追蹤並強制執行 AI 代理行動，支援 Arm 和 Intel 等第三方平台。
- Sentry 作為獨立監控器運行於 BlueField-4 DPU，可在毫秒級別隔離試圖越界的 AI 代理。
- 超過 100 家行業領導企業（包括 Anthropic、Microsoft、Salesforce 等）加入合作，共同提升 AI 安全標準。

## 結論
NVIDIA 透過開放式平台與跨產業合作，建立更安全的 AI 代理生態系統，從測試到部署全程提供治理與控制。
