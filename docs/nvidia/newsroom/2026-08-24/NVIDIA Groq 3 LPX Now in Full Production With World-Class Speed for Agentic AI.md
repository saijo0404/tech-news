# NVIDIA Groq 3 LPX Now in Full Production With World-Class Speed for Agentic AI

- **來源**: NVIDIA Newsroom
- **發布日期**: 2026-08-24
- **原文連結**: https://nvidianews.nvidia.com/news/nvidia-groq-3-lpx-now-in-full-production-with-world-class-speed-for-agentic-ai

## 核心主題
NVIDIA 推出 Groq 3 LPX 互動式 AI 推理加速器，擴展 Vera Rubin 平台，大幅提升 AI 推理速度，由 Nebius 率先採用。

## 關鍵重點
- Groq 3 LPX 在 Artificial Analysis 測試中達到每秒 3,400 個輸出 token 的紀錄，使用 Gemma 4 31B 模型
- 相比最近替代平台快 4 倍，適合需要低延遲的代理 AI 工作負載，大幅縮短程式碼開發時間
- Nebius 是第一個採用此產品的 AI 雲端，將部署於 Nebius Token Factory，讓開發者透過現有 API 即可使用

## 結論
Groq 3 LPX 代表 AI 推理性能的重大突破，將改變 AI 生產方式，提升吞吐量、效率和響應速度，為代理 AI 系統帶來極速處理能力。
