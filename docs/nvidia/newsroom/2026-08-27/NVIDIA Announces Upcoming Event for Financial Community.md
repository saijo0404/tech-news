# NVIDIA Announces Upcoming Event for Financial Community

- 活動時間：2026年9月10日星期四，太平洋時間上午8:50

- 重播期限：直播後90天內可重播

NVIDIA 作為 AI 和加速計算領域的世界領導者，繼續與金融界保持緊密合作，透過專業活動展示其技術實力並深化產業關係。
