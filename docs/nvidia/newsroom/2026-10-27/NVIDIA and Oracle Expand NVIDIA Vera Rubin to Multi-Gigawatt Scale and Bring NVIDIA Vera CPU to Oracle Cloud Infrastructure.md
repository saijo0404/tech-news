# NVIDIA and Oracle Expand NVIDIA Vera Rubin to Multi-Gigawatt Scale and Bring NVIDIA Vera CPU to Oracle Cloud Infrastructure

- **來源**: NVIDIA Newsroom
- **發布日期**: 2026-10-27
- **原文連結**: https://nvidianews.nvidia.com/news/nvidia-and-oracle-expand-nvidia-vera-rubin-to-multi-gigawatt-scale-and-bring-nvidia-vera-cpu-to-oracle-cloud-infrastructure

## 核心主題
NVIDIA 與 Oracle 合作，將 Vera Rubin GPU 和 Vera CPU 擴展至 Oracle Cloud Infrastructure (OCI)，支持多吉瓦級 AI 訓練和推理。

## 關鍵重點
- NVIDIA Vera Rubin NVL72 和 Vera CPU 已在 OCI 上一般可用，客戶可獨立擴展 CPU 和 GPU 資源。
- OCI Superclusters 將擴展至多吉瓦級規模，支持 frontier AI 模型訓練，OpenAI 已在 Abilene 的 OCI Supercluster 上訓練 GPT-6 Astra。
- 計劃推出 HGX Rubin NVL8 系統，提供 x86 架構的靈活性，包含兩顆 64 核心 Intel Xeon 6 CPU、4TB DDR5 記憶體和 6.4 Tbps RDMA 網路。
- NVIDIA Vera CPU 加速 AI Agent 的 CPU 密集型任務（工具調用、代碼執行、資料檢索），減少 GPU 閒置時間。
- Oracle Acceleron 提供硬體隔離，支持運行未信任 AI 生成代碼的工作負載。

## 結論
NVIDIA 和 Oracle 的合作擴展了 AI 基礎設施，使客戶能夠更有效地利用 GPU 進行訓練和推理，同時支持 AI Agent 的 CPU 密集型任務，提升 AI 工廠的生產力、耐用性和可替代性。
