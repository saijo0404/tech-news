# NVIDIA Expands Vera CPU Platform to Accelerate Scientific Discovery

- **來源**: NVIDIA Newsroom
- **發布日期**: 2026-11-16
- **原文連結**: https://nvidianews.nvidia.com/news/nvidia-expands-vera-cpu-platform-to-accelerate-scientific-discovery

## 核心主題
NVIDIA 推出 Vera CPU 平台，結合自訂 CPU 核心與 InfiniBand 網路，為氣候模擬等科學計算帶來更高效能與能效。

## 關鍵重點
- Vera CPU 平台提供比 x86 CPU 高 1.9 倍效能、2.4 倍每瓦特效能
- 德國氣候計算中心 DKRZ 已選定 Vera CPU 用於其 HLRE-5 超級電腦
- 提供 NVIDIA HPC SDK 26.11 及新一代 Fortran 編譯器支援

## 結論
Vera CPU 平台預計於 2027 年初由 Dell、HPE、Lenovo 和 Supermicro 推出，將重塑科學計算領域。
