# NVIDIA Launches OpenShell Reference Architecture for Safe AI Agents

- **來源**: NVIDIA Newsroom
- **發布日期**: 2026-10-21
- **原文連結**: https://nvidianews.nvidia.com/news/openshell-reference-architecture

## 核心主題
NVIDIA 推出 OpenShell 參考架構，整合 Vera Rubin、Vera CPU 與 BlueField-4 DPU，打造企業級安全 AI 代理基礎設施，實現 AI 能力與安全並行發展。

## 關鍵重點
- **硬體整合**: 結合 NVIDIA Vera Rubin（模型推理）、Vera CPU（代理執行）與 BlueField-4 DPU（安全監控），提供完整的安全代理運算架構。
- **安全機制**: 透過 NVIDIA Sentry 軟體框架實現「in-silicon」即時監控與政策強制，若代理越界會在毫秒內隔離並停止。
- **生態合作**: 與 Anthropic、AWS、Microsoft、ServiceNow 等百餘家企業合作，支援 Linux、Windows 及 Kubernetes 等多種企業作業系統。

## 結論
OpenShell 參考架構為企業部署數以億計的 AI 代理提供安全邊界，讓 AI 能在明確限制內自由運作，同時確保可觀察、可監控與可強制管制的企業級安全標準。
