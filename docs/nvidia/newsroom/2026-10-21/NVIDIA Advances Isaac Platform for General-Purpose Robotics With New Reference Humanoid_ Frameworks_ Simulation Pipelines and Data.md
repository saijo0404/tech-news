# NVIDIA Advances Isaac Platform for General-Purpose Robotics With New Reference Humanoid, Frameworks, Simulation Pipelines and Data

- **來源**: NVIDIA Newsroom
- **發布日期**: 2026-10-21
- **原文連結**: https://nvidianews.nvidia.com/news/nvidia-advances-isaac-platform-for-general-purpose-robotics-with-new-reference-humanoid-frameworks-simulation-pipelines-and-data

## 核心主題
NVIDIA 大幅擴展 Isaac 開發平台，推出全新人形機器人參考平台、數據集與運行時框架，加速通用機器人的開發與部署。

## 關鍵重點
- **Agile ONE SN 人形機器人平台**：由 Agile Robots 推出，基於 NVIDIA Isaac GR00T 與 Jetson Thor，具備 31 自由度、雙手觸覺感測與完整安全整合，預計 2027 年初上市。
- **NVIDIA Isaac Lab 3.0 與 Isaac OS**：提供從桌面到數據中心的開源機器人學習框架，支援多 GPU 工作流與 Newton/NVIDIA PhysX 物理引擎。
- **SimReady 中央圖書館與 Human 1M 數據集**：提供超過 2,000 個模擬準備好的機器人資產與豐富的人類活動數據集，可於 Hugging Face 獲取。
- **歐洲機器人生態系合作**：ABB、KUKA、Sereact、Humanoid 等歐洲機器人領導者正整合 NVIDIA 開放平台技術，加速自主機器人系統開發。
- **NVIDIA Halos 安全平台**：提供全棧安全解決方案，協助機器人從開發階段安全部署到真實世界。

## 結論
NVIDIA 透過整合硬體、軟體、數據與模擬工具，為開發者提供從數據生成到部署的完整機器人開發路徑，標誌著通用機器人發展進入加速期，物理 AI 即將在各大產業中廣泛應用。
