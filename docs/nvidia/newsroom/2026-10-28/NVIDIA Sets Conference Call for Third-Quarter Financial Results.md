# NVIDIA Sets Conference Call for Third-Quarter Financial Results

- **來源**: NVIDIA Newsroom
- **發布日期**: 2026-10-28
- **原文連結**: https://nvidianews.nvidia.com/news/nvidia-sets-conference-call-for-third-quarter-financial-results-6928873

## 核心主題
NVIDIA 宣布將於2026年11月17日舉行財報電話會議，討論2027財年第三季度的財務表現。

## 關鍵重點
- 會議時間：2026年11月17日星期二，太平洋時間下午2點（東部時間下午5點）
- 財務評論：CFO Colette Kress 將提供書面評論，並在會議後立即發布
- 參與對象：僅限財務分析師和機構投資者提問
- 直播方式：在 investor.nvidia.com 上進行，可重播至下一季財報會議

## 結論
NVIDIA 將透過電話會議和書面評論向投資者展示其第三季度的財務表現，強調其在AI和加速計算領域的領導地位。
