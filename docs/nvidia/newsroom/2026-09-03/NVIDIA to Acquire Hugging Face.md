# NVIDIA to Acquire Hugging Face

- **來源**: NVIDIA Blog
- **發布日期**: 2026-09-03
- **原文連結**: https://blogs.nvidia.com/blog/nvidia-to-acquire-hugging-face/

## 核心主題
NVIDIA 宣布以 129.3 億美元收購 Hugging Face，承諾保持其開源平台的獨立性與開放性，共同擴展 AI 生態系統。

## 關鍵重點
- 收購金額為 12,930,300,000 美元，旨在擴展 Hugging Face 平台規模與基礎設施
- Hugging Face 將保持開源平台性質，開發者可選擇自己想要的模型、框架、雲端服務和計算平台
- NVIDIA 是 Hugging Face 最大的開源模型貢獻者，已發布超過 500 個模型和 250 個開源數據集
- 收購不會強制要求使用 NVIDIA 硬體，支持多雲端和多加速器開發部署
- 承諾繼續支持開源和開權重模型，確保 AI 生態系統的開放性

## 結論
這次收購將使 AI 更開放、更強大、更易於全球各地的人們和機構使用，同時保留 Hugging Face 作為開源模型開發者社區的基礎地位。
