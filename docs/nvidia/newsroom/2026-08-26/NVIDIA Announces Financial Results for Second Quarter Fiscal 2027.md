# NVIDIA Announces Financial Results for Second Quarter Fiscal 2027

- **來源**: NVIDIA Newsroom
- **發布日期**: 2026-08-26
- **原文連結**: https://nvidianews.nvidia.com/news/nvidia-announces-financial-results-for-second-quarter-fiscal-2027

## 核心主題
NVIDIA 第二季財報顯示強勁成長，營收激增106%，並推出 Vera Rubin 平台等新產品。

## 關鍵重點
- **財務表現**：第二季營收962億美元，同比激增106%，季季成長18%；毛利率75%，淨利597億美元，每股盈餘GAAP$2.46、非GAAP$2.22
- **產品生態**：Vera Rubin平台全面量產（客戶包括Google、Microsoft、Azure等），推出NVIDIA Vera首支AI專用CPU，Groq 3 LPX推理加速器全量產
- **股東回報**：回購約260億美元，剩餘回購授權990億美元，下季營收展望1080億美元
- **戰略合作**：與SpaceXAI合作部署Vera CPU，與SK hynix合作開發新一代記憶體，成立Open Secure AI聯盟推動AI安全

## 結論
NVIDIA 繼續鞏固其AI與加速計算全球領導者地位，展現強勁財務表現與產品創新能力，同時積極擴展生態合作夥伴。
