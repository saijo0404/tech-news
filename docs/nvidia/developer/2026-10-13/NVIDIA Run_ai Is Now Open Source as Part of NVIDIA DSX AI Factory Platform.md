# NVIDIA Run:ai Is Now Open Source as Part of NVIDIA DSX AI Factory Platform

- **來源**: NVIDIA Developer Blog
- **發布日期**: 2026-10-13
- **原文連結**: https://developer.nvidia.com/blog/nvidia-runai-is-now-open-source-as-part-of-nvidia-dsx-ai-factory-platform/

## 核心主題
NVIDIA 將 Run:ai 平台開放源碼化，作為 NVIDIA DSX AI Factory Platform 的一部分，提供 AI 工作負載與 GPU 排程基礎設施，讓生態系夥伴能更快將創新帶入市場。

## 關鍵重點
- **四個模組化組件**：包含 KAI Scheduler（GPU 感知的 Kubernetes 排程）、GPU Fractioning Operator（CUDA 原生 GPU 共享）、KAI Resource Management（組織層級資源管理）、Workload Map（工作負載管理合約）
- **八家合作夥伴整合**：Crusoe、Mirantis、Nebius 等夥伴正在整合此平台，提供完整解決方案
- **Model Streamer 技術**：快速模型載入技術，整合於 vLLM、SGLang 及 ModelExpress，比預設載入器快 3-6 倍（穩定 80 Gbps）
- **Grove 工具**：提供單一 API 編排多組件工作負載，支援 Kubernetes 自動擴展與分佈式排程

## 結論
NVIDIA 開放 Run:ai 源碼後，生態系夥伴能更靈活地採用完整平台或獨立組件，大幅提升 GPU 利用率與工作負載吞吐量，加速 AI 工廠解決方案上線速度。
