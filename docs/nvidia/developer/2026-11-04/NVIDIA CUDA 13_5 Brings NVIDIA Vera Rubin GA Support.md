# NVIDIA CUDA 13.5 Brings NVIDIA Vera Rubin GA Support

- **來源**: NVIDIA Developer Blog
- **發布日期**: 2026-11-04
- **原文連結**: https://developer.nvidia.com/blog/nvidia-cuda-13-5-brings-nvidia-vera-rubin-ga-support/

## 核心主題
NVIDIA CUDA 13.5 正式支援 Vera Rubin GPU 架構，並帶來多项性能與功能改進，包括 Windows on Arm 擴展、MPS v3 功能增強及核心數學庫性能大幅提升。

## 關鍵重點
- **Vera Rubin GA 支援**：CUDA 13.5 正式支援 NVIDIA Vera Rubin GPU 架構，企業生產環境已準備就緒。
- **Windows on Arm 擴展**：新增支援 NVIDIA DGX Station for Windows。
- **核心數學庫改進**：cuBLAS 在 Vera Rubin GPU 上 GEMM 性能提升，cuSPARSE 性能提升 1.65-2.27 倍，nvJPEG 混合解碼吞吐量提升 10-600%。
- **MPS v3 功能**：加權時間切片、SM partition 負載平衡、cgroup 基礎路由等增強功能。
- **CUDA Python 1.2**：新增 `copy_batch()` 批次記憶體複製、程式化依賴啟動 (PDL) 及更靈活的 CUDA Graph 更新。
- **開發者工具升級**：NVIDIA Nsight Perf SDK for AI、CUDA-GDB、Compute Sanitizer 等工具功能增強。

## 結論
CUDA 13.5 是重要的更新，為企業生產環境帶來 Vera Rubin GPU 支援及多项性能改進，同時強化了開發者工具鏈與平台兼容性。
