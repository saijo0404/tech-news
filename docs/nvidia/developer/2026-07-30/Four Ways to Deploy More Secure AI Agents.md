# Four Ways to Deploy More Secure AI Agents

- **來源**: NVIDIA Technical Blog
- **發布日期**: 2026-07-30
- **原文連結**: https://developer.nvidia.com/blog/four-ways-to-deploy-more-secure-ai-agents/

## 核心主題
NVIDIA AI Red Team 識別出企業級 AI 代理常見的漏洞模式，並提出四項關鍵安全控制措施來降低部署風險。

## 關鍵重點
- **實施代理存取控制**：限制每個代理僅對明確授權的用戶開放，遵循最小權限原則，避免任何內部授權用戶都能存取代理。
- **限制程式碼執行**：避免使用命令列工具，若必須使用則應在沙盒環境（如 Docker 或 NVIDIA OpenShell）中運行，並使用嚴格的最小權限允許列表。
- **預設拒絕網路外洩**：採用預設拒絕的網路外洩政策，僅允許任務所需的最小端點，且這些限制必須在代理無法觸及的環境層面強制執行。
- **將秘密保持在代理範圍之外**：永不將持久化秘密暴露給代理，應使用專門的秘密管理器，僅在需要時按需檢取，並使用短期、範圍受限的令牌。

## 結論
基於控制平面的防禦措施（如系統提示和 LLM-as-a-judge 模式）無法可靠地抵禦攻擊者。必須採用確定性的架構控制，包括存取控制、沙盒化執行環境、預設拒絕的網路外洩控制，以及將秘密保持在代理範圍之外。完全自主的企業級 AI 系統本質上存在風險，需要謹慎的安全措施。
