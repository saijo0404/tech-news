# What's New for Game Developers: AI Animation and RTX Tools

- **來源**: NVIDIA Technical Blog
- **發布日期**: 2026-11-24
- **原文連結**: https://developer.nvidia.com/blog/whats-new-for-game-developers-ai-animation-and-rtx-tools/

## 核心主題
這篇文章介紹了 NVIDIA 為遊戲開發者推出的 AI 動畫和 RTX 工具更新，涵蓋 War Thunder 整合 DLSS 5、Unreal Engine 5.9 整合 Kimodo 動畫生成模型等最新進展。

## 關鍵重點
- **War Thunder 整合 DLSS 5**：Gaijin Entertainment 將 NVIDIA DLSS 5 與 3D-Guided Neural Rendering 整合到 Dagor Engine，優化色彩管理流程，提升光影細節與真實感。
- **NVIDIA Kimodo 動畫生成**：成為第一個整合到 Unreal Engine 5.9 預覽版的 AI 動作生成模型，允許動畫師透過文字提示、曲線路徑和目標姿勢生成角色動作。
- **NVIDIA In-Game Inferencing SDK 1.8**：新增 RTX Spark 平台支援、更新 llama.cpp 和 whisper.cpp 後端，支援 Parakeet 自動語音識別模型及 Vulkan 優先 API 整合。
- **RTX Dynamic Illumination 3.2 與 RTX Path Tracing 1.9**：引入分層低不相容採樣、ReSTIR DI 空間重採樣、SHaRC 光度緩存等功能，並支援 RTX Spark。
- **NVIDIA Real-Time BVH Viewer 1.0**：提供即時光線追蹤加速結構檢視工具，支援 D3D12 和 Vulkan，可檢視 TLAS/BLAS 內容並進行效能分析。
- **Nsight 開發工具更新**：NVIDIA Nsight Graphics 2026.4 和 Nsight Systems 2026.6 新增 DLSS-FG 支援與代理式 AI 工具，協助分析 DLSS 幀生成工作負載。

## 結論
本月 NVIDIA 遊戲開發更新協助團隊將新圖形、動畫和本地 AI 功能整合到引擎中，同時平衡圖像品質、性能和創意意圖。開發者應參考完整開發者課程、Unreal Engine 5.9 發布說明及 Nsight 工具下載資源，以充分利用這些新技術。
