# Expanding AI Storage Access with NVIDIA cuObject and the NVIDIA SCADA Server SDK

- **來源**: NVIDIA Technical Blog
- **發布日期**: 2026-09-30
- **原文連結**: https://developer.nvidia.com/blog/expanding-ai-storage-access-with-nvidia-cuobject-and-the-nvidia-scada-server-sdk/

## 核心主題
NVIDIA 推出了 cuObject 客戶端和伺服器庫，並擴展了 xio-sig 組織，同時推出了 SCADA Server SDK，以加速 AI 工作負載的儲存存取。

## 關鍵重點
- cuObject 客戶端和伺服器庫已一般化可用，提供標準化 API 和 RDMA 線程協議，加速物件儲存存取，無需透過伺服器 CPU 傳輸資料。
- xio-sig 組織擴展以包含 cuObject，Google Cloud 正在評估參與，Microsoft 計劃加入，以改善儲存 I/O 互操作性。
- SCADA Server SDK 使儲存供應商能夠建立響應 GPU 發起請求的伺服器，IBM Storage 已展示整合 SCADA 與 IBM Storage Scale 的原型。

## 結論
透過 xio-sig 擴展和 SCADA Server SDK，AI 開發者、儲存供應商和雲端服務可透過共享 API 和協議，建立更多加速儲存解決方案，並透過 NVIDIA Storage-Next 倡議推動開放產業標準。
