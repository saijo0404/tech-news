# NVIDIA Ising Enables Fully Automated Quantum Computer Calibration with Enhanced In-Context Learning

- **來源**: NVIDIA Technical Blog
- **發布日期**: 2026-07-27
- **原文連結**: https://developer.nvidia.com/blog/nvidia-ising-enables-fully-automated-quantum-computer-calibration-with-enhanced-in-context-learning/

## 核心主題
NVIDIA 推出 Ising Calibration 1.5 模型，一個 31B 參數的視覺語言模型，用於自動診斷和調校量子處理器，支援零樣本學習和情境學習。

## 關鍵重點
- Ising Calibration 1.5 是 31B 參數的視覺語言模型，可診斷和調校量子處理器，支援多種量子比特類型（超導量子比特、量子點、離子、中性原子等）
- 支援 NVFP4 量化版本，可在單一 GPU 或 NVIDIA DGX Spark 上部署，模型大小比 BF16 精度下減少 11.4%
- 在 QCalEval  benchmarks 上表現優異，零樣本推理比次佳開源模型平均提升 10%，情境學習比前代模型提升 86.68%
- 模型完全開源，提供權重、數據、基準測試和部署藍圖，採用 OpenMDW 許可證，可自由修改和部署

## 結論
此模型為量子計算校準帶來重大突破，使自動化校準工作流程更簡單、成本更低，並提供完整的開源資源供研究者使用。
