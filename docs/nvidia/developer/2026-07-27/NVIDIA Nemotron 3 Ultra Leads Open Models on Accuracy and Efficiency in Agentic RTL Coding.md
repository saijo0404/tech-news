# NVIDIA Nemotron 3 Ultra Leads Open Models on Accuracy and Efficiency in Agentic RTL Coding

- **來源**: NVIDIA Technical Blog
- **發布日期**: 2026-07-26
- **原文連結**: https://developer.nvidia.com/blog/nvidia-nemotron-3-ultra-leads-open-models-on-accuracy-and-efficiency-in-agentic-rtl-coding/

## 核心主題
NVIDIA Nemotron 3 Ultra 結合 ACE-RTL 代理，在 RTL 編碼任務中展現卓越準確性與效率，為開源模型在硬體設計領域帶來新標準。

## 關鍵重點
- ACE-RTL 代理與 Nemotron 3 Ultra 在綜合 Verilog 設計問題（CVDP） benchmarks 上，平均通過率達 97.1%，超越 GLM 5.2（92.1%）與 Kimi K2.6（95.2%）。
- Nemotron 3 Ultra 每輪迭代僅使用 6,629 個 token，比 GLM 5.2 少 28%、比 Kimi K2.6 少 71%，實現更高準確性與更低成本的平衡。
- 該模型採用混合 Mamba-Attention 架構與 RTL 專用的合成數據訓練，支援 1M token 長上下文，可與 Cadence、Siemens、Synopsys 等主流 EDA 工具整合。

## 結論
Nemotron 3 Ultra 透過其高效的長上下文推理能力與 RTL 專精訓練，成為開源模型在 RTL 開發與驗證領域的實用基礎，能顯著提升工程師的硬體設計效率。
