# How NVIDIA DSX MaxLPS Maximizes AI Factory Throughput and Efficiency

- **來源**: NVIDIA Technical Blog
- **發布日期**: 2026-09-27
- **原文連結**: https://developer.nvidia.com/blog/how-nvidia-dsx-maxlps-maximizes-ai-factory-throughput-and-efficiency/

## 核心主題
NVIDIA DSX MaxLPS 透過政策規範的動態電力分配，在相同電力預算下實現 GPU 數量增加 40%，並將總吞吐量提升 49.2%。

## 關鍵重點
- 在相同 264.4 kW 電力預算下，從 140 GPU 增加到 192 GPU，總吞吐量提升 49.2%
- 每瓦特吞吐量從 4.10 提升至 6.12 tokens/s/W，顯示電力效率顯著改善
- P99 首 token 延遲增加 17%，顯示需評估尾延遲以確保服務品質

## 結論
DSX MaxLPS 提供可驗證的五階段驗證流程，讓營運商能在符合電力限制的前提下，將工作負載變異轉化為可管理的容量。
