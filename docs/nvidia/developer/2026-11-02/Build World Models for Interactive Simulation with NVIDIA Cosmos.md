# Build World Models for Interactive Simulation with NVIDIA Cosmos

- **來源**: NVIDIA Technical Blog
- **發布日期**: 2026-11-02
- **原文連結**: https://developer.nvidia.com/blog/build-world-models-for-interactive-simulation-with-nvidia-cosmos/

## 核心主題
NVIDIA Cosmos 提供世界基礎模型和開發工具，用於物理 AI，解決感測器適配和可靠部署挑戰。

## 關鍵重點
- **Cosmos Framework**：提供模塊化、開源工具，支援訓練、強化學習、優化和推理，涵蓋 Cosmos 3、NVIDIA Alpamayo、GR00T、Qwen 和 pi0.5 等多個模型。
- **Cosmos 3 Nano 模擬配方**：可生成同步的相機視頻和 LiDAR 觀察數據，適用於自主車輛、機器人與手術場景，支援 PyTorch 和 vLLM-Omni。
- **Cosmos NIM 微服務**：提供 GPU 加速推理，透過量化、推測解碼和 KV 緩存感知路由，在 H200 GPU 上實現約 2-3 倍速度提升。

## 結論
NVIDIA Cosmos 為開發者提供完整的物理 AI 開發平台，包含世界模型訓練、模擬和部署工具，可加速從研究到生產的完整開發週期。
