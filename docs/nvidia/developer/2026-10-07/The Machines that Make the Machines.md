# The Machines that Make the Machines

- **來源**: NVIDIA Developer Blog
- **發布日期**: 2026-10-07
- **原文連結**: https://developer.nvidia.com/blog/the-machines-that-make-the-machines/

## 核心主題
NVIDIA 機器人團隊成功開發自動化系統，解決 GB300 測試托盤組裝中的關鍵挑戰，驗證了姿態估計與模組化方法在實世界操作中的有效性。

## 關鍵重點
- **機器人組裝突破**：NVIDIA Seattle Robotics Lab 與 Isaac 團隊開發機器人系統，成功組裝 GB300 測試托盤，解決母排組裝與多連接器插入任務
- **技術路線調整**：從傳統方法到學習方法，最終採用 DOPER 框架（姿態估計）與 SPARR 方法（模擬 RL + 真實世界微調），達成 90-95% 成功率
- **關鍵挑戰解決**：透過 3D 列印多功能夾爪減少觸覺感測器依賴，使用 sim-to-real 強化學習 + SPARR 方法進行真實世界政策訓練
- **實驗室到工廠挑戰**：需處理環境差異、產品設計變更，成功需 99.5% 成功率（598 次試驗零失敗），模擬複雜組件仍是挑戰
- **部署策略**：參考自動駕駛產業，初期人類監督逐步提升自主性，系統應具備強但不完美的表現並持續改進
- **通用化與適應性**：長期路徑為基於大規模數據的基礎模型（VLA、WAM 等），透過數據飛輪、世界模型與代理驅動機器人持續改進
- **工具與資源**：提供白色文件、DOPER 與 TALOS 工具，鼓勵加入 NVIDIA 機器人研究，提供免費基礎課程與資源

## 結論
NVIDIA 機器人自動化研究驗證了姿態估計、機械設計減少不確定性、全堆疊方法的重要性。未來路徑將聚焦於數據飛輪、世界模型與代理驅動機器人，透過持續收集部署數據反饋來提升系統能力。
