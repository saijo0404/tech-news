# NVIDIA and Microsoft Expand Accelerated Computing From Azure to Windows PCs

- **來源**: NVIDIA Blog
- **發布日期**: 2026-11-19
- **原文連結**: https://blogs.nvidia.com/blog/microsoft-ignite-accelerated-computing-azure-windows-pcs/

## 核心主題
NVIDIA 與 Microsoft 在 Microsoft Ignite 上擴展全棧合作，將加速計算從 Azure 雲端擴展至 Windows PC 端，涵蓋從基礎設施到邊緣運算的全方位解決方案。

## 關鍵重點
- **Azure 雲端升級**: 推出搭載 NVIDIA Vera Rubin NVL72 系統的 Azure 虛擬機器，支援大規模模型訓練與推理，並擴展 confidential computing 至裸金屬基礎設施。
- **企業模型自訂**: 透過 Microsoft Foundry 擴展 Nemotron 3.5 系列開源模型，企業可自訂模型權重並部署至雲端或本地環境，EY 案例顯示準確性提升 55%。
- **邊緣運算擴展**: 支援 NVIDIA RTX PRO 6000 Blackwell GPU、Jetson Thor/Orin 邊緣平台，並推出 Windows PC 本地 LLM 體驗與 Cloud PCs 的 Direct Stream 能力。
- **科學 AI 整合**: NVIDIA BioNemo 與 ALCHEMI 工具包擴展至 Microsoft Discovery，支援生命科學、藥物發現等研究應用。
- **Microsoft 內部優化**: Microsoft AI 採用 NVIDIA Dynamo 推理軟體與 RTX PRO 6000 Blackwell GPU 加速 Bing 搜尋模型。

## 結論
NVIDIA 與 Microsoft 的合作標誌著 AI 加速計算從雲端向邊緣設備的全面擴展，為企業提供從雲端訓練到本地部署的完整解決方案，同時透過 confidential computing 與 MaxLPS 技術強化安全性與能效。
