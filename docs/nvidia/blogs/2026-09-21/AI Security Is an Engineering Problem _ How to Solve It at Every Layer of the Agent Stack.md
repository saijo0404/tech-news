# AI Security Is an Engineering Problem — How to Solve It at Every Layer of the Agent Stack

- **來源**: NVIDIA Blog
- **發布日期**: 2026-09-21
- **原文連結**: https://blogs.nvidia.com/blog/ai-security-agent-stack/

## 核心主題
AI 安全是一個工程問題，需要透過全層次的代理堆疊控制、可執行的邊界和持續測試來解決。

## 關鍵重點
- AI 安全需要定義的安全需求、可執行的控制、指定負責人以及保護措施有效的證據
- 安全依賴於完整的代理堆疊，包括模型、集成的上下文和運行環境，每層都需要安全控制
- 需要將安全整合到代理的運作方式中，建立獨立於代理推理的安全邊界
- 工程團隊需要安全證據，包括測試和持續監控，以驗證控制措施的有效性
- 防禦者需要適當的工具來在正確的時間進行調查，開放和封閉模型各有其用途
- 透過開放工作分享證據，將優勢轉向防禦者，促進安全社區的知識共享

## 結論
AI 安全需要可執行的邊界、負責任的負責人以及保護措施有效的證據，開放研究和共享工具幫助更多防禦者達到這一標準並持續改進。
