# Vera Delivers the Best of Both Worlds: Highest Throughput and Fastest Agents

- **來源**: NVIDIA Blog
- **發布日期**: 2026-11-05
- **原文連結**: https://blogs.nvidia.com/blog/vera-cpu-highest-throughput-fastest-agents/

## 核心主題
NVIDIA Vera CPU 在 AI 代理（agents）執行速度和每瓦特效能上同時達到業界領先，為 AI 基礎設施提供單一解決方案。

## 關鍵重點
- 在 100 兆瓦數據中心測試中，單一 Vera CPU 表現優於最快和最節能的 x86 CPU
- 相比最快 x86 CPU，Vera 每瓦特可支援 1.6 倍更多代理
- 相比最節能 x86 CPU，Vera 代理速度快 2 倍且能效領先
- 多家合作夥伴（Perplexity、DeepInfra、ClickHouse、DuckLabs、Daytona、Modal）已在生產環境驗證其性能

## 結論
NVIDIA Vera CPU 為 AI 基礎設施提供商提供單一解決方案，同時兼具高速度和高能效，無需混合搭配不同 CPU。
