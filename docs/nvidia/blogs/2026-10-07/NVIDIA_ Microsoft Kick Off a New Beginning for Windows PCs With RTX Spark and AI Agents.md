# NVIDIA, Microsoft Kick Off a New Beginning for Windows PCs With RTX Spark and AI Agents

- **來源**: NVIDIA Blog
- **發布日期**: 2026-10-07
- **原文連結**: https://blogs.nvidia.com/blog/local-ai-rtx-spark-microsoft-windows-event/

## 核心主題
NVIDIA 與 Microsoft 合作推出 RTX Spark 硬體和 AI Agent 解決方案，將 AI 能力帶入 Windows PC 生態系統。

## 關鍵重點
- Microsoft Execution Containers (MXC) 推出，讓 AI Agent 能在 Windows 上安全運行
- RTX Spark 筆記型電腦和桌上型電腦推出，提供強大的本地 AI 運算能力
- NVIDIA DGX Station for Windows 推出，讓企業可以在 Windows 上運行大型 AI 模型

## 結論
NVIDIA 和 Microsoft 的合作將改變 Windows PC 的未來，讓 AI Agent 成為個人助理，並解決企業開發者需要維護雙重環境的問題。
