# NVIDIA Advances Agentic Security for Media, From European Public Service Broadcasting to Global Content Production

- **來源**: NVIDIA Blog
- **發布日期**: 2026-10-19
- **原文連結**: https://blogs.nvidia.com/blog/media-agentic-security-european-public-service-broadcasting-global-content-production/

## 核心主題
歐洲廣播聯盟（EBU）與 NVIDIA 合作擴展主權 AI 標準，同時 Adobe Frame.io 利用 NVIDIA GPU 加速視頻搜索能力，協助德國電視和電影製作商更高效地管理海量內容。

## 關鍵重點
- **主權雲與開源模型**：EBU 與 NVIDIA 擴展主權標準，引入 Microsoft Azure Local、Nebius 歐洲基礎設施平台及 NVIDIA Nemotron 開源模型，確保歐洲廣播機構在保護數據主權的同時進行 AI 創新。
- **Adobe Frame.io 加速視頻搜索**：利用 NVIDIA NVDEC、TensorRT 和 CUDA 平台，實現約 5 倍更快的嵌入生成、4 倍更高的吞吐量及 5 倍更低的延遲，幫助 UFA 等製作商快速定位特定場景。
- **智能內容管理**：Frame.io 的語義搜索功能可根據概念、動作或場景搜索視頻內容，並結合筆記、字幕和審核狀態進行混合搜索，使編輯能更快找到所需片段。
- **全球合作生態**：此次合作涵蓋 Adobe Substance 3D、Firefly Foundry 及 3D 數字孿生工作流，構建完整的媒體娛樂 AI 解決方案生態。

## 結論
NVIDIA 通過擴展 EBU 主權標準和加速 Adobe Frame.io 視頻搜索，為歐洲公共服務媒體提供了兼具數據安全與創新能力的解決方案，同時幫助全球內容製作商大幅提升工作效率。
