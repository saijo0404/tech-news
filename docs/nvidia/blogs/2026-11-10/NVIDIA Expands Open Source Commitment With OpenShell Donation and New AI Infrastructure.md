# NVIDIA Expands Open Source Commitment With OpenShell Donation and New AI Infrastructure

- **來源**: NVIDIA Blog
- **發布日期**: 2026-11-10
- **原文連結**: https://blogs.nvidia.com/blog/open-source-openshell-infrastructure/

## 核心主題
NVIDIA 在 KubeCon 上深化對開源軟體的承諾，透過捐贈 OpenShell 和貢獻新的 AI 基礎設施工具，強化 Kubernetes 作為 AI 工作載體基礎的地位。

## 關鍵重點
- **OpenShell 捐贈 CNCF**：NVIDIA 將 OpenShell（自主代理安全運行時）捐贈給 Cloud Native Computing Foundation，作為 CNCF Sandbox 專案，讓開發者能共同建構和改進 AI 代理的安全基礎設施。
- **貢獻 Agent Substrate 框架**：NVIDIA 貢獻了 Google 主導的 Agent Substrate 框架，支援在 Kubernetes 上以大規模運行長期代理工作負載，並與 NVIDIA Dynamo 和 KAI Scheduler 整合。
- **推出新的 DSX AI Factory Platform 工具**：包括 NVIDIA Kubernetes Engine (NVKE)、NVIDIA Kubernetes Recipes (NVKR) 和 NVIDIA Snapshot，這些工具幫助團隊在 Kubernetes 上部署、管理和擴展 GPU 基礎設施。

## 結論
這些進展標誌著使 Kubernetes 成為大規模 AI 工作負載領先基礎的一步，賦能開發者為未來構建更安全、更高效的 AI 基礎設施。
