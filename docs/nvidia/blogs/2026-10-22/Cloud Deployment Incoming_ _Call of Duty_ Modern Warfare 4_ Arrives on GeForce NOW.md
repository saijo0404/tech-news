# Cloud Deployment Incoming: 'Call of Duty: Modern Warfare 4' Arrives on GeForce NOW

- **來源**: NVIDIA Blog
- **發布日期**: 2026-10-22
- **原文連結**: https://blogs.nvidia.com/blog/geforce-now-thursday-call-of-duty-modern-warfare-4/

## 核心主題
這篇文章介紹了六款遊戲加入 GeForce NOW 雲端遊戲服務，重點是《現代戰爭4》上線，並帶來新的遊戲體驗和支付方式。

## 關鍵重點
- 《Call of Duty: Modern Warfare 4》於今日上線 GeForce NOW，帶來全新劇情、多人遊戲和 DMZ 模式，Ultimate 會員可體驗光線追蹤功能。
- 現有 Fire TV Stick 用戶可透過 Amazon 直接購買 GeForce NOW 會員，使遊戲體驗更便捷。
- 六款遊戲加入 GeForce NOW 服務庫，包括《FINAL FANTASY RESONANCE》和《The Elder Scrolls Online》的新賽季內容。

## 結論
GeForce NOW 繼續擴展其遊戲庫，並透過創新支付方式提升雲端遊戲體驗。
