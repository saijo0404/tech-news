# NVIDIA Cosmos Opens New Tools to Train, Evaluate and Deploy World Models

- **來源**: NVIDIA Blog
- **發布日期**: 2026-10-21
- **原文連結**: https://blogs.nvidia.com/blog/cosmos-open-train-evaluate-deploy-world-models/

## 核心主題
NVIDIA 擴展 Cosmos 平台，提供新工具、模擬檢查點與 Cosmos Data Factory 藍圖，幫助開發者快速構建世界模型，加速物理 AI 系統的開發。

## 關鍵重點
- **Cosmos Data Factory 藍圖**：提供五種雲端原生藍圖（自主駕駛數據集生成、圖像屬性增強、事件視頻生成、缺陷圖像生成、視頻數據增強），可通過 GitHub、Microsoft Azure、Nebius 和 CoreWeave 使用。
- **模型訓練與優化**：擴展 Cosmos Framework 訓練、優化和部署工具，支持 GR00T、Alpamayo、QWEN 等開源模型的微調和強化學習，並可通過分餓和量化進行優化。
- **模擬測試加速**：推出 Cosmos 3 Nano 模型變體，支持在可重複、難以捕捉的多視角多傳感器場景中測試自主策略，並提供次秒級別警報。
- **實際應用案例**：Porsche 使用 Cosmos Data Factory 減少 90% 的實體測試駕駛，ANYbotics 生成 1,500 個合成視頻片段，ADNOC 使用 Fogsphere 的 MistIQ 平台檢測安全風險。

## 結論
NVIDIA Cosmos 平台通過提供開源模型、數據工具和優化技術，幫助開發者從實驗到部署的整個流程更加高效，加速世界模型的開發與應用。
