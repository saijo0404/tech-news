# NVIDIA Agent Toolkit Expands, Grounding Enterprise Agents in Company Data

- **來源**: NVIDIA Blog
- **發布日期**: 2026-10-21
- **原文連結**: https://blogs.nvidia.com/blog/enterprise-platforms-agent-toolkit/

## 核心主題
NVIDIA 擴展了開源 Agent Toolkit，讓企業能夠利用公司數據開發可信任的代理系統，同時提供安全邊界和控制。

## 關鍵重點
- **NVIDIA Agent Knowledge Foundation**：包含 CUDA-X 庫（cuDF、cuGraph、cuML、cuOpt、cuVS）和新的 Auto-Ontology 庫，將原始公司數據轉換為業務概念
- **開源模型**：NVIDIA Nemotron Retriever 和 Kumo 系列模型（Kumo Tabular、Kumo Relational、Kumo Time Series、Kumo Forecast）幫助代理查找相關公司信息
- **安全邊界**：OpenShell 提供安全運行時，NVIDIA NemoClaw 提供安全代理藍圖，讓企業控制代理的訪問和操作範圍
- **企業採用案例**：Palantir、Databricks、Snowflake、Amazon OpenSearch、SAP、ServiceNow、Zoom 等企業已採用此基礎設施

## 結論
NVIDIA Agent Toolkit 的擴展使企業能夠在不移動數據、重建工作流或改變治理控制的情況下，利用公司數據開發可信任的代理系統，從開發到部署全程保障安全與可追溯性。
