# Google Cloud and NVIDIA Announce General Availability of NVIDIA Vera Rubin Infrastructure

- **來源**: NVIDIA Blog
- **發布日期**: 2026-10-21
- **原文連結**: https://blogs.nvidia.com/blog/google-cloud-vera-rubin-infrastructure/

## 核心主題
Google Cloud 與 NVIDIA 宣布推出基於 Vera Rubin 架構的 A5X 實例，為歐洲創新者提供下一代代理和強化學習基礎設施。

## 關鍵重點
- A5X 實例整合了 NVIDIA Vera Rubin NVL72、ConnectX-9 SuperNICs、Google Cloud Virgo Network 和第四代液冷技術，支援大規模代理推理和強化學習工作負載。
- Ineffable Intelligence（由 AlphaGo 創始人 David Silver 創立）是首批使用 A5X 的客戶，用於開發持續學習的「超級學習者」系統。
- WPP 展示了其創意代理參考架構，使用 NVIDIA Nemotron 模型和 OpenShell，將多步驟創意工作流程（如視頻生成、放大和重新設計）轉換為對話請求。
- Google Cloud 將是首批提供大規模 rack 級別 NVIDIA 保密計算的雲端提供商，支援 A4X Max 實例和 G4 VM。
- Google Cloud 和 NVIDIA 正在探索 NVIDIA DSX MaxLPS 能力，以優化 Vera Rubin 基礎設施的每瓦特性能和數據中心電源預算內的容量。

## 結論
這項合作標誌著 AI 基礎設施的重大進步，為需要大規模、安全且能源效率高的代理和強化學習工作負載的組織提供了新的解決方案。
