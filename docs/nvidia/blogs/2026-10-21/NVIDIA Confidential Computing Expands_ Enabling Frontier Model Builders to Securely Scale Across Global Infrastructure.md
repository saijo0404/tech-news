# NVIDIA Confidential Computing Expands, Enabling Frontier Model Builders to Securely Scale Across Global Infrastructure

- **來源**: NVIDIA Blog
- **發布日期**: 2026-10-21
- **原文連結**: https://blogs.nvidia.com/blog/confidential-computing-model-builders-infrastructure/

## 核心主題
NVIDIA 擴展其保密計算技術，推出 Confidential Bare Metal 新部署選項，讓前沿模型構建者能在第三方基礎設施上安全運行敏感工作負載，同時保留對模型和數據的控制權。

## 關鍵重點
- 提供三種部署選項：Confidential Bare Metal（裸金屬基礎設施）、Confidential Containers（Kubernetes 環境）和 Confidential Virtual Machines（虛擬化環境）
- 支持平台擴展至 NVIDIA Grace Blackwell NVL72、x86 基礎的 NVIDIA HGX Rubin NVL8 和 NVIDIA DGX Rubin NVL8 系統
- 多家企業如 Cohere、Google Cloud 等已宣布整合此技術，提供硬體隔離的計算環境

## 結論
NVIDIA 透過擴展保密計算生態系，幫助模型構建者在全球範圍內安全擴展訓練和推理工作負載，同時保護模型和數據的隱私。
