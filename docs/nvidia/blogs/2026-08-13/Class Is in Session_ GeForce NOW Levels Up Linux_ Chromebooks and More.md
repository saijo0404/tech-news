# Class Is in Session: GeForce NOW Levels Up Linux, Chromebooks and More

- **來源**: NVIDIA Blog
- **發布日期**: 2026-08-13
- **原文連結**: https://blogs.nvidia.com/blog/geforce-now-thursday-linux-native-app/

## 核心主題
GeForce NOW 推出原生 Linux 應用程式並優化雲端遊戲體驗，同時支援 Chromebook 遊戲。

## 關鍵重點
- GeForce NOW 原生 Linux 應用程式正式退出測試階段，支援 Ubuntu 24.04 及更高版本，並推出新的 Flatpack 儲存庫，讓使用者更容易安裝和更新。
- 雲端優化 DLSS Frame Generation，降低延遲，提升 60/120 FPS 下的遊戲流暢度，Performance 會員還享有 CPU 密集型遊戲的更高幀率。
- Chromebook 可透過 GeForce NOW 轉化為高性能遊戲電腦，支援超過 2000 款 PC 遊戲，新用戶可透過 Chromebook Fast Pass 免費獲得一年服務。
- 本周新增九款遊戲加入 GeForce NOW 庫，包括 Car Wash Simulator、Pax Autocratica、Clawed、Hell Let Loose: Vietnam 等。

## 結論
GeForce NOW 透過雲端遊戲技術，讓學生和玩家能隨時隨地從學習轉換到遊戲，提供跨裝置的靈活體驗。
