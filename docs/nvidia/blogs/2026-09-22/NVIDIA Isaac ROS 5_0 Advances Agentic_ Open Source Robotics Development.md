# NVIDIA Isaac ROS 5.0 Advances Agentic, Open Source Robotics Development

- **來源**: NVIDIA Blog
- **發布日期**: 2026-09-22
- **原文連結**: https://blogs.nvidia.com/blog/isaac-ros-5-0-agentic-open-source-robotics/

## 核心主題
NVIDIA Isaac ROS 5.0 將 AI 代理能力引入 ROS 開發生態系，透過 GPU 加速套件與 AI 代理工作流，加速開發者與 AI 代理共同建構機器人應用。

## 關鍵重點
- 引入 AI 代理工作流與 ROS Lyrical 及 Ubuntu 24.04 平台支援，讓開發者能更快建構、自訂與部署機器人應用
- 提供 FoundationStereo 與 FoundationPose 等 AI 代理準備的技能，讓 AI 代理能更輕鬆地理解 Isaac ROS 工具與工作流
- 擴展開放原始碼生態系，整合 AgenticROS、RealSense 相機、Intrinsic Core 等解決方案，並支援從 Jetson Orin Nano 到 Jetson Thor 的可擴展運算平台

## 結論
Isaac ROS 5.0 透過結合開放原始碼生態系、加速運算與新的 AI 代理開發工作流，幫助開發者解決實體 AI 挑戰的兩面：建構更強大的機器人應用，並高效地在物理世界中運行。
