# NVIDIA Harnesses Vera CPU to Speed Up Design of Next-Generation CPUs and GPUs

- **來源**: NVIDIA Blog
- **發布日期**: 2026-07-26
- **原文連結**: https://blogs.nvidia.com/blog/vera-cpu-eda/

## 核心主題
NVIDIA 使用自研 Vera CPU 加速下一代 CPU 和 GPU 的設計流程，早期測試顯示關鍵驗證與模擬工作負載性能提升達 1.5 倍。

## 關鍵重點
- NVIDIA 與 Cadence 和 Synopsys 合作，優化電子設計自動化 (EDA) 應用以配合 Vera CPU 架構
- 早期測試顯示 Cadence Jasper 和 Synopsys VCS 在相同核心數下，性能提升達 1.5 倍
- Vera CPU 結合 88 個自訂 Olympus CPU 核心、LPDDR5X 記憶體子系統和第二代 NVIDIA 可擴展一致性互連
- 部署於 EDA 工作流以加速從 RTL 到矽片的設計流程，縮短驗證時間並提升驗證吞吐量
- 未來將以 Rosa CPU（基於 Rigel 核心）繼續擴展 Vera 的能力，建立矽設計、軟體優化與系統工程之間的持續反饋循環

## 結論
透過將 Vera CPU 應用於自身設計流程，NVIDIA 不僅加速了下一代晶片開發，更建立了從設計到製造的完整優化閉環，為半導體產業帶來新的效率突破。
