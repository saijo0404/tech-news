# Thin, Light and Built for Everything: NVIDIA RTX Spark Windows Laptops Gain New Models, Agent Tools and Games

- **來源**: NVIDIA Blog
- **發布日期**: 2026-10-28
- **原文連結**: https://blogs.nvidia.com/blog/local-ai-rtx-spark-laptops-updates-models-agents-games/

## 核心主題
NVIDIA RTX Spark 筆記型電腦推出全新系列，搭載 Blackwell RTX GPU 與 Grace CPU 超級晶片，為開發者、創作者與遊戲玩家帶來本地 AI 超電腦級性能。

## 關鍵重點
- **硬體規格**：RTX Spark 筆記型搭載 NVIDIA Blackwell RTX GPU 與 Grace CPU 超級晶片，提供高達 128GB 統一記憶體與 1 petaflop FP4 AI 效能，支援 14mm 薄型設計與全日續航。
- **AI 工具更新**：推出 NVIDIA Nemotron 3.5 Transcribe（開放權重語音模型，支援 40 種語言）、LFM3 系列模型、NVIDIA App 資源管理功能（可調整 GPU 資源分配給 foreground app 與 background agents）。
- **遊戲支援**：Phantom Blade Zero 支援光線追蹤與 DLSS 4.5，Minecraft 透過 RTX Remix 1.6 支援 path tracing，Portal 與 Half-Life 2 RTX demo 也加入 RTX Spark 支援。
- **其他 AI 工具**：NVIDIA Nemotron 3.5 Bolt（4GB 即可運行）、Black Forest Labs FLUX 3 Image Klein（8GB VRAM 即可運行）、DGX Spark 64GB 開發平台。

## 結論
RTX Spark 筆記型電腦成功將桌面級 AI 能力整合到輕薄便攜設備中，透過超級晶片架構實現 GPU、CPU 與記憶體統一管理，讓開發者、創作者與遊戲玩家能在本地運行複雜 AI 模型與遊戲，無需依賴雲端服務。
