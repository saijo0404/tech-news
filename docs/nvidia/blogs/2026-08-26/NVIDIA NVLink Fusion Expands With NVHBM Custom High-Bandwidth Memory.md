# NVIDIA NVLink Fusion Expands With NVHBM Custom High-Bandwidth Memory

- **來源**: NVIDIA Blog
- **發布日期**: 2026-08-26
- **原文連結**: https://blogs.nvidia.com/blog/nvlink-fusion-nvhbm-custom-high-bandwidth-memory/

## 核心主題
NVIDIA 擴展 NVLink Fusion 技術，引入 NVHBM 客製化高頻寬記憶體，提升 AI 基礎設施性能與效率。

## 關鍵重點
- 將記憶體控制器整合到 HBM 基片上，相比傳統架構提供 30% 更高的記憶體頻寬和 15% 更低的功耗
- Amazon 的 Annapurna Labs 將是第一個與 NVIDIA 合作開發 NVHBM 技術的夥伴
- NVIDIA 建立標準化的 NVHBM 實現，可由多個記憶體供應商提供，降低工程整合難度

## 結論
這項技術將幫助超大型雲端服務商和 AI 創新者更快地部署客製化 AI 基礎設施，透過整合記憶體控制器與 HBM 基片，實現更高的性能與效率。
