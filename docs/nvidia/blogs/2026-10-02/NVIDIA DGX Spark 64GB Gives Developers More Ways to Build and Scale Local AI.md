# NVIDIA DGX Spark 64GB Gives Developers More Ways to Build and Scale Local AI

- **來源**: NVIDIA Blog
- **發布日期**: 2026-10-02
- **原文連結**: https://blogs.nvidia.com/blog/local-ai-dgx-spark-64gb-sync/

## 核心主題
NVIDIA DGX Spark 64GB 提供新的本地 AI 平台，支援高達 1000 億參數的模型，並透過 NVIDIA Sync Cluster Assistant 實現簡單的集群擴展。

## 關鍵重點
- 64GB 統一記憶體配置由 Acer、ASUS、Dell、Gigabyte、HP 和 MSI 等製造商提供，價格可負擔，包含 GB10 Grace Blackwell 超芯片和完整的 NVIDIA AI 軟體堆疊。
- 支援高達 1000 億參數的模型，兩台 64GB 系統組集群可支援高達 2000 億參數的模型，性能提升 1.7 倍。
- 從上電到運行模型只需數分鐘，支援 NVIDIA Agent Toolkit、CUDA-X AI 庫、Nemotron 開源模型、Ollama、vLLM 和 PyTorch 等。
- NVIDIA Sync Cluster Assistant 可自動配置多節點集群，無需額外設置，兩台設備可透過 QSFP 連接線直接連接。
- NVIDIA Sync Model Launcher 即將推出，可通過點擊幾下按鈕運行本地 AI，並支援 OpenCode 瀏覽器編程。

## 結論
DGX Spark 64GB 為開發者提供了更靈活、更經濟的本地 AI 解決方案，並通過 NVIDIA Sync Cluster Assistant 實現了簡單的集群擴展，使本地 AI 開發更加便捷和高效。
