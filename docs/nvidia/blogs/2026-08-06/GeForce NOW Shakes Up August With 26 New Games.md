# GeForce NOW Shakes Up August With 26 New Games

- **來源**: NVIDIA Blog
- **發布日期**: 2026-08-06
- **原文連結**: https://blogs.nvidia.com/blog/geforce-now-thursday-august-2026-games-list/

## 核心主題
NVIDIA GeForce NOW 在8月新增26款遊戲，並參加QuakeCon遊戲展，展示雲端遊戲最新體驗。

## 關鍵重點
- **新增8款遊戲**：包括World of Warships: Legends（海戰策略）、Beacon Pines、Sovereign Tower等，玩家可立即體驗。
- **QuakeCon現場體驗**：NVIDIA在QuakeCon遊戲展展示RTX 5080-powered Ultimate雲端遊戲，支援5K 120fps畫質，並可跨裝置遊玩。
- **7月新增15款遊戲**：包括Call of Duty: Black Ops 6、Dino Crisis系列、Halo: Campaign Evolved等，持續豐富遊戲庫。
- **跨裝置遊戲體驗**：玩家可從任何裝置（電腦、手機、平板、電視）遊玩，無需安裝，隨時隨地享受遊戲。

## 結論
GeForce NOW持續擴展遊戲庫，透過雲端技術讓玩家無需高階硬體即可體驗大量遊戲，並透過現場活動展示未來雲端遊戲趨勢。
