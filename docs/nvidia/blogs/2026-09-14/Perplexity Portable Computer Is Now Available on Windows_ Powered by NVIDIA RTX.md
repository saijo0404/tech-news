# Perplexity Portable Computer Is Now Available on Windows, Powered by NVIDIA RTX

- **來源**: NVIDIA Blog
- **發布日期**: 2026-09-14
- **原文連結**: https://blogs.nvidia.com/blog/local-ai-perplexity-windows-pcs/

## 核心主題
Perplexity 推出了 Portable Computer，可在 Windows 上運行，由 NVIDIA RTX 加速，提供本地 AI 代理功能。

## 關鍵重點
- **本地 AI 代理**：Perplexity Portable Computer 是本地版本的 Perplexity Computer，可在 Windows PC 上運行，保護敏感資料不離機。
- **硬體支援**：支援 NVIDIA GeForce RTX 和 RTX PRO 工作站，需要 24GB 或以上 VRAM。
- **無需複雜配置**：預裝 Qwen 3.8 27B 本地模型，優化 NVIDIA RTX GPU，無需自行配置複雜軟體堆疊。
- **跨應用整合**：支援 Microsoft Outlook、OneDrive、Word、Google Drive、Gmail、Slack 和 GitHub 等連接器，可處理工程、財務、創業等任務。
- **雲端協作**：複雜任務可自動識別並請求用戶同意後上傳至雲端模型處理。

## 結論
Perplexity Portable Computer 為 Windows 用戶帶來了更便捷的本地 AI 代理體驗，讓敏感資料處理更私密，同時降低雲端服務成本。
