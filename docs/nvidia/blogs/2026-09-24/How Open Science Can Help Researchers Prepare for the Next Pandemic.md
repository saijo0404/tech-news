# How Open Science Can Help Researchers Prepare for the Next Pandemic

- **來源**: NVIDIA Blog
- **發布日期**: 2026-09-24
- **原文連結**: https://blogs.nvidia.com/blog/open-protein-dataset/

## 核心主題
NVIDIA 與全球研究機構合作，開放式發布超過 2,800 種病毒的蛋白質結構預測數據，幫助科學家為未來大流行病做好準備。

## 關鍵重點
- 使用 AlphaFold2 模型和 NVIDIA BioNeMo 優化，預測了 2,800 多種病毒的蛋白質複合物 3D 結構，並開放給全球科學家使用
- 開放式數據集包含 30% 全新的蛋白質相互作用，這些互動形狀從未在蛋白質數據庫中記錄過，為生物學研究提供新洞察
- 提供 BioNeMo Structure Prediction Pipeline，讓研究者可以從蛋白質序列自行預測 3D 結構，加速疫苗和藥物開發

## 結論
這項開放式合作將加速疫苗和藥物開發，降低資源有限地區科學家的研究門檻，為應對未來大流行病提供關鍵基礎。
