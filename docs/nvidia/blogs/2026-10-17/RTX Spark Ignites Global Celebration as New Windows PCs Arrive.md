# RTX Spark Ignites Global Celebration as New Windows PCs Arrive

- **來源**: NVIDIA Blog
- **發布日期**: 2026-10-17
- **原文連結**: https://blogs.nvidia.com/blog/local-ai-rtx-spark-windows-laptops-celebration/

## 核心主題
NVIDIA 推出搭載 Blackwell RTX GPU 的 RTX Spark 筆記型電腦，並在全球多個城市舉辦發表會，標誌著 Windows PC 的新世代。

## 關鍵重點
- RTX Spark 筆記型電腦搭載 NVIDIA Blackwell RTX GPU 和 Grace CPU，提供高達 128GB 統一記憶體和 1 petaflop AI 運算能力
- 由 ASUS、Dell、HP、Lenovo、Microsoft 和 MSI 等品牌推出，售價從 $2,399 開始，帶來強大的本地 AI、內容創作和遊戲能力
- NVIDIA 在全球六個城市舉辦發表會，包括柏林、北京、伊斯坦堡、首爾、舊金山和台北，現場提供實機體驗和互動演示

## 結論
RTX Spark 筆記型電腦的推出標誌著 Windows PC 的新世代，將 NVIDIA 加速運算創新整合到單一超級晶片，並在全球範圍內受到熱烈歡迎。
