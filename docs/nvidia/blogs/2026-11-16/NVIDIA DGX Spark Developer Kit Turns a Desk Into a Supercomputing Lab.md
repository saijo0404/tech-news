# NVIDIA DGX Spark Developer Kit Turns a Desk Into a Supercomputing Lab

- **來源**: NVIDIA Blog
- **發布日期**: 2026-11-16
- **原文連結**: https://blogs.nvidia.com/blog/dgx-spark-hpc-developer-kit-sc26/

## 核心主題
NVIDIA 在 SC26 超級計算機會議上推出 DGX Spark HPC Developer Kit，讓研究人員可以在桌上電腦上運行多節點科學工作負載、AI 模型和智能體，無需等待共享 GPU 集群的排隊時間。

## 關鍵重點
- **桌上超級計算機集群**：四節 DGX Spark 系統通過 NVIDIA ConnectX-7 網絡直接環形連接，提供 512GB 記憶體和 20TB NVMe 儲存，無需額外購買網絡交換器。
- **支援超大模型**：透過 NVFP4 量化技術，可在四節 DGX Spark 集群上本地部署高達 700B 參數的模型（如 DeepSeek V4.1）。
- **加速科學研究**：支援 LAMMPS、NAMD、GROMACS、OpenFOAM、WRF 等科學模擬工具，以及 OpenFold3、Boltz-2 等 AI 模型，大幅縮短研究週期。
- **本地開發與調試**：提供 NVIDIA HPC SDK 安裝指南，包含 GPU 加速的 C/C++/Fortran 編譯器和消息傳遞工具，讓團隊可本地開發、調試科學應用。
- **真實應用案例**：Kvantify 運行 70 量子比特量子化學模擬、CYRAN AI 加速衛星影像解碼、UC Berkeley Rubin Lab 將結果時間縮短 15 倍。

## 結論
DGX Spark Developer Kit 為研究人員提供了前所未有的本地高性能計算解決方案，使科學模擬、AI 模型訓練和智能體開發不再受制於共享集群的排隊時間，大幅提升研究效率與靈活性。
