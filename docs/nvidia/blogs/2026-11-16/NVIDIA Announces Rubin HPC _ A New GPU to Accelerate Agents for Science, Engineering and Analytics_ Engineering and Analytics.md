# NVIDIA Announces Rubin HPC — A New GPU to Accelerate Agents for Science, Engineering and Analytics

- **來源**: NVIDIA Blogs
- **發布日期**: 2026-11-16
- **原文連結**: https://blogs.nvidia.com/blog/rubin-hpc/

## 核心主題
NVIDIA 於 SC26 發表 Rubin HPC，這是 Vera Rubin 平台的全新 GPU，旨在加速科學、工程和數據分析工作流中的模擬與數據處理。

## 關鍵重點
- **創紀錄的 CUDA 核心數**：單卡擁有超過 50,000 個 CUDA 核心，大幅提升計算能力。
- **稀疏數據加速與 NVLink 互連**：支援稀疏數據加速功能，並採用第七代 NVLink 技術加速 GPU 間連接。
- **與 CUDA-X 庫協同加速**：配合 NVIDIA CUDA-X 優化庫，為代理（agents）提供科學發現的最快路徑。
- **縮短發現週期**：透過加速模擬，縮短從假設到驗證的循環，幫助科學家更快實現突破。

## 結論
Rubin HPC 預計於 2028 年上市，將透過平衡數據移動與計算能力的設計，優化科學計算工作負載，幫助科學家與工程師在氣候模型、工程模擬、基因組分析等領域實現更快、更高效的突破。
