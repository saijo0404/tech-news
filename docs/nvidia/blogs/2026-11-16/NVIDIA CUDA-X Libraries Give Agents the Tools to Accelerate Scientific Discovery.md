# NVIDIA CUDA-X Libraries Give Agents the Tools to Accelerate Scientific Discovery

- **來源**: NVIDIA Blogs
- **發布日期**: 2026-11-16
- **原文連結**: https://blogs.nvidia.com/blog/cuda-x-libraries-agents-accelerate-scientific-discovery/

## 核心主題
NVIDIA 推出 CUDA-X 新函式庫系列，透過 GPU 加速幫助 AI 代理在科學研究領域取得突破性進展，大幅縮短數據分析與模擬時間。

## 關鍵重點
- **cuPhoton 加速天文觀測**：Event Horizon Telescope 的黑洞觀測數據處理時間從一個月縮短至八分鐘，成功重建 M87* 黑洞影像。
- **cuPhoton.xLens 輔助聚變模擬**：讓 Pacific Fusion 研究員在模擬運行時即時分析數據，並結合 Nemotron 代理進行互動式分析。
- **cuPotential 加速藥物開發**：分子模擬速度提升 3 倍，已與 Schrödinger 等多家公司合作，被 Cadence、Fathom Therapeutics 等採用。
- **Daviator 加速材料研究**：在 ALCHEMI 中提供量子力學計算加速，速度提升 22 倍，成本降低 75%。
- **cuSpa 加速生物學分析**：單細胞分析速度提升 900 倍，Therna Biosciences 處理速度提升 200 倍，10x Genomics 整合至 Sentira 平台。

## 結論
NVIDIA CUDA-X 函式庫透過 GPU 加速技術，為科學家提供處理海量數據與複雜模擬的強大工具，從天體物理、材料科學到單細胞生物學，全面加速科學發現的進程。
