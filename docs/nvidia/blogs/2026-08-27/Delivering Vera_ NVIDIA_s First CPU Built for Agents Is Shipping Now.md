# Delivering Vera: NVIDIA’s First CPU Built for Agents Is Shipping Now

- **來源**: NVIDIA Blog
- **發布日期**: 2026-08-27
- **原文連結**: https://blogs.nvidia.com/blog/vera-cpu-delivery/

## 核心主題
NVIDIA 推出其首款為代理 AI 量身打造的 Vera CPU，並開始大規模交付給 AWS、Oracle Cloud Infrastructure 等合作夥伴。

## 關鍵重點
- Vera CPU 擁有 88 個自訂 Olympus 核心，提供 1.2TB/s 記憶體頻寬，在代理 AI 工作負載上比傳統 CPU 快 1.8 倍
- NVIDIA 已向 AWS、Oracle Cloud Infrastructure、Anthropic、OpenAI 和 SpaceXAI 等客戶交付 Vera CPU 系統
- Vera CPU 與 Vera Rubin GPU 搭配使用，透過統一記憶體架構實現 2 倍於傳統基礎設施的能源效率

## 結論
Vera CPU 標誌著 AI 基礎設施的新里程碑，特別適合處理需要編程、工具調用和長上下文管理的代理 AI 工作負載。
