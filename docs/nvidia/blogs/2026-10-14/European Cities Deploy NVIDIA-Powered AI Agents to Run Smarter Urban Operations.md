# European Cities Deploy NVIDIA-Powered AI Agents to Run Smarter Urban Operations

- **來源**: NVIDIA Blog
- **發布日期**: 2026-10-13
- **原文連結**: https://blogs.nvidia.com/blog/european-cities-agents-urban-operations/

## 核心主題
歐洲城市廣泛部署 NVIDIA 驅動的 AI 代理，利用加速計算和數位孿生技術來改善城市運營和公共服務。

## 關鍵重點
- 多個歐洲城市（英國利物浦、法國科多爾省、意大利米蘭、比利時安特衛普等）與 NVIDIA 合作夥伴（K2K、Akila、ThinkDeep、Galene.AI 等）共同部署 AI 代理，應用於城市規劃、公共服務和公共設施管理。
- 使用 NVIDIA Cosmos、Nemotron、Omniverse 等技術，建立本地 AI 工廠以處理數據並保持數據主權，包括能源管理、公共設施維護、交通規劃、安全監控等應用。
- 實際效益顯著：法國科多爾省透過 AI 代理將文件搜尋時間從數週縮短至數分鐘，總營運成本降低 10%，目標規模化後可達 30%。

## 結論
歐洲城市正透過本地化 AI 基礎設施和 AI 工廠，實現更智能的城市運營，同時保持數據主權和控制權，並持續擴展至更多部門和地區。
