# Physical AI Takes the Wheel: How the World's Robotaxi Leaders Are Building With NVIDIA Technologies

- **來源**: NVIDIA Blog
- **發布日期**: 2026-09-10
- **原文連結**: https://blogs.nvidia.com/blog/robotaxi-leaders-full-stack-open-platform/

## 核心主題
NVIDIA 提供完整的機器人計程車技術堆疊，涵蓋 AI 訓練、模擬驗證和車載計算，幫助全球主要機器人計程車公司開發和部署無人駕駛車隊。

## 關鍵重點
- **三電腦解決方案**：NVIDIA 提供訓練電腦（DGX）、模擬驗證電腦（Omniverse 和 Cosmos）、車載電腦（DRIVE Hyperion）的完整技術堆疊
- **主要合作夥伴**：Uber、Waymo、Mercedes-Benz、Lucid、Nuro、Pony.ai 等全球機器人計程車領導者已採用 NVIDIA 技術
- **技術亮點**：NVIDIA Alpamayo 開放式 VLA 模型、NVIDIA Cosmos 世界基礎模型、DRIVE AGX Thor 晶片提供感知、推理和路徑規劃能力
- **市場規模**：機器人計程車市場預計 2035 年達到 4000 億美元，已有超過 600 萬輛商用車輛在運行

## 結論
從雲端訓練到車載部署，NVIDIA 的加速計算技術已成為機器人計程車平台開發的關鍵基礎設施，幫助企業實現從開發到商業化部署的全流程自動化。
