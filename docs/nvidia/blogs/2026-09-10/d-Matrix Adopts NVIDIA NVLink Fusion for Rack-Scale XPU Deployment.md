# d-Matrix Adopts NVIDIA NVLink Fusion for Rack-Scale XPU Deployment

- **來源**: NVIDIA Blog
- **發布日期**: 2026-09-10
- **原文連結**: https://blogs.nvidia.com/blog/d-matrix-nvlink-fusion/

## 核心主題
d-Matrix 宣布採用 NVIDIA NVLink Fusion 技術，將其新一代 Raptor XPUs 與 NVIDIA AI 基礎設施平台連接，以加速從自訂矽晶片到大規模部署的過渡。

## 關鍵重點
- NVLink Fusion 提供高頻寬、低延遲連接，使 d-Matrix 能利用 NVIDIA MGX 生態系統的成熟架構、供應鏈、供電和冷卻基礎設施。
- 採用標準化机架設計，數據中心可一次性建設並支援 GPU、CPU 和 XPUs，無需為每種處理器類型建立獨立的机架架構。
- d-Matrix 計劃將其 XPUs 連接至單一高頻寬、低延遲擴展域，並與 NVIDIA GPU 系統（如 Vera Rubin NVL72）協同工作，實現分散式推理。

## 結論
通過採用 NVLink Fusion，d-Matrix 能夠加速上市時間、提高性能並降低部署半自訂 AI 工廠的風險，同時利用 NVIDIA 的全套 AI 工廠平台。
