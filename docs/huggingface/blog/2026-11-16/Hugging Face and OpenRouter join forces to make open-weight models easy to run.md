# Hugging Face and OpenRouter join forces to make open-weight models easy to run

- **來源**: Hugging Face Blog
- **發布日期**: 2026-11-16
- **原文連結**: https://huggingface.co/blog/openrouter

## 核心主題
Hugging Face 與 OpenRouter 合作，使用 OpenRouter 的智能路由系統，讓用戶可以通過單一 API 和 Hugging Face token 輕鬆調用所有開源權重模型，並根據實時價格、速度和可靠性自動選擇最佳供應商。

## 關鍵重點
- 開源權重模型在 OpenRouter 上的使用量從 2025 年 10 月的 26.8% 上升至 2026 年 9 月底的 71.7%，顯示出開源模型越來越受歡迎
- 開源權重模型平均成本僅為閉源模型的 1/4（輸入 token 每百萬 $0.28 vs $1.27，輸出 token 每百萬 $1.62 vs $6.36）
- OpenRouter 的智能路由系統根據實時價格、速度和可靠性自動選擇最佳供應商，並支持失敗重試機制，將容量錯誤降低了 46%

## 結論
這次合作讓開發者可以保持現有代碼不變，通過 Hugging Face token 即可調用所有開源模型，同時享受 OpenRouter 的智能路由和成本優勢。
