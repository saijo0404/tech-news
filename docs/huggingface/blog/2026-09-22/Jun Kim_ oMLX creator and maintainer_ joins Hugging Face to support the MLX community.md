# Jun Kim, oMLX creator and maintainer, joins Hugging Face to support the MLX community

- **來源**: Hugging Face Blog
- **發布日期**: 2026-09-22
- **原文連結**: https://huggingface.co/blog/omlx

## 核心主題
Hugging Face 正式歡迎 Jun Kim 加入團隊，成為 oMLX 的維護者，以支持 MLX 社區的發展。

## 關鍵重點
- Jun Kim 從側邊工作轉變為全職維護 oMLX 項目，確保長期穩定發展
- oMLX 將作為新想法的測試床，並利用現有依賴（如 mlx-lm 和 mlx-vlm）
- 目標是簡化從 transformers 模型定義到 MLX 實現的轉換，促進生態系整合
- oMLX 保持 Apache 2.0 許可，Jun Kim 繼續領導項目

## 結論
Hugging Face 對 MLX 和 oMLX 的承諾展現了對本地 AI 生態系的持續支持，為開發者提供了更穩定的工具基礎設施。
