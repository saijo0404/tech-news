# Pay for Hugging Face Hub with your Google Cloud Account

- **來源**: Hugging Face Blog
- **發布日期**: 2026-11-10
- **原文連結**: https://huggingface.co/blog/hub-gcp-marketplace

## 核心主題
Hugging Face 現在允許將組織與 Google Cloud 帳戶連結，使 Hugging Face 的使用費用顯示在 Google Cloud 帳單上，而不是直接由信用卡支付。

## 關鍵重點
- **單一帳單**：Hugging Face 的使用費用會顯示在現有的 Google Cloud 帳單上，與其他雲端支出一起計費。
- **無需新增供應商**：購買通過現有的 Google Cloud 帳單和採購流程進行，無需引入新的供應商。
- **涵蓋所有內容**：升級組織到 Team 或 Enterprise 訂閱、按使用量付費的計算（Jobs、推理終端點、推理提供者、GPU Spaces、ZeroGPU 配額擴展）以及額外的公共 Hugging Face 定價存儲。

## 結論
通過 Google Cloud Marketplace 訂閱後，組織將通過 Google Cloud 帳戶計費，所有成員都可以使用 Hugging Face 計算服務，費用將顯示在 Google Cloud 帳單上。
