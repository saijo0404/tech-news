# ToyBlocks - A controlled world for robot learning and evaluation

- **來源**: Hugging Face Blog
- **發布日期**: 2026-11-06
- **原文連結**: https://huggingface.co/blog/allenai/toyblocks

## 核心主題
ToyBlocks 是 AllenAI 推出的機器人學習與評估框架，作為 FoundationWorlds 系列的首個作品，提供一個受控的模擬環境，包含機械臂與積木，用於研究機器人在簡單環境中的學習與泛化能力。

## 關鍵重點
- **自動生成任務與演示**：透過強化學習與運動規劃自動產生大量訓練數據，無需人工遠端操作
- **高層次推理與低層次動作**：結合高層次規劃模型（如 Molmo 2）與低層次動作模型（如 ManiFlow）
- **Agent 學習能力驗證**：在拼字任務中，Agent 成功解決或正確識別不可行任務的比例達 63%
- **技能自適應機制**：Agent 能像科學家一樣進行實驗，自行撰寫的技能描述使成功率從 24% 提升至 63%
- **世界模型預測能力**：測試 Wan 2.2、Astra 和 LeWM 三種模型，Wan 2.2 預測最準確，添加最佳模型生成的軌跡可將政策成功率從 19% 提升至 78%
- **模擬到現實轉移**：ManiFlow 低層技能成功率模擬 80.0% vs 實世界 81.1%，Molmo 2 + ManiFlow 系統模擬 55.5% vs 實世界 50.0%
- **完整數據集與資源**：初始數據集包含 85,336 個長時程演示（約 1,600 小時、1.44 億幀）

## 結論
ToyBlocks 框架讓研究者能系統性地驗證機器人在空間推理、多步驟規劃及跨環境泛化方面的能力，並為未來更複雜環境的機器人學習提供測試床。未來方向包括雙臂操作、靈活機器人手、非結構化堆疊操作，目標是讓機器人可靠地應用所學知識到陌生任務和環境。
