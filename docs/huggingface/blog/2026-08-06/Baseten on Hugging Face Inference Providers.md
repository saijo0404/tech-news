# Baseten on Hugging Face Inference Providers

- **來源**: Hugging Face Blog
- **發布日期**: 2026-08-06
- **原文連結**: https://huggingface.co/blog/baseten

## 核心主題
Hugging Face 正式將 Baseten 納入其推理服務供應商生態系統，使開發者可以更輕鬆地通過 Hugging Face Hub 訪問和使用 Baseten 提供的 AI 模型。

## 關鍵重點
- Baseten 現在是 Hugging Face Hub 的支援推理服務供應商，可在模型頁面直接使用
- 支援多種模型類型，包括 Kimi K3、DeepSeek V4 Flash、GLM-5.2 等熱門開源大語言模型
- 提供兩種使用模式：自訂 API 金鑰（直接呼叫 Baseten）和通過 Hugging Face 路由（使用 HF 帳戶付費）
- 已整合到 Hugging Face SDK（Python 和 JavaScript）以及多個 Agent Harness 工具中
- PRO 用戶每月獲得 2 美元推理信用，可跨供應商使用

## 結論
這項整合大幅降低了開發者使用 Baseten 服務的門檻，使更多開源模型能更便捷地應用於實際專案。
