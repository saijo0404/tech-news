# Give Your Coding Agents a Memory You Own

- **來源**: Hugging Face Blog
- **發布日期**: 2026-09-03
- **原文連結**: https://huggingface.co/blog/funes

## 核心主題
這篇文章介紹了 funes 工具，它讓編碼代理擁有自己的持久記憶，解決了代理間記憶斷裂的問題，使不同代理能共享和追溯歷史決策。

## 關鍵重點
- **單一記憶層**: funes 為 Claude Code、Codex、pi 和 Hermes 等多個代理提供統一的記憶層，所有代理寫入相同格式的記憶。
- **原始證據保留**: 記憶不經過摘要處理，保留原始文本和完整上下文，可追溯至原始會話和轉折。
- **本地隱私優先**: 預設本地運行，無需 Hugging Face 帳號，嵌入和重排序都在本地完成，確保隱私。
- **跨機器共享**: 可將記憶綁定到 Hugging Face dataset，讓不同機器上的代理共享同一記憶。
- **比交接更便宜**: 測試顯示 recall 比手動交接便宜 8 倍和 4 倍，避免重新開始。
- **開放源碼**: 基於開源組件（Lance、本地嵌入模型），可自訂和貢獻。

## 結論
funes 將編碼代理的會話記錄轉化為可查詢、可追溯的記憶系統，讓開發者無需擔心代理間記憶斷裂，並提供比傳統交接更高效的解決方案。
