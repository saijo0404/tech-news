# Training Swarms: How to build, train, and evaluate multi-agent systems

- **來源**: Hugging Face Blog
- **發布日期**: 2026-11-26
- **原文連結**: https://huggingface.co/blog/training-swarms

## 核心主題
這篇文章介紹了多智能體系統（Swarms）的構建、訓練與評估方法，透過協同訓練讓多個智能體更有效率地解決問題。

## 關鍵重點
- 多智能體系統透過智能體間的有效溝通協同工作，而非單純增加嘗試次數
- 訓練後成功率從 6.56% 提升至 82.34%，提升 12.5 倍
- 單次嘗試 token 消耗減少 37.4%，溝通頻率增加但總 token 消耗下降
- 廣播式溝通比直接訊息更有效，實驗使用 1 台 H200 訓練器 + 7 台 H200 推論引擎，成本約 $50

## 結論
小規模多智能體系統透過有效溝通，能在相同預算下顯著提升任務成功率，驗證了協作比單純增加嘗試次數更具效益。

---

訓練流程採用 Hugging Face Jobs 在 H200x2 機器上運行，使用 Qwen/Qwen3-0.6B 模型。GPU 0 提供 vLLM 服務基礎模型，GPU 1 執行 TRL 訓練。每次更新包含 128 個團隊，每個團隊有 4 個代理嘗試同一問題。訓練 50-75 次更新後，可獲得 60.9% 的保留問題成功率。
