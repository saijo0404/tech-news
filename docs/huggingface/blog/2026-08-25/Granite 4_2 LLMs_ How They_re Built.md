# Granite 4.2 LLMs: How They're Built

- **來源**: Hugging Face
- **發布日期**: 2026-08-25
- **原文連結**: https://huggingface.co/blog/ibm-granite/granite-4-2

## 核心主題
IBM 推出的 Granite 4.2 是首款密集、僅解碼器的推理 LLM 家族，提供 3B、8B、30B 三種尺寸，採用多階段強化學習訓練，支援思考/不思考模式切換及原生工具調用。

## 關鍵重點
- **模型架構**：三個模型（3B、8B、30B）共享相同架構設計，採用 GQA 注意力機制、RoPE 位置嵌入和 SwiGLU 前饋網絡
- **訓練策略**：從 0 開始預訓練（約 15T tokens），支援 512K tokens 長上下文，混合數據 SFT（代理數據 31.6% + 非代理數據 68.4%）
- **強化學習**：多階段 RL 訓練管道，8B 和 30B 模型額外進行代理 RL（軟體工程→終端→搜尋）
- **推理能力**：所有模型支援思考/不思考模式切換，8B 和 30B 支援低效思考模式（節省推理預算）
- **工具調用**：原生工具調用支援，符合 OpenAI 函數呼叫格式，可透過 vLLM 或 SGLang 部署
- **授權**：Apache 2.0 開放授權

## 結論
Granite 4.2 系列模型在推理能力和工具調用方面展現顯著進步，特別適合需要複雜推理和工具使用能力的應用場景。其多階段訓練管道和開放授權政策為開發者提供了良好的基礎設施和靈活性。
