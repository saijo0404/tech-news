# Build specialized multimodal models with LFM3

- **來源**: Hugging Face Blog
- **發布日期**: 2026-10-27
- **原文連結**: https://huggingface.co/blog/LiquidAI/lfm3

## 核心主題
Hugging Face 團隊推出 LFM3 系列多模態模型，整合文字、視覺、音訊、全模態與決策能力於單一共享架構，首次推出全模態模型並支援邊緣裝置執行。

## 關鍵重點
- LFM3-1.7B 模型效能超越 LFM2.5-2.6B，但參數少 35%，採用三混合架構
- 首次推出六種模態模型分支，支援文字、視覺、音訊、全模態與決策
- 視覺模型支援影片輸入，計算量比 SigLIP2 少 3 倍
- 音訊模型支援流式解碼，首 token 時間低至 50ms
- 所有模型均支援微調，可在單一 GPU 上部署，適用於邊緣設備

## 結論
LFM3 系列模型代表多模態 AI 的重大突破，提供高效能、低資源消耗與高度客製化的解決方案，適合本地部署與邊緣裝置應用。
