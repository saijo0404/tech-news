# An Indic Voice Agent with CUGA

- **來源**: Hugging Face Blog
- **發布日期**: 2026-11-25
- **原文連結**: https://huggingface.co/blog/ibm-research/an-indic-voice-agent-with-cuga

## 核心主題
IBM Research 團隊利用 CUGA 框架開發了一個印地語等多語言語音助手，解決非英語使用者難以使用英文數位服務的痛點，透過語音交互讓印度農業等領域的用戶能更便捷地獲取資訊。

## 關鍵重點
- **跨語言檢索挑戰**：CUGA 預設嵌入模型僅支援英文，導致印地語問題無法正確匹配英文文檔；解決方案是使用多語言嵌入模型（intfloat/multilingual-e5-large），使同一意義無論何種語言都能定位到相同向量。
- **農業助手實例**：農民用印地語詢問「如何分辨好種子與壞種子」，系統將語音轉文字、搜尋 154 頁英文農業手冊、用印地語回答並顯示來源頁面。
- **CUGA 架構優勢**：CUGA 作為可配置通用代理（Configurable Generalist Agent）提供模型串接、工具管理、狀態維護與安全防護，開發者只需撰寫工具與提示，無需處理代理循環。
- **語音層設計**：在 CUGA 文本輸入/輸出基礎上，僅加兩層語音處理（語音轉文字 + 文字轉語音），支援 Sarvam AI 雲端 API 或開源模型（SraVaani/Svara），可自由切換。
- **安全與優化設計**：避免 Markdown 等不適合朗讀的內容、使用簡單輸入檢查快速過濾離題問題、確保所有答案基於檢索內容、用戶鍵值直接由瀏覽器呼叫雲端 API 避免伺服器洩漏。

## 結論
此語音代理展示了如何透過開源、可審計的 CUGA 框架，為印度等語言多樣化地區打造可信任的數位服務。未來可擴展至健康、法律等領域，並透過 Bharat Core 等本土化 AI 堆疊實現數據主權與合規性。
