# BotPsy - On-Device Personal Assistant with a Sub-Billion-Parameter Agentic Language Model

- **來源**: Hugging Face Blog
- **發布日期**: 2026-11-11
- **原文連結**: https://huggingface.co/blog/qvac/botpsy

## 核心主題
BotPsy 是由 Tether AI Research 推出的 0.8B 參數個人助理模型，專為設備端部署優化，在推理效率和指令遵循上表現優異。

## 關鍵重點
- **性能卓越**：工具使用與代理基準測試中表現最佳，超越同級模型（≤1.2B 參數），並在 5/6 個基準測試中領先 Qwen3.5-2B-Think（2.5 倍參數）
- **設備端高效**：推理 token 減少 3 倍，循環率從 22.9% 降至 1.4%
- **安全性提升**：自動紅隊測試中不安全回應率僅 21%（同級模型平均 36%）
- **指令遵循能力大幅提升**：IFEval 從 59.7 升至 90.8
- **多輪對話表現突出**：BFCL v4 多輪任務從 7.5 提升至 46.1，ACEBench Agent 從 7.9 提升至 28.3
- **適用場景**：適合低到中等難度任務、設備與系統管理、個人生產力、一般資訊檢索
- **限制**：不適合高風險任務，多輪任務表現隨指令數量增加而下降

## 結論
BotPsy 作為次十億參數的端側個人助理，在推理效率和指令遵循上表現優異，但通用知識和複雜搜尋能力仍有限，建議用於非關鍵性任務。
