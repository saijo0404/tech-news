# Open-sourcing AstaBrief: the fast report-generation model in Asta

- **來源**: Hugging Face Blog
- **發布日期**: 2026-10-02
- **原文連結**: https://huggingface.co/blog/allenai/astabrief

## 核心主題
AstaBrief 8B 模型正式開源，是 Asta Enterprise 平台中的快速報告生成模型，旨在幫助科學家更快生成引用完整的報告，同時降低生成成本和時間。

## 關鍵重點
- **性能優勢**：相比私有模型，報告生成速度快 3.5 倍（平均 51.1 秒 vs 178.5 秒），採用 SFT 和 DPO 方法訓練，避免 RL 訓練的不穩定性
- **訓練基礎**：基於 Qwen3-8B，使用 90K 真實科學家查詢篩選後生成 47K 訓練示例，專注於科學證據的準確性、引用歸屬和報告結構
- **評估結果**：在 SQABench-CS2 測試中表現良好，人類評估中兩位研究者更偏好其引用準確性，84.2% 使用者對 Fast 模式給予正面反饋
- **使用情況**：374 位 Asta 使用者中 29.1% 使用超過兩天，平均每位使用者生成 3.67 條報告，23% 使用者嘗試 Fast 模式後不再切換回 Thinking 模式
- **開放權重優勢**：作為開放權重模型，機構可自行部署於內部硬體，無需依賴專有 API

## 結論
AstaBrief 模型成功平衡了報告生成速度與準確性，通過開源方式讓機構能自主部署，未來將擴展細粒度偏好學習和強化 RAG+RL 方法，進一步提升多輪多工具能力。
