# AutoSynthData: Generating Training Data for Enterprise Agents

- **來源**: Hugging Face
- **發布日期**: 2026-10-02
- **原文連結**: https://huggingface.co/blog/ServiceNow-AI/autosynthdata

## 核心主題
ServiceNow CoreAI 開發的 AutoSynthData 系統，將企業代理的能力缺口轉化為訓練數據，通過分析目標模型失敗與強教師模型成功，生成並驗證新的訓練任務。

## 關鍵重點
- **任務設計三要素**：系統規範（定義環境限制）、使用者提示（要求代理完成的工作）、驗證器（判斷任務是否成功完成）
- **任務生成三原則**：可行性（任務在環境中可執行）、真實性（符合使用者實際需求）、難度（暴露模型能力缺口）
- **兩階段數據集構建**：目標階段（生成核心樣本）→ 複製階段（擴展為新變體）
- **雙層質量控制**：樣本級驗證（正負驗證、修復循環）+ 批次級審查（覆蓋度與多樣性評估）
- **動態調整訓練 frontier**：根據模型改進結果，持續調整下一輪訓練任務的難度與方向

## 結論
AutoSynthData 提供了一種循環式訓練數據生成框架，通過持續識別能力缺口並生成針對性訓練任務，幫助企業代理在真實環境中逐步提升能力。
