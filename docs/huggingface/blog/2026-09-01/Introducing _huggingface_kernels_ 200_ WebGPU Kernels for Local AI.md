# Introducing @huggingface/kernels: 200+ WebGPU Kernels for Local AI

- **來源**: Hugging Face
- **發布日期**: 2026-09-01
- **原文連結**: https://huggingface.co/blog/webgpu-kernels

## 核心主題
Hugging Face 推出 207 個 WebGPU 核子，提供瀏覽器端本地 AI 推理的優化 GPU 運算庫，並搭配專屬載入庫與社群測試平台。

## 關鍵重點
- 提供 207 個 WebGPU 核子，每個都有完整的版本化套件，包含介面、shader 模板、正確性測試和效能測試案例。
- 推出 Fleet 瀏覽器端效能測試套件，讓使用者可以貢獻真實硬體上的效能與正確性證據。
- 相比 ORT WebGPU，這些核子在多個操作上表現出顯著速度提升，某些情況下快達 10,000 倍以上。
- 每個核子都有獨立的儲存庫和合約，可從 Hugging Face Hub 直接載入並執行。

## 結論
這是一個建立 WebAI 基礎設施的重要步驟，透過透明、版本化的核子合約和社群貢獻的真實硬體測試，將提升瀏覽器端 AI 推理的速度與可靠性。
