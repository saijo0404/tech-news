# How Much Memory Does Your Agent Actually Need?

- **來源**: Hugging Face
- **發布日期**: 2026-08-18
- **原文連結**: https://huggingface.co/blog/ibm-research/altk-evolve-hmm

## 核心主題
這篇文章探討了 AI 代理（agent）需要多少記憶（memory）才能達到最佳效果，發現記憶的「劑量」應該根據模型的能力來調整，而不是一味地增加。

## 關鍵重點
- ALTK-Evolve 技術讓代理可以從自己的過去軌跡中學習，提取可重用的指導原則，並在推理時注入這些指導，無需更新模型權重。
- 記憶的劑量取決於模型能力：能力強的模型（有提升空間）需要完整的指導集，能力較弱的模型則適合使用核心指導加任務相關指導的精選方案。
- 已飽和的模型（如 GLM-5）顯示記憶不會帶來可測量的提升。
- 精選檢索（curated retrieval）可以同時是最準確且最便宜的方案，例如 gpt-oss-120b 在任務完成度上提升 16.1%，但 token 使用量僅增加 5%。
- 提示緩存（prompt caching）可以保持完整的指導集在生產環境中經濟可行。

## 結論
記憶不應該只是累積，而應該根據模型的能力進行校準。給代理的記憶量應該與其能力相匹配，這樣才能在提升準確性的同時保持成本效益。
