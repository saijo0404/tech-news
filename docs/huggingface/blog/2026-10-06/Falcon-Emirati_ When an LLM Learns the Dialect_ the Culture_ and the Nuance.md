# Falcon-Emirati: When an LLM Learns the Dialect, the Culture, and the Nuance

- **來源**: Hugging Face
- **發布日期**: 2026-10-06
- **原文連結**: https://huggingface.co/blog/tiiuae/falcon-emirati

## 核心主題
Falcon-Emirati-7B 是專注於阿拉伯聯合酋長國（UAE）方言的語言模型，旨在讓 LLM 理解阿拉伯聯合酋長國方言、文化與細微差別。

## 關鍵重點
- **資料來源多元**：結合真實阿拉伯聯合酋長國方言網路內容、關於 UAE 文化的標準阿拉伯語資料，以及基於詞典和風格規則的合成資料
- **評估表現優異**：在 Alyah 基準測試中得分 84.83%，領先所有對比模型；在 UAE 文化理解任務中準確率達 85.57%
- **文化理解能力突出**：在詩歌與方言類別中表現優越，甚至在宗教與社會敏感度類別中完勝 Fanar-2-27B
- **使用方式**：可透過 chat.falconllm.tii.ae 平台嘗試使用，但需注意模型可能反映訓練數據中的偏見

## 結論
模型大小不保證方言能力，必須透過針對方言的數據和評估才能提升。Falcon-Emirati-7B 在正確性和方言忠誠度上均顯著領先競爭對手，為阿拉伯聯合酋長國方言理解提供了重要突破。
