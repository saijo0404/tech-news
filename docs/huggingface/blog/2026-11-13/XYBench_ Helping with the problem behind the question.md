# XYBench: Helping with the problem behind the question

- **來源**: Hugging Face
- **發布日期**: 2026-11-13
- **原文連結**: https://huggingface.co/blog/allenai/xybench

## 核心主題
這篇文章介紹了 XYBench，一個用於評估大語言模型（LLM）識別用戶問題背後的真正目標（而非表面請求）的基準測試集。

## 關鍵重點
- XYBench 包含超過 8,000 個真實世界問題，涵蓋程式設計、烹飪和家庭維修等領域，用於測試模型識別誤解並提供有效解決方案的能力。
- 實驗顯示，所有評估的模型（包括 Claude Sonnet 4.6、GPT-5、Gemini 3.1 Pro、Qwen3.5-9B 和 DeepSeek-V4 Pro）都更傾向於解決用戶表面請求（Y），而非真正目標（X）。
- 研究發現模型在識別誤解和優先處理真正目標方面存在顯著差距，即使當用戶明確表達目標時，模型仍無法完全達到人類參考答案的水平。
- XYBench 獲得了 EMNLP 2026 最佳資源論文獎，並提供了三個評估指標：實用解決方案、實用強調和誤解識別。

## 結論
XYBench 為研究者提供了一個工具，可以測試和改進模型識別用戶誤解並提供有效解決方案的能力，即使用戶最初的問題基於錯誤的假設。
