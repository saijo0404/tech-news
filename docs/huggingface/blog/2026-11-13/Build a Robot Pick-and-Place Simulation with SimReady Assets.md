# Build a Robot Pick-and-Place Simulation with SimReady Assets

- **來源**: Hugging Face
- **發布日期**: 2026-11-13
- **原文連結**: https://huggingface.co/blog/nvidia/simready-assets-robot-pick-and-place

## 核心主題
這篇文章介紹如何使用 SimReady 資產在 Isaac Sim 中建立機器人抓取與放置模擬，包括下載資產、組裝機器人、測試控制並執行任務。

## 關鍵重點
- SimReady 資產包含預先配置好的物理屬性（碰撞、質量、關節驅動等），可直接用於模擬
- 使用 SimReady Central 下載 UR17G 機械臂、Robotiq 2F-140 夾爪和飲料罐資產
- 執行前需驗證關節設置、運動和接觸行為，確保模擬準確性

## 結論
透過 AI 代理生成控制程式碼，可自動化完成從抓取到放置的完整流程，提升機器人模擬開發效率。
