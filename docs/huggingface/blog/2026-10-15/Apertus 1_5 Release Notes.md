# Apertus 1.5 Release Notes

- **來源**: Hugging Face
- **發布日期**: 2026-10-15
- **原文連結**: https://huggingface.co/blog/swiss-ai/apertus-v15-release-notes

## 核心主題
Apertus 1.5 是瑞士 AI 實驗室推出的最新模型版本，在原有 8B 和 70B 模型基礎上擴展了多模態理解能力、思考模式及更長的上下文窗口。

## 關鍵重點
- **原生多模態理解**：模型可同時處理圖像、音頻和文本，無需額外視覺編碼器，通過擴展詞表實現
- **思考模式**：可切換至推理模式，先思考再回答，提升複雜推理任務表現
- **四倍上下文窗口**：從 8k 擴展至 262,144 tokens，大幅提升長文處理能力
- **改進的指令遵循**：比前代模型更準確地理解並執行指令
- **改進的工具使用**：強化與外部工具和 API 的整合能力
- **開放價值**：嚴格遵循 Apertus 憲章，確保模型價值和原則的透明度

## 結論
Apertus 1.5 通過持續預訓練和後訓練，在保持完全開放（權重、數據、價值、訓練細節）的同時，顯著提升了多模態理解和推理能力，為開源模型發展提供了可重現的範例。
