# FLUX.3 Image Klein 模型

- **來源**: Hugging Face Blog
- **發布日期**: 2026-10-15
- **原文連結**: https://huggingface.co/blog/flux-3

## 核心主題
FLUX.3 Image Klein 模型是整合了文字生成圖像、多參考圖像編輯與佈局控制的新一代影像生成模型，支援模組化 Diffusers 管道並提供優化的性能表現。

## 關鍵重點
- 支援完整場景描述的文字生成圖像，預設 16 步驟生成 1024×1024 圖像
- 多參考圖像編輯功能，可傳遞多張參考圖像並透過提示詞指定來源
- 新增框選控制功能，可指定圖像中特定區域位置，支援區域移動
- 採用潛在空間架構，使用 VAE 將潛在空間轉換為像素，影像壓縮 8 倍並打包為 token
- 雙階段處理架構：文字、影像與參考影像各自獨立處理後，所有 token 聯合處理互相學習
- 使用 Qwen3-VL 進行多層文字編碼，整合 8 個不同深度的隱藏狀態
- 採用四維位置編碼（RoPE），使用 (timestep, height, width, sequence length) 提升位置感知能力
- 每個 token 獨立時間步調，影像 token 使用當前時間步，文字與參考影像固定於時間步 0
- 50 步驟去噪循環，使用大時間偏移（6.93），前 10 步驟呈現基本輪廓，細節在最後幾步生成
- 精簡檢查點：H100 上約 2 秒生成 1024×1024 圖像
- 記憶體優化：支援 NVFP4 與 FP8 量化，降低記憶體佔用
- 模組化 Diffusers 管道，可擴充或移除組件
- 支援 LoRA 微調，可訓練特定風格模型
- 提供 DreamBooth 訓練腳本
- 硬體建議：精簡版本 H100 約 16-20GB 記憶體，量化版本 RTX 6000 約 13-15GB 記憶體

## 結論
FLUX.3 Image Klein 模型透過模組化架構與記憶體優化技術，在保持高品質影像生成的同時大幅降低硬體門檻，為開發者提供靈活的微調與部署選項。
