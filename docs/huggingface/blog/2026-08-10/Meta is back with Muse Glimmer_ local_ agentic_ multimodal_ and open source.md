# Muse Glimmer

- **來源**: Hugging Face Blog
- **發布日期**: 2026-08-10
- **原文連結**: https://huggingface.co/blog/muse-glimmer

## 核心主題
Meta 推出 Muse Glimmer 30B 本地多模態開源模型，支援圖片與視頻理解，具備本地代理應用能力。

## 關鍵重點
- 30B 參數規模，Apache 2.0 開源授權，可透過 Hugging Face Hub 下載
- 支援多模態（文字、圖片）與本地部署，適合隱私敏感應用
- 具備自動推理優化與量化能力，支援 DFlash 加速
- 支援 NVIDIA/AMD/Intel GPU 部署，提供完整 Python 程式碼範例
- 在編程任務（SWE-Bench）與多模態推理測試中表現優異

## 結論
Muse Glimmer 是 Meta 推出的開源多模態模型，適合本地隱私敏感應用，提供完整的部署與使用工具鏈，包括 Hugging Face Hub、vLLM、llama.cpp 等多種部署方式。
