# The model that didn't exist, so you made it yourself

- **來源**: Hugging Face Blog
- **發布日期**: 2026-10-08
- **原文連結**: https://huggingface.co/blog/building-with-ml-intern

## 核心主題
作者使用 Hugging Face 的 ML Intern 工具，在幾天內創建了多個原本不存在的模型，從零預算開始，通過提示詞工程實現模型開發。

## 關鍵重點
- 作者通過描述需求，讓 ML Intern 在一天內創建了 0.8B 版本的 Prompt Rewriter 模型，僅需 CPU 運行，成本僅 16 美元
- 創建了 5 個更多模型，每個都從 HuggingChat 開始，最終成為 Hub 上的公開模型，包含柑橘疾病診斷、Huggy 角色模型、相機角度 LoRA、Doodle-in LoRA、口袋重写器和 Agate 4-step 模型
- 強調預算控制、基線測試和煙霧測試的重要性，確保模型開發過程透明可控
- 總計算成本約 103 美元，包括 GPU 和 CPU 作業費用，展現了 AI 模型開發的民主化趨勢

## 結論
ML Intern 是 HuggingChat 中的功能，用戶可以通過簡單提示創建模型，並分享成果。文章鼓勵用戶嘗試使用此工具創建他人不會想到的模型，並標記 @Gradio 和 @HuggingFace。
