# PD Serving of Qwen3.8-2.4T

- **來源**: vLLM Blog
- **發布日期**: 2026-09-21
- **原文連結**: https://vllm.ai/blog/2026-09-21-qwen38-pd-serving

## 核心主題
vLLM 團隊在 GB300 NVL72 集群上對 Qwen3.8-2.4T 模型進行 PD（Prefill-Decode）服務性能測試，建立了完整的帕累托前沿曲線，涵蓋高吞吐量與低延遲兩種極端場景。

## 關鍵重點
- 高吞吐量場景下，vLLM 每 GPU 達到 5000 總 token 吞吐量，低延遲場景下每用戶生成 token 速率達 180 tokens/秒
- 文章詳細拆解了性能調優過程，包括 KV cache 估計、峰值激活、CUDA graph 等關鍵因素的分析方法
- 提供了完整的 srt-slurm 腳本和決策過程，讓其他人可以驗證並重現性能結果
- 針對 Qwen3.8-2.4T 的混合架構特性（92 層，包含 GDN 和 Full-Attn 層），提供了精確的記憶體分配和並發度計算方法
- 通過分離測量 prefill 和 decode 性能，為分散式服務架構提供了最佳 topology 選擇建議

## 結論
這篇文章不僅提供了令人印象深刻的性能數字，更重要的是分享了可重用的性能調優工作流程，為其他模型在 vLLM 上的 PD 服務優化提供了寶貴的參考。
