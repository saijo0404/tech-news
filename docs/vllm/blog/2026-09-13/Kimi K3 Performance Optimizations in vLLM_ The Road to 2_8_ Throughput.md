# Kimi K3 Performance Optimizations in vLLM: The Road to 2.8× Throughput

- **來源**: vLLM Blog
- **發布日期**: 2026-09-13
- **原文連結**: https://vllm.ai/blog/2026-09-13-kimi-k3-performance-optimization

## 核心主題
vLLM 團隊針對 Kimi K3 模型進行了全面的性能優化，透過針對 KDA 狀態管理、記憶體佈局與並行策略的改進，實現了 2.2 至 2.8 倍的吞吐量提升。

## 關鍵重點
- **整體性能提升**：在並發量 1、4、16 的情況下，平均延遲降低 56%–60%，吞吐量提升 120%–180%，首 token 延遲 (TTFT) 降低 72%–85%。
- **四項代表性優化**：
  - 適應性推論 token 預算：根據請求數量動態調整，減少不必要的模型前向傳播。
  - 內部 KDA 前綴檢查點：在單一前向傳播中完成檢查點導出，避免第二次完整模型遍歷。
  - 零複製混合 KDA 批次：透過連續視圖與直接寫入，減少索引選擇與複製操作。
  - 延遲 MXFP4 最終化：將 MXFP4 頂部-k 最終化整合至潛尾核心中，減少核心理發次數。
- **ReplaySSM 技術**：改用緩存 SSM 輸入並重建接受狀態，取代每步寫入 KDA 狀態，大幅提升有效容量。
- **Prefill/Decode 分離與混合狀態離線**：針對 Mamba 與 KDA 狀態的差異化處理，優化記憶體傳輸。
- **解碼上下文並行 (DCP)**：沿序列維度分片 KV Cache，大幅提升長共享前綴代理工作負載的 KV 容量，並降低查詢交換延遲。

## 結論
透過針對 Kimi K3 架構特性的深度優化，vLLM 成功將服務效率推向新高度，為未來更大規模模型部署奠定基礎。完整優化工作追蹤於 GitHub Issue #50587。
