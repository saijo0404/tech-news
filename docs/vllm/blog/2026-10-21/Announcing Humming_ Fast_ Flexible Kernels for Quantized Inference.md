# Announcing Humming: Fast, Flexible Kernels for Quantized Inference

- **來源**: vLLM
- **發布日期**: 2026-10-21
- **原文連結**: https://vllm.ai/blog/2026-10-21-humming

## 核心主題
Humming 是 Ant Group 與 vLLM 社區開源的通用高性能量化推理核庫，提供廣泛的裝置支援和量化格式支援，顯著提升推理效率。

## 關鍵重點
- **廣泛裝置支援**：支援 NVIDIA Turing 及之後架構，已支援 T-Head Zhenwu 810E，未來可擴展至其他 CUDA 相容裝置
- **統一量化架構**：將量化描述與執行選擇分離，提供通用介面，可重用組件，降低維護負擔
- **高效 JIT 編譯**：編譯時間從 23.35 秒降至 1.82-1.88 秒，支援並行編譯，暖機時僅需 2-4 秒
- **廣泛量化格式支援**：支援 W4A16、W4A8、W4A4 等組合，包括 INT4、NVFP4 及特殊浮點格式（如 float4e0m3、float8e3m4）
- **優異性能**：小批次比 Marlin 快 3-4 倍，大批次 H200 上達 2 倍、B300 上達 3-5 倍，支援 MoE 工作負載
- **裝置優化**：針對不同 GPU 架構（H200、B300、SM120/121）自動選擇最佳解碼路徑與記憶體存取策略

## 結論
Humming 通過其通用架構和高效 JIT 編譯，為量化推理提供了高性能、易於維護的解決方案，特別適合需要支援多種量化格式和 GPU 架構的場景。
