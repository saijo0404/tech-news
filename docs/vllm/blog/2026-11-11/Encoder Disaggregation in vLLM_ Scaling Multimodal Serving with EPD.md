# Encoder Disaggregation in vLLM: Scaling Multimodal Serving with EPD

- **來源**: vLLM Blog
- **發布日期**: 2026-11-11
- **原文連結**: https://vllm.ai/blog/2026-11-11-encoder-disaggregation-epd

## 核心主題
vLLM 推出 Encoder / Prefill / Decode (EPD) 解耦架構，將多模態推理的三個階段獨立部署，大幅提升擴展性與性能。

## 關鍵重點
- **Metadata-only 請求**：下游實例無需重複預處理，只需傳輸編碼器已計算的結構元數據（如圖片網格、時間戳等）
- **跨模態支援**：支援圖片、影片、音頻等多模態輸入，均採用相同的元數據傳輸機制
- **專用執行路徑**：Model Runner V2 隔離編碼器執行，支援 CUDA Graph 優化，啟動 I/O 大幅降低（從 683 秒降至 0.31 秒）
- **遠端嵌入傳輸**：支援 NIXL 和 Mooncake 兩種後端，透過共享快存實現跨節點傳輸
- **跨編碼器輸出重疊**：Mooncake Store 實現跨實例快存，測試中將 512 張圖片的重複編碼次數從 512 次降至 0 次
- **性能提升**：音頻測試中吞吐量從 62.21 提升至 73.13 requests/s（+17.8%），延遲從 980ms 降至 853ms（-12.9%）

## 結論
EPD 架構透過將編碼、預填充、解碼三階段獨立部署，並結合元數據傳輸、專用執行路徑和共享快存機制，顯著提升多模態服務效率。特別適合圖片/視頻密集型工作負載，可根據不同階段獨立調整資源配置。
