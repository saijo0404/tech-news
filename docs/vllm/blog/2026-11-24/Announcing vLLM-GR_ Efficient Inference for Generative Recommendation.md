# Announcing vLLM-GR: Efficient Inference for Generative Recommendation

- **來源**: vLLM Blog
- **發布日期**: 2026-11-24
- **原文連結**: https://vllm.ai/blog/2026-11-24-vllm-gr-announcement

## 核心主題
vLLM-GR 是一個基於 vLLM 的開源推理和服務框架，專為生成式推薦模型設計，通過光束搜索技術在單一請求中探索多個候選 ID，大幅提升推薦系統的推理效率。

## 關鍵重點
- **vLLM 堆疊整合**：推薦模型可運行在 vLLM 堆疊上，重用 vLLM 的模型執行、調度和分頁 KV 快取，支持 NVIDIA GPU 和 Ascend NPU 硬體。
- **降低搜索成本**：通過光束搜索在單一請求中探索多個候選 ID，候選路徑共享快取的使用者歷史，減少重複計算和主機與加速器間的協調。
- **目錄約束**：推薦結果與商品目錄保持一致，通過目錄約束引導搜索指向真實商品 ID，支持模型和目錄更新。
- **優異性能**：在多個加速器上（包括 H20、RTX PRO 6000、A100、A2、A5）展現優異性能，批量大小 4 和 8 時記錄最低 P99 延遲。

## 結論
vLLM-GR 成功將 vLLM 的高性能推理能力應用於生成式推薦場景，通過光束搜索和目錄約束解決推薦服務中的關鍵挑戰，為推薦模型在線服務提供高效、靈活且易用的解決方案。
