# The Gemini app is now available for Windows

- **來源**: Google Blog
- **發布日期**: 2026-09-10
- **原文連結**: https://blog.google/innovation-and-ai/products/gemini-app/gemini-app-now-on-windows/

## 核心主題
Google 正式推出 Gemini app for Windows，讓使用者可以透過簡單的鍵盤捷徑直接獲得 AI 協助，無需離開當前工作流。

## 關鍵重點
- 使用 Alt + Space 鍵盤捷徑即可快速開啟 Gemini，隨時獲得即時協助
- 支援從 Gmail、Google Drive 等 Google 應用程式中獲取資訊，並可處理多步驟任務
- 可以產生自訂圖片（使用 Nano Banana）與影片（使用 Gemini Omni），整合在單一工作空間中
- 輕量級設計，運行時不會影響電腦運作速度
- 全球開放下載，支援 Windows 10 和 Windows 11 系統

## 結論
這是 Gemini app 在 Windows 平台的首發，未來還會持續推出更多原生桌面功能，讓 AI 協助更深度地融入日常工作流程。
