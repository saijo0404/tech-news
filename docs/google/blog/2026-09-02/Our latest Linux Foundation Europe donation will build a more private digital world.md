# Our latest Linux Foundation Europe donation will build a more private digital world

- **來源**: Google Blog
- **發布日期**: 2026-09-02
- **原文連結**: https://blog.google/products-and-platforms/platforms/google-pay/zero-knowledge-proof-library-linux-foundation/

## 核心主題
Google 捐贈其 Longfellow 零知識證明 (ZKP) 庫給 Linux Foundation Europe 下的 Post-Quantum Cryptography Alliance 聯盟，以建立更私密的數位世界。

## 關鍵重點
- 零知識證明 (ZKP) 技術允許驗證個人資訊（如證明年齡大於18歲）而不分享其他個人資訊，提升隱私保護
- Google 將此加密庫轉移給 Linux Foundation Europe 以建立中立、開放的治理模式，讓全球社群可以信任、審計並採用
- 建立量子安全的數位身份應用標準，促進公共與私人部門間的協作，確保數位憑證的安全使用

## 結論
透過捐贈 ZKP 庫給 Linux Foundation Europe，Google 與全球社群合作建立可互操作的數位基礎設施，確保每個人都能安全使用數位憑證進行信任互動，同時保護個人隱私。
