# Check if a text message is a scam using Circle to Search

- **來源**: Google Blog
- **發布日期**: 2026-10-15
- **原文連結**: https://blog.google/innovation-and-ai/technology/safety-security/circle-to-search-android-text-message-scams/

## 核心主題
Google 推出了 Circle to Search 功能，讓 Android 使用者可以透過圈選可疑訊息來識別潛在詐騙，防止點擊惡意連結或洩露個人資訊。

## 關鍵重點
- 詐騙手法越來越高明，但防禦工具也在不斷進步，Circle to Search 是 Google 提供的最新防護手段
- 使用方式：長按 Android 主畫面按鈕或導航欄，圈選可疑訊息，AI 會自動分析並提供建議
- 若分析結果顯示紅旗，建議立即刪除訊息並封鎖發送者號碼

## 結論
Circle to Search 是簡單有效的防詐騙工具，幫助用戶在點擊連結或分享個人資訊前快速識別潛在風險，提升數位安全防護能力。
