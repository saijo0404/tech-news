# Producers can now vibe code their own music production tools using Google Flow Music.

- **來源**: Google Blog (Google Labs)
- **發布日期**: 2026-10-06
- **原文連結**: https://blog.google/innovation-and-ai/models-and-research/google-labs/create-music-production-plugins-google-flow/

## 核心主題
Google Flow Music 允許音樂製作人使用自然語言（vibe code）創建自訂音樂製作工具，並可導出為 VST3/AU 插件，無需編程經驗。

## 關鍵重點
- 音樂製作人可以使用自然語言創建自訂樂器或效果器，無需編程經驗
- 這些自訂工具可以導出為 VST3/AU 插件，在數位音頻工作站中運行
- 例子：製作人 Khris Riddick-Tynes 創建了名為 "No Chaser" 的插件，確保樂器和人聲清晰專業

## 結論
這項功能讓音樂製作人能更輕鬆地建立符合其工作流程和風格的工具，將創意直接轉化為專業製作環境中的實際工具。
