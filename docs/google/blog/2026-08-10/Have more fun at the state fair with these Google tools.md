# Have more fun at the state fair with these Google tools

- **來源**: Google Blog
- **發布日期**: 2026-08-10
- **原文連結**: https://blog.google/products-and-platforms/products/gemini/state-fair-tips/

## 核心主題
這篇文章介紹了五種使用 Google 工具（特別是 Gemini 和 Maps）來規劃州慶活動的方法，包括行程規劃、導航、尋找美食、了解展覽和創建照片紀念品。

## 關鍵重點
- 使用 Gemini 建立客製化行程，包含休息時間和最喜愛的活動
- 使用 Ask Maps 獲取即時交通資訊和尋找場內的便利設施
- 使用 AI 搜尋功能尋找最受歡迎的州慶美食
- 使用 Gemini Live 或 Search Live 透過相機即時了解展覽資訊
- 使用 Gemini 的圖片編輯功能將照片轉為創意紀念品

## 結論
Google 工具可以幫助你在州慶活動中更好地規劃行程、探索展覽並創造難忘的記憶。
