# Genie 4 is now available on the Gemini API

- **來源**: Google Blog
- **發布日期**: 2026-11-19
- **原文連結**: https://blog.google/innovation-and-ai/technology/developers-tools/genie-4-in-gemini-api/

## 核心主題
Genie 4 正式透過 Gemini API 開放給開發者使用，允許從文字提示或參考圖片開始，生成連續的 720p 世界場景，並具備同步音訊功能。

## 關鍵重點
- 開發者可透過 Gemini API 或 Google AI Studio 使用 Genie 4，從文字提示、參考圖片或兩者開始生成內容
- 支援生成連續 720p 世界場景（24fps），並包含同步的本地音訊（環境音效、音效、角色對話）
- 透過即時鍵盤控制與文字提示，可動態改變環境中的天氣、照明、物件或事件
- Gemini 推理確保世界狀態的一致性與連貫性，適用於原型製作、空間設計、機器人訓練等應用
- 所有輸出均包含不可察覺的 SynthID 水印

## 結論
Genie 4 為開發者提供了強大的互動世界生成工具，可協助原型開發、空間概念視覺化及 AI 代理訓練，透過 Gemini API 輕鬆整合到開發流程中。
