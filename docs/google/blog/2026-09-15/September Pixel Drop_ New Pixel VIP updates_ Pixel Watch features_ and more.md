# September Pixel Drop: New Pixel VIP updates, Pixel Watch features, and more

- **來源**: Google Blog
- **發布日期**: 2026-09-15
- **原文連結**: https://blog.google/products-and-platforms/devices/pixel/september-2026-pixel-drop/

## 核心主題
Google Pixel 9 月更新帶來了多種新功能和改進，包括增強的 VIP 聯絡功能、Pixel Watch 新功能以及 Harry Potter 主題。

## 關鍵重點
- 更新的家庭螢幕小工具，可單擊呼叫或訊息 VIP，並使用底部浮動覆蓋導航菜單切換聯絡人
- Pixel Watch 獲得 Raise to Talk 改進和更多單手操作手勢應用程式整合
- 可立即使用 Harry Potter 音頻包慶祝《哈利·波特：全聲演播版》在 Audible 的發行，所有合格 Pixel 用戶將獲得兩個月 Audible 免費試用
- 增強的防詐騙功能，包括美國地區的 Gboard 內聯警告和更多地區的聊天應用程式通知詐騙檢測

## 結論
這次 September Pixel Drop 為 Pixel 用戶帶來了更便捷的聯絡管理、更智能的防詐騙功能以及有趣的 Harry Potter 主題體驗，同時 Pixel Watch 用戶也能獲得更多功能改進。
