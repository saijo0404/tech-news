# Build real-time voice applications with Gemini 3.8 Live and 3.5 Transcribe

- **來源**: Google Blog
- **發布日期**: 2026-09-15
- **原文連結**: https://blog.google/innovation-and-ai/technology/developers-tools/build-real-time-voice-applications-gemini-audio/

## 核心主題
Google 推出了新的 Gemini 音頻模型，讓開發者可以建立更智能的即時語音應用程式。

## 關鍵重點
- **Gemini 3.8 Live 和 3.8 Live Extended Thinking**：支援語音到語音的即時對話，具備深度推理能力，可執行任務同時維持對話流暢，在 Speech-to-Speech 排行榜上排名第一。
- **Gemini 3.5 Transcribe**：支援 85 多種語言的高精度語音轉文字，平均字詞錯誤率僅 4.0%（串流模式）和 2.6%（非串流模式），支援自動語碼切換和自訂詞彙偏置。
- **開發者友善**：透過 Gemini API 和 Google AI Studio 提供，價格合理（輸入$0.005/分鐘，輸出$0.018/分鐘），可透過 Agora、Fishjam、LiveKit 等多個第三方平台部署。

## 結論
這些新模型代表了一個重大進步，為開發者提供了更簡化的替代方案，無需使用串列架構即可建立智能語音代理，大幅提升了即時語音應用程式的開發體驗。
