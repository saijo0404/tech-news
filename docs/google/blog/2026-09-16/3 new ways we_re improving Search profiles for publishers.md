# 3 new ways we're improving Search profiles for publishers

- **來源**: Google Blog
- **發布日期**: 2026-09-16
- **原文連結**: https://blog.google/products-and-platforms/products/search/3-new-ways-were-improving-search-profiles-for-publishers/

## 核心主題
Google 推出 Search profiles 三大更新，幫助出版商更好地突出內容並與受眾建立連結。

## 關鍵重點
- **多帳號管理**：媒體組織可從單一登入管理所有子品牌的 Search profiles，無需切換多個帳號。
- **增強的文章檢視**：優化圖片縮圖與標題長度，提升文章可發現性與可讀性。
- **降低資格門檻**：美國出版商與創作者只需 10,000 追蹤者（YouTube、Instagram、X 或 TikTok）即可獲得 Search profiles 資格。

## 結論
這些更新讓出版商能更輕鬆地管理數位內容並擴大受眾觸及範圍，建議立即登入 Search profile 體驗新功能。
