# NOAA and Google Cloud collaborate to advance weather forecasting

- **來源**: Google Cloud blog
- **發布日期**: 2026-07-27
- **原文連結**: https://blog.google/innovation-and-ai/infrastructure-and-cloud/google-cloud/noaa-google-cloud-weather-forecasting/

## 核心主題
NOAA 與 Google Cloud 合作，將 NOAA 的超運算系統遷移至 Google Cloud，以大幅提升天氣預報的準確性與速度。

## 關鍵重點
- NOAA 選擇 Google Cloud 作為其 Weather and Climate Operational Supercomputing System (WCOSS) 的高性能計算 (HPC) 基礎設施提供商。
- 通過遷移至 Google Cloud 的 H4D 虛擬機器，NOAA 成為全球首批將運算數值天氣預測直接移至公有雲的大型氣象中心之一。
- 此次合作為氣象學家與研究者提供了前所未有的規模、速度和 AI 能力，可運行大規模模擬、改進預測模型並發出更快、挽救生命的早期預警。

## 結論
NOAA 與 Google Cloud 的合作標誌著氣象預報領域的重大突破，透過雲端高性能計算大幅提升天氣預報的準確性與速度，最終將挽救更多生命並保護基礎設施。
