# Get ready for the game with new football features in Search

- **來源**: Google Blog
- **發布日期**: 2026-09-09
- **原文連結**: https://blog.google/products-and-platforms/products/search/football-features-google-search/

## 核心主題
Google Search 推出了全新美式足球功能，包括即時遊戲直播、更深入的統計數據以及幻獸足球帳戶連結，讓球迷能更深入追蹤比賽。

## 關鍵重點
- **Live Game Feed**：搜尋進行中的比賽時，會出現紅色「Live」圖標，提供比賽摘要、動態時間軸、關鍵視頻亮點和 AI 驅動的即時洞察。專業美式足球功能已在美国 mobile 推出，本月將擴展至大學球隊及全球用戶。
- **更深入的統計數據**：搜尋比賽對決時，會出現新的輪播圖，可查看所有比賽的比分。新增聯賽領先者統計（如傳球達陣、衝球碼）及詳細球員指標（擒殺、失誤、衝球碼後碼等）。未來還將顯示冠軍預測和季后赛大綱。
- **幻獸足球帳戶連結**：可連結 Yahoo Fantasy 或 Sleeper 帳戶，透過 AI Mode 獲得客製化建議。無需手動輸入數據或截圖，即可獲得選項建議、 waiver wire 目標等。此功能目前在美国英语版可用。

## 結論
Google Search 透過這些新功能，將成為美式足球賽季的終極遊戲日指南，幫助球迷更深入追蹤比賽動態和幻獸足球選項。
