# Google Cloud introduces the Gemini agent.

- **來源**: Google Cloud blog
- **發布日期**: 2026-10-08
- **原文連結**: https://blog.google/innovation-and-ai/infrastructure-and-cloud/google-cloud/gemini-at-work/

## 核心主題
Google Cloud 推出了 Gemini agent，這是一個通用的工作代理，可以在單一提示框中完成從知識工作到編碼等各種任務。

## 關鍵重點
- Gemini 擁有組織的所有業務上下文，可以從單一提示框完成從知識工作到編碼等各種任務
- 它可以規劃工作、使用技能和工具、連接客戶的業務系統，並在他們已經工作的文檔、郵件箱和開發環境中返回完成的工作
- 它會為任務選擇最佳模型，具有內建的費用控制，最重要的是具有企業客戶所需的安保、管理和治理功能

## 結論
Gemini agent 是 Google Cloud 推出的通用工作代理，為企業客戶提供安全、可控的 AI 工作自動化解決方案。
