# Here's how to use sign-to-text translation on Pixel 11

- **來源**: Google Blog
- **發布日期**: 2026-08-21
- **原文連結**: https://blog.google/products-and-platforms/devices/pixel/american-sign-language-sign-to-text-pixel-11/

## 核心主題
Pixel 11 系列引入全新手語轉文字功能，與聽障社群合作開發，透過 AI 技術將美國手語 (ASL) 即時轉為英文文字。

## 關鍵重點
- 使用多語言手語轉文字 (SL2T) 模型，分析手勢、表情和肢體動作進行即時翻譯
- 支援單手和雙手手語，可與 Live Transcribe 或 Gboard 搭配使用
- 在 Pixel 11 上啟用此功能：將手語轉文字加入 Gboard 工具列，並對前置鏡頭進行手語，翻譯結果會顯示在外螢幕上

## 結論
Pixel 11 系列已上市銷售，使用者可透過 Google Store 購買並體驗這項創新功能，為聽障人士提供更便捷的溝通方式。
