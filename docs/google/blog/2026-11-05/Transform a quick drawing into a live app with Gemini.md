# Transform a quick drawing into a live app with Gemini

- **來源**: Google Blog
- **發布日期**: 2026-11-05
- **原文連結**: https://blog.google/innovation-and-ai/products/gemini-app/turn-drawings-into-apps-gemini/

## 核心主題
這篇文章介紹了如何使用 Gemini 將草圖轉化為互動式應用程式，讓靈感能迅速實現。

## 關鍵重點
- 上傳草圖照片（如應用程式原型、習慣追蹤器或遊戲板）到 Gemini
- 選擇 Canvas 工具並詢問 Gemini「Can you code this app?」，Gemini 會讀取視覺內容並撰寫代碼
- 在預覽視窗測試應用程式，Gemini 可即時調整顏色、字體或功能

## 結論
下次靈感出現時，不妨使用 Gemini 將其快速轉化為可運作的應用程式，讓創意不再停留在紙上。
