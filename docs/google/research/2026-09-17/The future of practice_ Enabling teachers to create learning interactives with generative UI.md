# The future of practice: Enabling teachers to create learning interactives with generative UI

- **來源**: Google Research Blog
- **發布日期**: 2026-09-17
- **原文連結**: https://research.google/blog/the-future-of-practice-enabling-teachers-to-create-learning-interactives-with-generative-ui/

## 核心主題
Google 研究團隊開發了利用生成式 UI (GenUI) 讓教師能為每位學生量身打造互動式學習模擬實驗，填補傳統數位學習被動體驗的缺口。

## 關鍵重點
- 教師可透過生成式 AI 快速為特定課程主題和學生需求，客製化創建互動式學習模擬實驗，解決傳統教學工具無法因材施教的問題
- 學習互動式涵蓋 STEM 領域（物理、化學、生物、數學），包含逐步挑戰、即時指導和工具箱，促進學生主動探索與批判性思考
- 採用主動學習原則與遊戲化設計，透過漸進式難度挑戰和情境化提示，幫助學生建立完整的知識模型
- 系統內建自訂驗證循環，確保教學原則、功能性和視覺設計符合教育標準，所有內容均由教師審核
- 透過 Google for Education Pilot Program 讓學校參與測試，持續收集反饋以改進學習互動式品質

## 結論
這項研究展示了生成式 AI 如何填補互動式學習工具的缺口，使教育更貼近主動學習科學原則，並為未來擴展更多學習互動式奠定基礎。
