# GlucoFM: Foundation model for continuous glucose monitoring

- **來源**: Google Research Blog
- **發布日期**: 2026-08-26
- **原文連結**: https://research.google/blog/glucofm-foundation-model-for-continuous-glucose-monitoring/

## 核心主題
GlucoFM 是一個輕量級的自監督連續血糖監測(CGM)基礎模型，通過雙流設計分別建模較慢的血糖趨勢和短期波動，為多種代謝預測任務設定新的性能標準。

## 關鍵重點
- **雙流架構設計**：GlucoFM 採用獨特的雙流設計，將較慢的血糖趨勢與短期波動（如進食、活動或傳感器誤差）分開處理，比單一表示流的現有模型更準確。
- **自監督預訓練**：在109,066小時未標記CGM數據上進行預訓練，使用潛在預測目標學習每日上下文和時間演化，無需大量標記數據。
- **臨床任務表現優異**：在四個族群、七項臨床預測任務（包括糖尿病風險、胰島素抵抗、β細胞功能等）上評估，平均PR-AUC比最佳GluFormer變體高5.8個百分點。
- **跨族群轉移能力強**：在跨數據集轉移測試中，GlucoFM在11次評估中表現優於第二強模型，證明其能捕捉通用代謝模式而非族群特定噪音。
- **少樣本適應能力突出**：在標記數據極度有限的少樣本設定下仍保持最佳性能，特別適合醫療數據標記成本高的場景。
- **後餐血糖預測精度最高**：在後餐血糖反應預測任務中，GlucoFM達到最低平均絕對誤差(MAE) 21.88 mg/dL，優於其他模型。

## 結論
GlucoFM 通過學習可重用的代謝模式，使有限的標記臨床數據得到更好利用，為糖尿病風險評估、胰島素抵抗預測等醫療應用提供新的工具。未來研究將擴展到更大、更多樣的族群，並探索跨週期趨勢的建模能力。
