# AgentHands: Generating interactive hand gestures for spatially grounded agent conversations in XR

- **來源**: Google Research Blog
- **發布日期**: 2026-08-25
- **原文連結**: https://research.google/blog/agenthands-generating-interactive-hand-gestures-for-spatially-grounded-agent-conversations-in-xr/

## 核心主題
AgentHands 是一個基於 LLM 的 XR 原型，通過同步的互動手勢增強對話式代理，提供空間定位指導，縮小心理映射差距並增強用戶在物理任務中的參與度。

## 關鍵重點
- **手勢分類系統**：建立了六維度分類法，涵蓋手性、手勢形式、空間性、時間動態、互動性和視覺效果，用於定義代理在 3D 環境中如何使用手勢
- **物件註冊與手勢庫**：系統使用眼動追蹤和場景重建快速註冊物件，建立包含指示性、具象性和表達性三類手勢行為的庫
- **同步 XR 執行**：本地解析器協調文本轉語音播放與動畫引擎，使用字級時間戳記使代理的手勢與說話完美同步
- **應用場景驗證**：在蘭花護理和 3D 列印操作等場景中，空間手勢顯著提升了物件定位、動作理解和安全提示的顯著性

## 結論
AgentHands 代表了 AI 系統不僅分析我們的環境，而且動態在其中運作的未來的一步。通過利用共語手勢和 XR 的空間力量將對話扎根於物理運動，我們可以減少複雜任務的认知負荷，使空間計算更具可訪問性和以人為本。
