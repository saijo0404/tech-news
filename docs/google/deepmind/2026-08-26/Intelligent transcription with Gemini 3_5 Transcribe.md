# Intelligent transcription with Gemini 3.5 Transcribe

- **來源**: DeepMind
- **發布日期**: 2026-08-26
- **原文連結**: https://deepmind.google/blog/intelligent-transcription-with-gemini-3-5-transcribe/

## 核心主題
Gemini 3.5 Transcribe 是 Google 最新推出的精準語音轉文字模型，能將原始音訊直接轉換為準確、經過潤飾且格式化的文字，並支援多語言與即時轉錄。

## 關鍵重點
- **精準度提升**：相比前代模型 Chirp 3，最終轉錄時間提升 70%，語音錯誤率（WER）平均為 4.0%（即時）和 2.6%（非即時），能準確識別郵政編碼、訂單編號等數字實體。
- **智能轉錄功能**：自動處理自我修正（如「我們週二見—不，週三」）、移除填充詞（「呃」和「啊」）、自動格式化文字，並支援自訂詞彙以識別專業術語。
- **多語言與多說話者識別**：支援超過 85 種語言，能自動檢測並轉錄不同口音與方言；可準確歸屬最多三位的說話者並提供字級時間戳記。
- **開發者整合**：透過 Gemini API（Live API 與 Interactions API）提供即時串流與預錄音訊處理，開發者可輕鬆整合至語音代理、即時字幕工具或通話分析管道。
- **跨產品應用**：已在 Gemini macOS 應用程式、Android 的 Rambler 功能、Google Antigravity 等場景中應用，支援語令控制、文件分析與圖片生成。

## 結論
Gemini 3.5 Transcribe 代表語音識別技術的重大突破，透過更精準的轉錄、更低的延遲與更廣泛的應用場景，為開發者與終端用戶帶來更自然、高效的語音互動體驗。
