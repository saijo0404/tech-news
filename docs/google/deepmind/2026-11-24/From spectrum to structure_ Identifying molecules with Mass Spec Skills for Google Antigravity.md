# From spectrum to structure: Identifying molecules with Mass Spec Skills for Google Antigravity

- **來源**: Google DeepMind
- **發布日期**: 2026-11-25
- **原文連結**: https://deepmind.google/blog/interpreting-mass-spectra-with-google-antigravity/

## 核心主題
Google DeepMind 與 Google Antigravity 合作推出 Mass Spec Skills，協助科學家解讀串聯質譜（MS/MS）並識別分子結構，解決傳統方法僅能標註約 5% 質譜數據的痛點。

## 關鍵重點
- **準確率大幅提升**：無技能時準確率<4%，加入 Mass Spec Skills 後準確率提升至約 97%
- **效率顯著提升**：使用 Mass Spec Skills 可大幅減少 token 消耗（Flash 減少近 4 倍、Argon 減少一半、Carbon 減少近 1/5）
- **功能強大**：自動解讀質譜數據、查詢公共化學資料庫（如 PubChem、GNPS、MoNA）、運行已驗證的質譜分析工具、生成可驗證的報告
- **準確性高**：複雜分子結構預測準確率超過 90%
- **應用廣泛**：可加速藥物發現流程、代謝組學研究，協助識別未知小分子，應用於健康、環境科學及天然產物發現

## 結論
Mass Spec Skills 結合 Gemini 語言模型推理能力與專業化學工具，實現從原始質譜到完整結構解析的全流程自動化，大幅降低科學家使用複雜工具的門檻，將原本需數天至數月的分析縮短至數小時。
