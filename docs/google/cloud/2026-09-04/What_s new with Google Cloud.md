# What's New with Google Cloud

- **來源**: Google Cloud Blog
- **發布日期**: 2026-09-04
- **原文連結**: https://cloud.google.com/blog/topics/inside-google-cloud/whats-new-google-cloud/

## 核心主題
Google Cloud 近期在 AI 代理平台、雲端基礎設施、資料處理與安全治理方面推出多项重大更新，協助組織應對 AI 安全挑戰並提升效能。

## 關鍵重點
- **AI 代理平台更新**：VM Extension Manager 正式一般可用，支援宣告式政策與自動修復；Claude Fable 5.1 與 Grok 4.6 在 Agent Platform 上推出；Apigee AI Gateway 提供企業 AI 流量集中治理
- **資料與資料庫增強**：BigQuery 連續查詢支援狀態處理（JOIN、聚合、窗口函數）；Database Migration Service 整合 Gemini 輔助 PostgreSQL 遷移；Kafka 管理服務推出合成資料生成器工具
- **效能優化**：Dataflow 管道支援停止替換與平行遷移；Compute Flex CUDs 可用於 G2/G4 GPU VM；Rapid Bucket 提升 PyTorch 訓練效能達 5 倍
- **安全與治理強化**：推出 Agent Identity 治理與可驗證加密身份；Apigee 新增 ParsePayload 政策強化代理工具安全；強化 AI 代理安全，實施零信任架構
- **Apigee MCP 正式上線**：可將企業 API 轉化為 AI 工具，支援 OpenAPI v3 原生規範
- **Gemini 模型更新**：Gemini 3.1 Flash-Lite（最快、成本效益最高）與 Gemini 3.1 Pro（更強大的複雜問題解決能力）推出
- **雲端工具擴展**：VS Code 新增 Google Cloud Workbench Notebooks 擴展；Cloud Run Worker Pools 支援非 HTTP 工作負載
- **合規與自動化**：合規性自動化工具減少 RTF 風險；設備授權機制支援無鍵盤/瀏覽器裝置
- **多場技術活動**：All Things Agentic Hackathon、Apigee AI Horizon 活動、多場 Community TechTalk 涵蓋 AI 治理、MCP、Apigee 上線指南等主題

## 結論
Google Cloud 持續強化 AI 代理平台、雲端基礎設施與安全治理能力，提供全面的解決方案以協助組織應對 AI 安全挑戰並提升效能。產業正轉向流式計算、集中治理和統一協同架構，建議採用 Prompts-as-Code 架構將提示視為軟體資產。
