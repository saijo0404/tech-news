# From weeks to minutes: The new agentic era of data pipelines

- **來源**: Google Cloud Blog
- **發布日期**: 2026-09-01
- **原文連結**: https://cloud.google.com/blog/products/data-analytics/build-data-pipelines-in-less-time-with-data-agent-kit/

## 核心主題
Google Cloud 推出 Data Agent Kit，讓數據工程師能用自然語言快速構建和維護數據管道，大幅減少開發時間。

## 關鍵重點
- Data Agent Kit 是一個可免費使用的開源工具集，可整合到 VS Code 等 IDE 中，提供數據工程標籤頁和專用的代理技能
- 使用 declarative YAML DSL 替代複雜的 Python 代碼，讓數據科學家也能構建 Apache Airflow DAG
- 通過三個示例管道展示完整的 MLOps 工作流：訓練、推理和評估，實現自動化、自修復的數據管道
- 提供實時監控和智能故障診斷功能，當管道失敗時自動分析錯誤並建議修復方案

## 結論
這種代理化的方法讓數據團隊可以將更多時間花在業務價值上，而不是基礎設施代碼上，真正實現了從數周到分鐘的效率提升。
