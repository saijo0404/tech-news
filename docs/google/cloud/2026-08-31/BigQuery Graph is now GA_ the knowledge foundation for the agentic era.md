# BigQuery Graph is now GA: the knowledge foundation for the agentic era

- **來源**: Google Cloud Blog
- **發布日期**: 2026-09-01
- **原文連結**: https://cloud.google.com/blog/products/data-analytics/bigquery-graph-connecting-data-and-ai-at-scale/

## 核心主題
BigQuery Graph 正式一般化發布，將圖計算能力直接整合到數據倉儲中，為 AI 代理提供知識基礎。

## 關鍵重點
- **大規模圖分析與 AI 代理整合**：BigQuery Graph 提供 ISO 標準的 GQL 語言，與 SQL 並存，無需 ETL 即可進行圖遍歷分析，支援 PB 級數據處理。
- **跨雲邊界圖湖倉**：單一 BigQuery Graph 可跨 Google Cloud、AWS、Databricks 等多雲環境，無需數據移動即可進行跨雲遍歷，實現「Borderless graph Lakehouse」。
- **AI 代理可構建、聊天並記錄可審計的記憶**：AI 代理可直接與圖聊天，並通過 BigQuery Agent Analytics 記錄可審計的決策記憶，實現可解釋的自主系統。

## 結論
BigQuery Graph 通過將圖計算能力直接整合到數據倉儲中，消除了數據孤島和運營 overhead，為 AI 代理提供可擴展的知識基礎，使企業能夠處理複雜的多跳分析問題。
