# What's new in AI infrastructure and orchestration in August

- **來源**: Google Cloud Blog
- **發布日期**: 2026-09-01
- **原文連結**: https://cloud.google.com/blog/topics/ai-infrastructure/whats-new-in-ai-infrastructure-this-month/

## 核心主題
Google Cloud 八月 AI 基礎設施更新，涵蓋儲存、運算、架構與客戶案例

## 關鍵重點
- Filestore 新增 Colossus 後端，支援 AI 代理群組高效存取，可獨立配置 IOPS 與儲存容量
- gVisor 沙盒支援 Ray 集群，提供比一般容器更强的隔離性，快啟動與低記憶體佔用
- Cloud Run 單人實例，30 天僅 $5.70，適合個人 AI 代理低成本部署
- MCP 協議核心改為完全無狀態，移除握手機制，每個請求獨立自描述
- UiPath 架構調整至共享 GPU fleet，Mirendil 使用 AI Hypercomputer 加速模型訓練
- Replenit 利用 Gemini Enterprise Agent Platform 與 Cloud TPU，降低 90% 管道成本
- GKE 支援 15,000 節點集群，支援網路策略強制執行
- k8s-aibom 開源工具，自動檢測 AI 運時並生成 ML-BOM 清單

## 結論
Google Cloud 八月持續強化 AI 基礎設施，提供成本效益與性能優化的解決方案，涵蓋儲存、運算、架構與安全工具，幫助客戶降低 AI 部署成本並提升效能。
