# Strengthen your CI/CD pipeline with new Secure Source Manager capabilities

- **來源**: Google Cloud Blog Security & Identity
- **發布日期**: 2026-09-22
- **原文連結**: https://cloud.google.com/blog/products/identity-security/strengthen-your-cicd-pipeline-with-new-secure-source-manager-capabilities/

## 核心主題
Google Cloud Secure Source Manager (SSM) 推出新功能以加強 CI/CD 管道安全性，包括防止未授權存取和更細粒度的程式碼所有權管理。

## 關鍵重點
- **防止未授權存取 CI/CD 系統**：即使企業網路已被入侵，SSM 也能從版本控制系統到部署工具全面阻擋未授權存取，降低軟體供應鏈攻擊風險。
- **新增 Code Owners 系統**：提供按檔案和分支的細粒度存取控制，允許工程師更精確地管理程式碼所有權，並支援多部門獨立批准機制。
- **支援可巢狀的多檔案所有權**：不再受單一巨型檔案限制，可將 CODEOWNERS 檔案巢狀儲存於子目錄，讓子團隊擁有其資料夾同時保留根管理員的否決權。
- **Developer Connect 整合**：讓 CI/CD 系統與運算環境即使在不同私有網路間也能安全連接，透過 VPC 服務控制提供深度防禦。

## 結論
這些新功能幫助開發者更安全地管理 CI/CD 工作流，透過更精細的存取控制和網路整合，有效降低現代軟體供應鏈面臨的威脅。
