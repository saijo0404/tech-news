# Introducing object enrichments: Transform unstructured data into agent-ready context

- **來源**: Google Cloud Blog
- **發布日期**: 2026-11-20
- **原文連結**: https://cloud.google.com/blog/products/storage-data-transfer/cost-effective-ai-context-extraction-from-unstructured-gcs-data/

## 核心主題
Google Cloud 推出「object enrichments」新功能，利用 AI 模型自動從雲端儲存物件中提取豐富上下文元數據，使 AI 代理能更有效地處理非結構化企業數據。

## 關鍵重點
- **大幅降低成本**: 使用 Google 自有 AI 模型進行圖像標註和 PDF 分類，相比其他雲端服務節省 75% 成本，處理 1000 萬張圖片僅需 $700。
- **無需自管管道**: 只需三步驟即可設定（定義範圍、選擇模型、授予權限），無需編碼，Google 自動處理推理、解析和儲存。
- **上下文與數據同存**: 元數據直接寫入物件上下文（object context），與原始數據一同儲存，避免分散的元數據管理問題。
- **支援多模態推理**: 可與 Gemini 原生整合，支援摘要、實體提取、轉錄、翻譯等進階功能。

## 結論
object enrichments 讓企業能以更低成本、更簡單方式將非結構化數據轉化為 AI 代理可用的豐富上下文，解決了傳統方案中成本高、操作繁瑣和元數據分散的三大痛點。
