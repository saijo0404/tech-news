# What's New with Google Cloud

- **來源**: Google Cloud Blog
- **發布日期**: 2026-11-19
- **原文連結**: https://cloud.google.com/blog/topics/inside-google-cloud/whats-new-google-cloud/

## 核心主題
Google Cloud 於 2025-2026 年推出大量 AI 基礎設施與雲端運算更新，重點聚焦自主代理開發、模型擴展、安全治理與成本優化。

## 關鍵重點
- **AI Agent 開發**：推出 AI Agent Clinic 課程、延遲服務層級降低成本 50%、支援 Gemini 4 系列模型及 OpenTelemetry 標準化追蹤
- **模型擴展**：新增 Claude Fable 5.2、Meta Muse 系列模型、Claude Sonnet 5.5 及 Gemini 3.1 Pro/Flash-Lite
- **安全治理**：SentinelOne 合作、Apigee 三層 LLM 防護、零站立特權 PAM、Model Armor 防提示注入
- **成本優化**：Apigee X 動態路由節省 70%、Gemini 平台轉發享 50% 折扣、Resource-Based CUD Sharing 預設啟用
- **基礎設施**：A5X 加速、AlloyDB Omni Web UI、Storage Intelligence Advisor、Cloud Location Finder
- **Apigee 更新**：Trace Viewer、Local Emulator、MCP 正式支援、Excel-to-API 轉換功能
- **資料庫遷移**：DMS 新增 Gemini AI 輔助程式碼轉換、SAP BDC Connect for BigQuery
- **GPU 優化**：Compute Flex CUDs 支援 G2/G4 VM、Fractional G4 VM 提供 GPU 切片
- **PyTorch 優化**：GCSFS 2026.8.0 提升訓練效能 5 倍、Run:ai Model Streamer 加速載入 2 倍以上
- **雲端服務**：Dataflow Job Builder、Bigtable Subscriptions、Managed Kafka、Cloud Run Worker Pools
- **開發者工具**：ADK、MCP 授權治理工具、Apigee Migration Assessment Tool、VS Code 擴展
- **活動資訊**：All Things Agentic Hackathon（獎金$19 萬）、多場技術講座（4-10 月）
- **AI 投資回報**：僅 5% 自訂 AI 投資帶來可衡量業務價值，關鍵在於組織架構調整
- **AI Agent 優化**：OpenTelemetry 追蹤降低延遲 80%、多租用戶 AI 系統防止資料洩漏

## 結論
Google Cloud 持續強化 AI 基礎設施與雲端運算能力，透過 AI Agent 開發、模型擴展、安全治理與成本優化四大方向，協助企業提升 AI 投資回報率。建議企業採用微代理架構、Zero-Trust 安全與 EvalOps 策略導入 Gemini，並利用 Apigee AI 閘道集中治理 AI 流量。
