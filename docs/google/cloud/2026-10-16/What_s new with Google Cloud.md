# What's new with Google Cloud

- **來源**: Google Cloud Blog
- **發布日期**: 2026-10-17
- **原文連結**: https://cloud.google.com/blog/topics/inside-google-cloud/whats-new-google-cloud/

## 核心主題
Google Cloud 最新更新重點，涵蓋 AI 模型、Apigee 功能、儲存與管理工具等

## 關鍵重點
- **AI 模型更新**：Claude Sonnet 5.5、Opus 5.5、Fable 5.1 陸續推出，強化編碼、研究與分析能力，提供企業級安全與治理功能
- **成本優化**：Apigee X 動態路由可節省 70% Gen AI 成本，根據請求複雜度自動路由至輕量或進階模型
- **儲存與管理**：Storage Intelligence Advisor 正式通用，自動檢測異常並提供建議；Dataflow Job Builder 支援 Delta Lake 表格導入；Managed Kafka 支援公共互聯網集群
- **Apigee 功能擴展**：支援 Apigee X 與 Cloud Run 的私有 WebSocket 連接；新增 Apigee Trace Viewer 與本地模擬器測試工具；支援 Apigee 遷移評估工具
- **AI 代理與治理**：AI Agent Clinic 推出實作課程，標準化多回合追蹤；推出 MCP 工具授權與代理治理解決方案；Agentic Data Cloud 提供信任基礎與即時上下文
- **資料庫與服務**：AlloyDB Omni Red Hat RPM Orchestrator 正式通用；Bigtable 訂閱功能支援零 ETL 數據傳輸；VM Extension Manager 正式通用，簡化虛擬機軟體生命週期管理

## 結論
Google Cloud 持續強化 AI 治理、安全與成本優化，推動企業級 AI 部署，同時提供完善的 API 管理與儲存解決方案。
