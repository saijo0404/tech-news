# Announcing Wiz Runtime Sensor add-on for GKE: Turnkey threat detection for Kubernetes

- **來源**: Google Cloud Blog
- **發布日期**: 2026-10-17
- **原文連結**: https://cloud.google.com/blog/products/identity-security/wiz-sensor-for-gke-turnkey-threat-detection-for-kubernetes/

## 核心主題
Google Cloud 推出 Wiz Runtime Sensor 加載模組，為 GKE 提供即開即用的 Kubernetes 實時威脅檢測功能。

## 關鍵重點
- 作為 GKE 的一等公民管理平台加載模組，提供低接觸式部署和自動化生命週期管理
- 原生整合 Secret Manager，安全地管理 Wiz API 金鑰，避免分散式管理風險
- 支援 fleet-wide 治理，可透過組織策略強制所有集群啟用此功能
- 提供核心級可觀測性，監控系統呼叫、進程、網路連線和檔案存取，同時保持低 CPU 使用率
- 獨立自動更新，無需 GKE 版本升級或節點池重新創建即可獲得最新檢測規則

## 結論
此整合結合了 GKE 的自動化平台功能與 Wiz 的全面安全智能，使平台和安全團隊能夠在雲端速度下創新，同時保持強大的實時防護。
