# Google Cloud expands model choice and flexibility, bringing OpenAI models to customers

- **來源**: Google Cloud Blog
- **發布日期**: 2026-10-22
- **原文連結**: https://cloud.google.com/blog/products/ai-machine-learning/google-cloud-brings-openai-models-to-customers/

## 核心主題
Google Cloud 現在是唯一提供所有三大主流閉源大語言模型（包括 OpenAI 模型）的超大型雲端供應商，讓企業可以根據不同工作負載選擇最適合的模型。

## 關鍵重點
- Google Cloud 現在提供 GPT-6 Astra、GPT-6.1 Sol 和 GPT-6 Luna 三款 OpenAI 模型，讓企業可以根據工作負載選擇最適合的模型
- 所有 OpenAI 模型通過 Google Cloud Marketplace 交易，使用費單統一計入 Google Cloud 帳單，並可應用到 Flexible Savings Plans
- 提供嚴格的企業級數據治理和安全性，包括嚴格數據邊界、隔離訪問邊界和統一審計身份管理
- 目前這些模型在 private preview 中向選定企業客戶開放，未來將擴展到 Gemini for business 和 Google Antigravity

## 結論
Google Cloud 通過整合 OpenAI 模型，為企業提供了更靈活的模型選擇和更強大的企業級安全合規能力，幫助企業更高效地利用 AI。
