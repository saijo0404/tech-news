# Chrome Enterprise brings more protections to healthcare technologies

- **來源**: Google Cloud Blog
- **發布日期**: 2026-11-13
- **原文連結**: https://cloud.google.com/blog/products/chrome-enterprise/chrome-enterprise-brings-more-protections-to-healthcare-technologies/

## 核心主題
Google 推出 Chrome Enterprise Premium，為醫療技術提供更強大的保護，使醫療組織能在採用 AI 工具的同時保障患者資料安全。

## 關鍵重點
- **強化資料防洩漏控制**：先進的 DLP 控制限制未經授權的複製、貼上、表單提交、列印和螢幕擷取，防止患者資料洩漏到未獲批准的 AI 提示或瀏覽器擴充套件中。
- **完整的操作可見性**：提供瀏覽器活動、擴充套件使用和資料轉移的詳細報告，幫助保安團隊發現陰影 AI 並維持內部監督。
- **一致管理擴充套件和網頁 AI**：保安政策和擴充套件控制直接應用於瀏覽器層，IT 團隊可以管理權限、阻擋有風險的擴充套件，並對每個 AI 服務強制執行防護措施，無需額外的工具。
- **相容 IGEL OS 和 Citrix UniconOS 終端**：Chrome Enterprise 現在與 IGEL OS 相容，並即將在 IGEL Marketplace 上提供，允許醫療 IT 輕鬆部署和管理瀏覽器。
- **優化 Epic 工作流程**：支援靜默列印和 Epic Hyperspace for the web 的 PDF 更新，讓醫療人員將必要命令和腕帶直接路由到授權的列印機，同時保持受保護的健康資訊嚴格隔離在活躍的管理會話中。

## 結論
Chrome Enterprise 為醫療組織提供統一的保安、資料防洩漏 (DLP) 和治理層面，使 IT 和保安團隊有信心採用現代醫療技術，同時支持患者護理體驗，不會犧牲關鍵的保護和控制。
