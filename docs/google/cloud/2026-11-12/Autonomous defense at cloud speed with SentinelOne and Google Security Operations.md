# Autonomous defense at cloud speed with SentinelOne and Google Security Operations

- **來源**: Google Cloud Blog
- **發布日期**: 2026-11-13
- **原文連結**: https://cloud.google.com/blog/topics/partners/autonomous-defense-at-cloud-speed-with-sentinelone-and-google-security-operations/

## 核心主題
Google Cloud 與 SentinelOne 合作，透過重新架構的整合技術，實現端點遥測數據的直接 API 傳輸，大幅降低延遲並降低成本。

## 關鍵重點
- **直接 API 傳輸取代中間儲存**：SentinelOne 直接透過 Google API 傳輸事件，消除中間雲端儲存跳躍，減少儲存費用並降低延遲
- **現代化 EDR 數據結構**：大幅縮小平均事件大小，保留完整分析忠實度，減少下游計算工作負載
- **與 Mandiant 合作開發統一警報 API**：支援自動化主機隔離、全盤深度可見性掃描、惡意軟體提取和藝術品豐富化
- **即時數據可用性**：移除中間雲端儲存需求，使數據可在 Google Security Operations 中近乎即時用於檢測、調查和代理工作流
- **成本與預算優化**：減少總擁有成本，避免資源浪費在未優化的遥測數據上

## 結論
現代防禦需要直接行動而非延遲傳輸。透過消除不必要的中間層並直接透過 API 傳輸，安全團隊可以獲得足夠的速度來超越現代威脅，同時保護預算。
