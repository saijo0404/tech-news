# AI-powered cloud governance: What's new in Organization Policy

- **來源**: Google Cloud Blog Security & Identity
- **發布日期**: 2026-11-13
- **原文連結**: https://cloud.google.com/blog/products/identity-security/ai-powered-cloud-governance-whats-new-in-organization-policy/

## 核心主題
Google Cloud 推出 Organization Policy Model Context Protocol (MCP) 伺服器，讓 AI 代理能自動管理組織策略，簡化雲端治理。

## 關鍵重點
- Organization Policy MCP 伺服器讓 AI 代理能直接與組織策略互動，支援 posture audits、drift detection 和 exemption management，無需手動解析複雜的階層鏈。
- 支援自然語言約束撰寫，透過 Gemini 讓管理員可以用自然語言撰寫自訂組織策略，例如要求 Agent Runtime 使用特定身份或防止停用自動升級。
- 提供超過 100 個預定義策略，並支援自訂組織策略，可針對特定需求設定邊界，並提供符合性測試資源配置以驗證策略。

## 結論
Organization Policy 提供主動式雲端治理，讓企業能安全擴展並建立基礎防護措施，同時讓工程團隊快速安全地建構和部署。
