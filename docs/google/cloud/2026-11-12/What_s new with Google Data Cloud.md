# What's new with Google Data Cloud

- **來源**: Google Cloud Blog
- **發布日期**: 2026-11-13
- **原文連結**: https://cloud.google.com/blog/products/data-analytics/whats-new-with-google-data-cloud/

## 核心主題
Google Data Cloud 近期推出多项数据分析与 AI 整合新功能，强化企业数据管理、查询与分析能力，并分享多个客户成功案例。

## 關鍵重點
- **Data Cloud connectors 在 Gemini 中預覽**：支援自然語言查詢企業資料，無需資料移動，可連接 BigQuery、Looker、Spanner 等資料來源
- **AlloyDB for PostgreSQL 更新**：支援直接查詢 Cloud Storage 中的 Apache Iceberg 表格，推出 AlloyDB Express 輕量級開發環境，新增 AI 調優 SQL 函數
- **BigQuery 新功能**：資料代理可視化功能一般化、支援 Apache Iceberg 管理表格變更歷史、新增 AI.TRANSLATE 和 AI.CHUNK_DOCUMENT 函數
- **Cloud Spanner 更新**：支援 ON DELETE SET NULL 外鍵動作、近似聚合函數加速大規模分析查詢
- **Knowledge Catalog 增強**：LookML 元數據索引一般化、新增 Knowledge Studio、接地氣 AI 代理準確度提升 4 倍
- **客戶案例**：Carwow、Best Buy、Myer、Unico 等客戶已採用相關功能，Unico 透過整合防止超過 50 億美元詐騙損失
- **Data Agent Kit 一般可用**：支援從 VS Code、Cursor 等編輯器建立端到端資料科學管道
- **Gartner 報告**：Google 被評為數據湖倉平台魔力象限中「最遠見」企業

## 結論
Google Data Cloud 持續擴展其數據分析、AI 整合與客戶案例，提供全面的數據管理解決方案，幫助企業實現單一數據來源真相與自服務分析能力。
