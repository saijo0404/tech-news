# Simplifying last mile cloud connectivity with Lumen and partner Cross-Cloud Interconnect

- **來源**: Google Cloud Blog
- **發布日期**: 2026-11-13
- **原文連結**: https://cloud.google.com/blog/products/networking/partner-cross-cloud-interconnect-for-last-mile-delivered-by-lumen/

## 核心主題
Google Cloud 推出「Partner Cross-Cloud Interconnect for last mile」服務，與 Lumen Technologies 合作，簡化企業將私人雲端、數據中心與其他雲端環境與 Google Cloud 連接的複雜性。

## 關鍵重點
- 提供分鐘內即可建立的 Layer 3 私人連接，取代傳統需要數週或數月的複雜配置流程
- 支援 1 到 50 Gbps 的彈性連接速度，適用於公共雲端、私人雲端、AI neoclouds 和上雲地點
- 採用開放式 API 規格，讓網路團隊可使用單一運維手冊管理多雲端連接，並具備預置冗餘路由器、協調維護和線速 MACsec 加密等特性

## 結論
這項服務是企業實現更靈活性、雲端化網路體驗的重要一步，特別適合需要擴展至私人雲端、neoclouds、數據中心等多雲端環境的場景。
