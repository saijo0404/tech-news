# Introducing the Google Cloud Developer Plugin for AI Coding Agents

- **來源**: Google Cloud Blog
- **發布日期**: 2026-09-11
- **原文連結**: https://cloud.google.com/blog/topics/developers-practitioners/introducing-the-google-cloud-developer-plugin-for-ai-coding-agents/

## 核心主題
Google Cloud 推出了新的開發者插件，讓 AI 編碼代理更容易與 Google Cloud 互動，解決工具耦合問題。

## 關鍵重點
- 插件是安裝包形式，為 AI 代理提供 Google Cloud 相關的技能和工具，使 AI 代理在 Google Cloud 上更有效率
- 基於開源標準（Agent Plugins specification），確保跨平台一致性，無需為每個 AI 助手維護不同的配置
- 主要插件 google-cloud-developer 包含身份驗證、授權、項目管理等功能，並包含 Developer Knowledge MCP server 配置
- 支持多種 AI 工具（Antigravity CLI、Claude Code、Codex CLI）的安裝方式，安裝過程簡單直觀

## 結論
這是一個重要的進展，讓 AI 編碼代理能更輕鬆地與 Google Cloud 集成，並提供標準化的插件生態系統，幫助開發者成功使用 Google Cloud 服務。
