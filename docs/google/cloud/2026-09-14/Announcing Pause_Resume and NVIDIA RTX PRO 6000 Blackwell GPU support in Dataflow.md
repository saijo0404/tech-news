# Announcing Pause/Resume and NVIDIA RTX PRO 6000 Blackwell GPU support in Dataflow

- **來源**: Google Cloud Blog Data Analytics
- **發布日期**: 2026-09-15
- **原文連結**: https://cloud.google.com/blog/products/data-analytics/new-dataflow-features-to-enable-large-scale-ai-workloads/

## 核心主題
Google Cloud Dataflow 推出兩項重大新功能：Pause/Resume 功能與 NVIDIA RTX PRO 6000 Blackwell GPU 支援，以優化 AI 工作負載並提升計算效率。

## 關鍵重點
- **Pause/Resume 功能**：允許使用者暫停和恢復 Dataflow 批次工作，避免重新開始失敗的工作，大幅減少資源浪費並提高開發者生產力。
- **NVIDIA RTX PRO 6000 Blackwell GPU 支援**：支援 G4 VM，提供 96GB vGPU 記憶體和 1.6 TB/s 頻寬，可運行 70B+ 參數模型，顯著提升 AI 推理性能。
- **成本優化與效率提升**：透過動態重新分配加速計算資源，優化批次工作成本，同時運行高要求的 AI 工作負載，無需管理底層基礎設施。

## 結論
這兩項新功能共同幫助企業優化批次工作成本，同時運行高要求的 AI 工作負載，加速 AI 開發週期並提升整體效率。
