# Agent-ready analytics: Unlocking insights with BigQuery augmented analytics

- **來源**: Google Cloud Blog Data Analytics
- **發布日期**: 2026-09-15
- **原文連結**: https://cloud.google.com/blog/products/data-analytics/bigquery-augmented-analytics-tvfs/

## 核心主題
BigQuery 推出了六項增強分析表值函數（TVFs），結合 AI、機器學習和統計方法來自動化洞察發現和模式解釋。

## 關鍵重點
- **AI.KEY_DRIVERS**：識別指標增加或減少的主要驅動因素，例如回答「為什麼本季度營收比上季激增？」
- **AI.CAUSAL_EFFECT**：量化行動或事件的影響，將觀察結果與預期基準比較，例如「營收提升有多少來自定價更新而非自然增長？」
- **ML.CORRELATION**：評估數值指標之間關係的方向和強度，例如「用戶會話時間增加是否與終身客戶價值提高相關？」
- **ML.DETECT_CHANGE_POINTS**：識別指標經歷結構性轉變的特定日期或時間段，例如「平台延遲在哪些時間段經歷持續的結構性轉變？」
- **ML.TREND**：將基本趨勢與短期波動或噪音分離，例如「過去一年營收的基本趨勢是什麼？」
- **ML.SEASONALITY**：發現可預測的重複週期，例如「哪些天數每週 consistently 經歷最高伺服器負載？」

## 結論
這些函數不僅可以串聯使用，還能直接整合到 AI 代理的技能中，實現自動化、對話式數據調查工作流，大幅加速分析並減少數據導出需求。
