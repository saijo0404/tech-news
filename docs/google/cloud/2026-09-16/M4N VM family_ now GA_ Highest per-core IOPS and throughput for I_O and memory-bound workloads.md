# M4N VM family, now GA: Highest per-core IOPS and throughput for I/O and memory-bound workloads

- **來源**: Google Cloud Blog
- **發布日期**: 2026-09-17
- **原文連結**: https://cloud.google.com/blog/products/compute/compute-engine-m4n-vms/

## 核心主題
Google Cloud 正式推出 M4N VM 系列，專為高 I/O 和高記憶體工作負載設計，提供業界最高的每核心 IOPS 和吞吐量，並可為 Oracle 資料庫降低超過 20% 的 TCO。

## 關鍵重點
- M4N 提供高達 26.57 GB/vCPU 的記憶體核心比，搭配 25 GiB/s 儲存效能，解決記憶體密集型工作負載的效能瓶頸
- 支援 Oracle、SAP HANA、SQL Server 等企業級資料庫，以及生成式 AI 和 RAG 資料層，提供次毫秒級相似度搜尋
- 採用第五代 Intel Xeon 可擴展處理器與 Google 自研 Titanium 離線架構，搭配 Hyperdisk Extreme 可達 100 萬 IOPS 和 25 GiB/s 儲存吞吐量

## 結論
M4N 是 Google Cloud 針對高記憶體和高 I/O 工作負載的創新解決方案，透過優化記憶體與儲存效能，幫助企業降低授權成本並提升關鍵工作負載的效能。
