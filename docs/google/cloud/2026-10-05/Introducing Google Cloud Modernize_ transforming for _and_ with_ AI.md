# Introducing Google Cloud Modernize, transforming for (and with) AI

- **來源**: Google Cloud Blog
- **發布日期**: 2026-10-06
- **原文連結**: https://cloud.google.com/blog/products/infrastructure-modernization/google-cloud-modernize-accelerate-transformation-with-ai/

## 核心主題
Google Cloud 推出 Google Cloud Modernize，整合多種工具以加速企業基礎設施現代化轉型，利用 AI 能力縮短多年期規劃。

## 關鍵重點
- **Modernization Hub**：全新內置控制台體驗，整合現代化工具，支援 Java、.NET 和 mainframe 應用程式現代化
- **AI 驅動基礎設施評估**：Agentic Quick Estimator 可快速將 VMware 庫存轉換為總擁有成本 (TCO) 預測，縮短評估週期
- **高性能計算選項**：推出 X5 系列（單節點 43 TiB 記憶體）、M4N 系列（核心優化）和 Z4D/Z4M 系列（超低延遲數據引擎），支援高吞吐量工作負載
- **自動化容器遷移**：EKS 到 GKE 自動化遷移工具，支援 GitOps 合規和快速現代化
- **VMware 彈性解決方案**：自管理 VMware 解決方案提供 Bare Metal Z3 形狀，支援 VMware Cloud Foundation 9.1

## 結論
Google Cloud Modernize 提供完整的現代化解決方案，幫助企業利用 AI 加速基礎設施和應用程式現代化，縮短轉型週期並降低風險。
