# Powering the agentic enterprise with latest innovations in Oracle AI Database@Google Cloud

- **來源**: Google Cloud Blog
- **發布日期**: 2026-10-28
- **原文連結**: https://cloud.google.com/blog/products/databases/oracle-ai-databasegoogle-cloud-whats-new-at-oracle-ai-world/

## 核心主題
Google Cloud 與 Oracle 合作深化整合，透過 Oracle AI Database@Google Cloud 與 Gemini Enterprise 的協同，幫助企業建立自主代理工作流。

## 關鍵重點
- **Remote MCP Server 與 Knowledge Catalog 整合**：推出標準化介面，讓 AI 代理能安全存取 Oracle 資料庫，透過 Secret Manager 自動解決資料庫憑證，無需自訂 SQL 中間件。
- **Gemini Connector**：使用者可在 Gemini 應用程式中直接使用自然語言查詢 Oracle 資料庫，Gemini 自動利用 Knowledge Catalog 確保回應僅基於授權資料。
- **Oracle in Gemini Enterprise 與 Gemini 在 Oracle 應用程式**：雙向整合，企業可在 JD Edwards、NetSuite 等系統中部署多代理工作流，並將 Gemini 推理能力嵌入 Oracle Fusion 應用程式。
- **多種資料整合方案**：提供雙向 Lakehouse、實時 CDC 流式傳輸（OCI GoldenGate）、BigQuery 查詢聯邦等選項，讓企業根據需求選擇最適合的資料整合方式。
- **全球擴展與合規性**：新增 Turin（義大利）與 Queretaro（墨西哥）新區域，並計劃取得 FedRAMP High 認證，支援美國政府與公共部門工作負載。

## 結論
透過結合 Oracle 的傳統交易引擎與 Google 的代理資料雲，企業可將被動系統轉化為主動智能運營引擎，支援大規模自主 AI 代理部署，驅動關鍵業務流程的預測洞察與自動化行動。
