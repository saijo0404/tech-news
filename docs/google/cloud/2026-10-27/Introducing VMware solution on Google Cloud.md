# Introducing VMware solution on Google Cloud

- **來源**: Google Cloud Blog
- **發布日期**: 2026-10-28
- **原文連結**: https://cloud.google.com/blog/products/infrastructure-modernization/vmware-solution-on-google-cloud/

## 核心主題
Google Cloud 正式推出自管理 VMware 解決方案，提供完整的 VMware Cloud Foundation 管理權限，讓企業在雲端環境中保留對虛擬化架構的直接控制權。

## 關鍵重點
- 提供完整的 VMware Cloud Foundation 管理權限，包括 ESXi、vCenter、NSX Manager 等組件的根級管理權限
- 支援 VMware Cloud Foundation 9.x，可充分利用 Broadcom 的最新創新技術
- 部署在專用 GCE Z3 裸金屬實例上，提供高性能架構（96 核心、1.5TB RAM、72TB 全閃 NVMe 儲存）
- 支援 NVMe 記憶體階層化，可降低伺服器 TCO 高達 40%
- 提供 NetApp volumes 作為外部資料儲存選項
- 支援 Google Cloud 承諾和折扣，可優化成本（Flex CUDs）
- 提供三治理運營選擇：Google、客戶或夥伴框架
- 支援 AI 加速，可與 BigQuery 和 Gemini 平台直接連接

## 結論
此解決方案為企業提供了更大的控制權、選擇和架構自由，使其在遷移至雲端時能夠保留所需的靈活性和性能，同時無需重新架構 VMware 環境或放棄既有的運營實踐。
