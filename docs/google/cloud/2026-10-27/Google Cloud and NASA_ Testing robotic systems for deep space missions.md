# Google Cloud and NASA: Testing robotic systems for deep space missions

- **來源**: Google Cloud Blog
- **發布日期**: 2026-10-27
- **原文連結**: https://cloud.google.com/blog/topics/public-sector/google-cloud-and-nasa-testing-robotic-systems-for-deep-space-missions/

## 核心主題
Google Cloud 與 NASA 合作開發機器人系統，以支援深空任務（如登月基地和火星任務），提高乘員安全和效率。

## 關鍵重點
- 機器人系統可處理例行物流任務，讓宇航員專注於科學發現，節省寶貴的太空時間
- 機器人具備醫療支援功能，例如在宇航員需要時準備超音波設備，協助醫療人員進行診斷
- 使用 Google DeepMind 的 MuJoCo 模擬器和 Pi0 模型進行測試，實現 85% 的成功率
- 在太空船中運行需要邊緣計算能力，使用 Google Cloud G4 实例進行模型訓練，然後部署到輕量級邊緣設備
- 目標是通過簡單語音指令控制機器人，在宇航員監督下執行任務，但不取代人類決策

## 結論
這項 Google Cloud 與 NASA 的合作將為未來深空任務的科學探索開闢新途徑，同時確保乘員安全，是太空探索的重要里程碑。
