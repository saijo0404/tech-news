# Bringing Google TPUs to Oracle Cloud Infrastructure

- **來源**: Google Cloud Blog
- **發布日期**: 2026-10-28
- **原文連結**: https://cloud.google.com/blog/products/infrastructure/bringing-google-tpus-to-oracle-cloud-infrastructure/

## 核心主題
Google 與 Oracle 合作，將 Google TPU 引入 Oracle Cloud Infrastructure，使 OCI 成為第一個提供 TPUs 的非 Google 超大型雲端服務商，TPU 容量將於 2027 年開始部署。

## 關鍵重點
- TPU 採用系統級協同設計，結合自訂矽晶片與光學網路、供電、液態冷卻及編譯器軟體，在效能每瓦特和總擁有成本方面超越單一組件
- 第八代 TPU 提供每晶片 12.6 PFLOPS 的原始 FP4 運算能力，比 TPU v1 高出 100 倍，且在低延遲服務方面提供每美元高達 80% 更好的效能
- TorchTPU 已開放源碼，開發者可使用 vLLM、SGLang 等工具在 TPU 上訓練、服務和部署模型，無需重新撰寫程式碼
- OCI 提供四個主要優勢：針對 AI 密度設計的數據中心、Oracle Acceleron 的安全高效能網路、靠近企業數據的地理位置優勢，以及與 GPU 並存的多元架構選擇

## 結論
Google 與 Oracle 的合作將超過十年的目的導向 AI 系統工程開放給更廣泛的生態系統建設者，當客戶有更多目的導向運算的選擇時，整個產業將建設得更快、運作得更有效率。
