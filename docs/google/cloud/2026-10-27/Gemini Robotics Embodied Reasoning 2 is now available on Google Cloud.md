# Gemini Robotics Embodied Reasoning 2 is now available on Google Cloud

- **來源**: Google Cloud Blog
- **發布日期**: 2026-10-28
- **原文連結**: https://cloud.google.com/blog/products/ai-machine-learning/gemini-robotics-embodied-reasoning-2-is-now-available-on-google-cloud/

## 核心主題
Google 正式推出 Gemini Robotics ER 2，讓機器人具備實體推理能力，可在 Google Cloud 上進行模擬、訓練和部署。

## 關鍵重點
- **物理任務驗證與自我修正**：機器人可透過連續視頻分析驗證任務進度，精確定位關鍵事件，並自動修正失敗步驟。
- **跨形態單一智能層**：同一模型可適用於從固定機械臂到全人形機器人的各種形態，並支援多機器人協作。
- **代理工具調度與自然語言互動**：開發者可將 VLA 模型或導航 API 作為工具，透過自然語言指令調度機器人動作。
- **在 Google Cloud 構建安全實體代理**：提供快速模擬、精準訓練和易於運作的企業級部署環境。

## 結論
Gemini Robotics ER 2 為企業機器人帶來新的可能性，使機器人能理解複雜環境、規劃行動並適應變化，加速物理 AI 應用落地。
