# Introducing Ask, a new Google Earth Engine feature to accelerate geospatial coding

- **來源**: Google Cloud Blog
- **發布日期**: 2026-09-29
- **原文連結**: https://cloud.google.com/blog/products/data-analytics/accelerate-geospatial-coding-with-ai-in-google-earth-engine/

## 核心主題
Google Earth Engine 推出了新的「Ask」功能，整合 Gemini AI 能力，讓使用者能在程式碼編輯器中直接撰寫、除錯、理解和優化地理空間查詢。

## 關鍵重點
- **語境感知協助**：根據工作區上下文（腳本、資產、聊天歷史）提供客製化建議，無需額外說明
- **四種主要用途**：從自然語言生成程式碼、解釋複雜程式碼、一鍵除錯優化查詢
- **個人化選項**：可選擇不同 Gemini 模型、文檔搜尋、資料集搜尋或 Google 搜尋
- **使用方式**：只需 Gemini API 鍵，兩步驟即可開始使用

## 結論
此功能讓地理空間開發者能更快速獲得可行動的洞察，無需離開程式碼編輯器即可進行撰寫、除錯、理解和優化。
