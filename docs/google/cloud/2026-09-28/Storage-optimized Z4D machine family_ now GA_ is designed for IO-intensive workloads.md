# Storage-optimized Z4D machine family, now GA, is designed for IO-intensive workloads

- **來源**: Google Cloud Blog
- **發布日期**: 2026-09-28
- **原文連結**: https://cloud.google.com/blog/products/compute/storage-optimized-z4d-vm-and-bare-metal-instances/

## 核心主題
Google Cloud 正式推出新一代 Storage-optimized Z4D 機器系列，專為高 IO 密集型工作負載設計，提供大規模本地 SSD 儲存與卓越效能。

## 關鍵重點
- Z4D 提供高達 84,000 GiB 的本地 SSD (LSSD) 儲存，搭配第五代 AMD EPYC 處理器與 Titanium SSD，效能比前代 Z3 提升達 40%
- 提供兩種 VM 類型：Z4D-highmem-standardlssd（適合資料分析與 SQL 資料庫）與 Z4D-highmem-highlssd（適合分佈式資料庫與資料搜尋），並支援裸金屬實例
- 支援 Nutanix Cloud Clusters (NC2)，是首批支援此平台的 AMD 實例，並提供 Enhanced maintenance 體驗與 Hyperdisk 支援

## 結論
Z4D 機器系列為 AI/ML 訓練、資料庫、資料分析等高 IO 密集型工作負載提供卓越儲存效能與彈性，客戶測試顯示效能提升顯著，已於 2026 年 9 月 28 日正式上線。
