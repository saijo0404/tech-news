# How Nammu21 automates syndicated loans on Google Cloud Universal Ledger

- **來源**: Google Cloud Blog
- **發布日期**: 2026-11-04
- **原文連結**: https://cloud.google.com/blog/topics/financial-services/how-nammu21-automates-syndicated-loans-on-google-cloud-universal-ledger/

## 核心主題
Nammu21 與 Google Cloud 合作，利用 AI 平台將法律協議轉化為智能合約，在 Google Cloud Universal Ledger (GCUL) 上自動化放貸全週期，解決傳統放貸市場效率低下的問題。

## 關鍵重點
- Nammu21 將客製化信貸文件轉化為數位信貸工具 (DCI)，並映射回原始法律條款，實現法律條款到可執行行為的自動轉換
- 使用 GCUL 的許可式分佈式帳本，以 gculpy 語言編寫可程式合約，提供即時交易終結和可預測的成本
- 透過基於角色的權限控制和合規執行閘門，確保交易合規性和隱私，解決公共區塊鏈的未請求資產問題
- 所有付款流程直接在 GCUL 上使用令牌化商業銀行貨幣進行，消除外部支付通道需求，實現多參與方協調
- 證明概念涉及 19.45 億美元定期貸款，展示了單一不可變來源真實性的價值，縮短結算時間並降低後台費用

## 結論
此證明概念展示了信貸市場運作的結構性轉變，通過將每個設施的治理條款渲染為 DCI 並在 GCUL 上執行，根本性地改變了放貸市場的運作機制，縮短結算時間，降低後台費用，並通過設計而非手動檢查來減輕交易對手風險。
