# Simplify pipelines with new BigQuery identity columns

- **來源**: Google Cloud Blog Data Analytics
- **發布日期**: 2026-09-03
- **原文連結**: https://cloud.google.com/blog/products/data-analytics/bigquery-identity-columns-to-auto-generate-sequential-integers/

## 核心主題
BigQuery 推出 identity columns 新功能，可自動生成連續整數，簡化資料管道管理。

## 關鍵重點
- **自動化識別碼生成**：BigQuery 自動管理唯一識別碼，減少資料管道複雜度
- **兩種設定選項**：支援 GENERATED ALWAYS AS IDENTITY（自動管理）和 GENERATED BY DEFAULT AS IDENTITY（可手動覆寫）
- **簡化資料載入**：無需預先計算唯一鍵，直接插入資料即可自動生成 ID

## 結論
此功能讓資料工程師能更專注於提供洞察，而非管理識別碼，是 BigQuery 持續優化資料平台的重要進展。
