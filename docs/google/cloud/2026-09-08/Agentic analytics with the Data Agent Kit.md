# Agentic analytics with the Data Agent Kit

- **來源**: Google Cloud Blog
- **發布日期**: 2026-09-09
- **原文連結**: https://cloud.google.com/blog/products/data-analytics/agentic-analytics-with-the-data-agent-kit/

## 核心主題
這篇文章介紹了 Google 推出的 Data Agent Kit，一個基於 Model Context Protocol (MCP) 和 Agent Skills 的解決方案，讓資料開發者可以在 IDE 中透過自然語言提問，自動跨多個資料來源（如 BigQuery、Cloud SQL、Cloud Storage）進行資料分析與問題診斷。

## 關鍵重點
- Data Agent Kit 透過 MCP 標準與 Agent Skills 讓 AI 代理能自動執行資料查詢與分析，無需手動撰寫 SQL
- 支援在 Antigravity IDE、Cursor 等工具中直接透過對話式介面進行資料探索與問題診斷
- 案例展示：透過自然語言提問自動分析訂單價值下降原因，並自動生成 dbt 專案與測試

## 結論
Data Agent Kit 大幅降低資料分析門檻，讓非技術人員也能透過簡單對話完成複雜的資料探索與問題診斷，同時自動生成可重複使用的資料模型。
