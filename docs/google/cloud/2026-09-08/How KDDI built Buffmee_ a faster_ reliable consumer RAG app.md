# How KDDI Optimized RAG Performance with Agent Development Kit

- **來源**: Google Cloud Blog
- **發布日期**: 2026-09-09
- **原文連結**: https://cloud.google.com/blog/topics/customers/how-kddi-optimized-rag-performance-with-agent-development-kit/

## 核心主題
KDDI 利用 Google Cloud 的 Agent Development Kit (ADK) 優化其消費者 RAG 應用程式 Buffmee 的效能，成功降低延遲並提高準確性。

## 關鍵重點
- 使用自動化評估框架（如 LLM-as-a-Judge）將延遲降低 38%，TTFT 提升近 18%
- 將大系統提示拆分為 ADK Skills，動態載入所需邏輯以優化回應時間
- 實施二元評估系統和內容採樣策略，減少評估工作量 75%
- 利用 BigQuery Agent Analytics 和 ADK 日誌分析代理識別瓶頸

## 結論
透過系統化的自動化評估和效能分析，KDDI 成功推出了兼具速度與可靠性的消費者 RAG 應用程式，為其他組織提供了可複製的優化路徑。
