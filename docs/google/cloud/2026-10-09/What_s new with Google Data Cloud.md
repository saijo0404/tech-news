# Whats new with Google Data Cloud

- **來源**: Google Cloud Blog
- **發布日期**: 2026-10-09
- **原文連結**: https://cloud.google.com/blog/products/data-analytics/whats-new-with-google-data-cloud/

## 核心主題
Google Data Cloud 持續推出 AI 代理整合功能與多模型工作負載解決方案，並透過客戶案例驗證其效能。

## 關鍵重點
- **Data Agent Kit** 一般可用，提供 MCP 工具和 Google 撰寫的代理技能，可連接 15+ 個 Data Cloud 服務
- **Spanner Omni** 一般可用，支援跨環境部署的多模型工作負載
- **AlloyDB** 推出 PostgreSQL for agents 及原生 BM25 混合搜尋功能
- **BigQuery** 引入增強分析 TVF、TabFM 及身份欄位
- **Dataflow** 新增暫停/恢復功能及 NVIDIA RTX PRO 6000 GPU 支援
- **Memorystore for Valkey 9.1** 提供最高 3 倍 QPS 與微秒級延遲
- 客戶案例：Yahoo、PayPal、Surescripts、Airwallex、Lucius AI 等已採用 Google Data Cloud 解決方案

## 結論
Google Data Cloud 持續強化 AI 代理整合能力，提供跨雲端、多模型、跨區域的資料分析解決方案，並透過客戶案例驗證其效能。
