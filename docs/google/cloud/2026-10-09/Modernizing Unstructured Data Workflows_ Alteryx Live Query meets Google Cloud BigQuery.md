# Modernizing Unstructured Data Workflows: Alteryx Live Query meets Google Cloud BigQuery

- **來源**: Google Cloud Blog Data Analytics
- **發布日期**: 2026-10-10
- **原文連結**: https://cloud.google.com/blog/products/data-analytics/modernize-unstructured-data-workloads-with-alteryx-and-bigquery/

## 核心主題
這篇文章介紹了 Alteryx Live Query 與 Google Cloud BigQuery 的整合，如何幫助企業處理大規模的非結構化數據，特別是發票 PDF 等文件。

## 關鍵重點
- Live Query 提供直觀的瀏覽器介面，讓業務用戶無需編碼即可建立複雜數據管道
- 與 BigQuery 結合實現安全 SQL 下推，數據處理直接在倉儲內執行
- 支持使用 Gemini 等 AI 模型從 PDF 和圖片中提取智能
- 自動化發票處理流程：提取、分類、驗證、路由和上載
- 提高直通式處理率，減少手動處理
- 加快對賬並減少手動例外情況
- 增進可審計性，保持數據可追溯
- 減少數據移動，保持數據在 BigQuery 內

## 結論
這種 Google Cloud 原生模式將非結構化文檔轉換為可操作的運營輸出，使財務團隊能夠減少手動工作，加速例外處理，並專注於更高價值的戰略計劃。
