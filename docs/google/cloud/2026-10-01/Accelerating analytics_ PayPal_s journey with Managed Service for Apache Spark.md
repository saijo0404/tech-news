# Accelerating analytics: PayPal’s journey with Managed Service for Apache Spark

- **來源**: Google Cloud Blog
- **發布日期**: 2026-10-02
- **原文連結**: https://cloud.google.com/blog/products/data-analytics/paypals-journey-with-managed-service-for-apache-spark/

## 核心主題
PayPal 將分析工作負載從傳統 Hadoop 平台遷移至 Google 的 Managed Service for Apache Spark，以解決擴展性與複雜性問題。

## 關鍵重點
- **快速部署與彈性擴展**：Managed Spark 允許在分鐘內部署集群，根據處理需求進行擴展，消除了冗長的設置和閒置資源成本。
- **統一基礎設施**：標準化使用 Apache Spark 提高了團隊一致性，並降低了運營複雜性。
- **處理效率提升**：核心分析工作負載處理時間提升 25%，SLA 遵守率提升 30%，運營成本因工具整合和減少手動維護而降低。
- **工程師專注創新**：工程師有更多時間進行創新，快速原型開發新的分析能力，為客戶和合夥人創造價值。

## 結論
這次遷移使 PayPal 能夠提供更快速、更準確的分析洞察，推動持續創新。從分散的環境轉向統一的雲端原生平台，為 PayPal 建立了現代化分析基礎設施，使其能夠在全球業務需求不斷演變的情況下，以速度、精確度和影響力交付洞察。
