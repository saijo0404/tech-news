# What's new in Gemini Enterprise Agent Platform

- **來源**: Google Cloud Blog
- **發布日期**: 2026-07-30
- **原文連結**: https://cloud.google.com/blog/products/ai-machine-learning/whats-new-in-gemini-enterprise-agent-platform/

## 核心主題
Google Cloud 宣布 Gemini Enterprise Agent Platform 的多項新功能已對所有人開放，包括 Agent Memory Bank、Agent Runtime、Agent Identity、Agent Gateway、Agent Registry、Agent Evaluation 和 Agent Observability，幫助企業更簡單、更安全地擴展 AI 代理。

## 關鍵重點
- **Agent Memory Bank**：提供低延遲的個人化，透過定義結構化模式自動提取和維護關鍵對話上下文，確保代理能保留用戶偏好、過往決策和帳戶歷史。
- **Agent Runtime**：支持長達 7 天的連續運行，可自動化複雜的多天任務，讓代理在背景中執行整個異步過程，無需常態人工介入。
- **Agent Identity**：基於開源標準的原生 IAM 類型，實施最小權限原則，透過綁定存取至代理運行時來降低 token 竊取風險，並提供不可否認的審計。
- **Agent Gateway**：提供中央控制點，可安全治理所有代理互動，透過 IAM 條件和自然語言規則強制細粒度存取控制，並整合 Model Armor 保護提示注入、工具中毒和資料洩漏。
- **Agent Registry**：單一視圖管理組織內所有代理，作為單一圖書館讓團隊輕鬆找到和重複使用代理，同時讓管理員監控代理擴張。
- **Agent Evaluation**：持續監控和評估代理性能，透過線上評估監控主動識別性能退化和行為漂移，提供預設、自訂 Python、LLM-as-a-judge 或與 Google DeepMind 共同開發的適應性標準。
- **Agent Observability**：提供深度端到端可見性，透過全面追蹤和即時可視化儀表板了解代理推理、工具使用和執行性能。

## 結論
這些新功能讓企業能夠更簡單、更安全地擴展 AI 代理，從 AT&T、Best Buy、Commerzbank AG 等客戶的實際應用案例可見其價值。建議立即參考 Gemini Enterprise Agent Platform 文檔開始使用這些新功能。
