# Automate data monitoring and root-cause analysis with Looker Agentic Workflows

- **來源**: Google Cloud Blog
- **發布日期**: 2026-07-30
- **原文連結**: https://cloud.google.com/blog/products/business-intelligence/looker-adds-agentic-workflows-for-data-monitoring-and-insights/

## 核心主題
Google Looker 推出智能代理工作流 (Agentic Workflows)，自動化數據監控與根本原因分析，取代傳統僅通知指標變化的警報機制。

## 關鍵重點
- **自然語言設定自動化**：使用者可透過對話介面直接輸入監控需求（如「每週監控退貨率」或「當平均訂單價值超過$1,000時通知」），系統自動生成工作流配置供審查後啟動。
- **自動根本原因分析**：當指標突破設定閾值時，背景代理自動執行關鍵驅動分析 (KDA)，識別驅動變化的具體因素（如產品類別或客戶群體），並將診斷報告直接發送給團隊工作空間。
- **中央化管理與治理**：提供統一的工作流管理介面，業務使用者可檢視與編輯自己的監控，企業管理員則保留全系統審查、調整或停用工作流的權限。

## 結論
Looker Agentic Workflows 將數據監控從被動警報轉化為主動自動化分析，大幅減少人工介入需求。目前處於預覽階段，適用於 Looker 26.08 及以上版本，管理員可透過 Gemini in Looker 設定頁面啟用此功能。
