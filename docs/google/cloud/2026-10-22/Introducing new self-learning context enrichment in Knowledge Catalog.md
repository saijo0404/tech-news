# Introducing new self-learning context enrichment in Knowledge Catalog

- **來源**: Google Cloud Blog Data Analytics
- **發布日期**: 2026-10-23
- **原文連結**: https://cloud.google.com/blog/products/data-analytics/knowledge-catalog-self-learning-context-enrichment-for-ai-agents/

## 核心主題
Google Cloud 推出自學上下文增強功能，讓 AI 代理能自動學習和更新業務上下文，並重新設計了 Knowledge Studio 體驗。

## 關鍵重點
- **自學上下文增強**：分析代理和用戶互動，自動識別上下文缺口，從文檔、代碼庫和業務文檔中提取驗證後的定義
- **Knowledge Studio 重構**：新的命令中心，讓上下文工程師可視覺化探索數據資產、瀏覽上下文圖並審查變更提案
- **性能提升**：基於內部測試，AI 代理準確度提升近 4 倍，延遲降低 33%，token 使用減少 75%
- **自動化與治理**：可設定自動發布閾值（如 85%），低於門檻或敏感變更需人工審核，所有變更可追溯並可復原
- **上下文集合**：為不同用戶群組建立精確的上下文子集，支援 IAM 權限控制和 OKF 格式可移植性

## 結論
這些新功能將幫助企業在從少量代理擴展到數百萬代理的過程中，保持業務上下文的準確性和現狀，大幅降低人工維護成本並提升 AI 代理的準確性。
