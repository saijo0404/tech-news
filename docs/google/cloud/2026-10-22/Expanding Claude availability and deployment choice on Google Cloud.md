# Expanding Claude availability and deployment choice on Google Cloud

- **來源**: Google Cloud Blog
- **發布日期**: 2026-10-23
- **原文連結**: https://cloud.google.com/blog/products/ai-machine-learning/expanding-claude-availability-on-google-cloud/

## 核心主題
Google Cloud 宣布推出 Claude 模型的第二種部署選項（Anthropic 管理），讓團隊有更多選擇來運行模型，並可與現有的 Google 管理部署選項一起整合。

## 關鍵重點
- 提供兩種部署選項：Anthropic 管理和 Google 管理，兩者都提供 Day 0 的模型訪問
- Anthropic 管理選項提供即時的 Claude 平台功能（如 Claude Managed Agents、skills 和程式碼執行）
- Google 管理選項提供嚴格的治理、合規和主權要求，並提供與 Google Cloud 服務的本地整合
- 無論選擇哪種部署方式，都可以訪問 Claude Fable 5.1、Sonnet 5.5、Haiku 5.5 和 Opus 5.5 等模型

## 結論
這為開發者提供了模型選擇和架構靈活性，使他們可以根據組織的獨特需求在 Google Cloud 上運行生成式 AI 工作負載。
