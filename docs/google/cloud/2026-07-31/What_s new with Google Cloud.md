# What's New with Google Cloud

- **來源**: Google Cloud Blog
- **發布日期**: 2026-07-31
- **原文連結**: https://cloud.google.com/blog/topics/inside-google-cloud/whats-new-google-cloud/

## 核心主題
Google Cloud 在 AI 能力、API 治理、雲端基礎設施與安全治理方面的最新更新與進展。

## 關鍵重點
- **AI 模型更新**：Claude Opus 5、Sonnet 5 與 Gemini 3.1 系列推出，具備增強推理與代碼生成能力
- **Apigee API 管理**：新增 OpenAPI v3 原生支援、API Tester 開源測試框架，簡化 API 治理與 TDD 開發
- **雲端基礎設施升級**：Cloud Run 新增服務健康功能、TPU 模型加載速度提升 2 倍、Vast Edge 推出雲端備份即時恢復介面
- **AI 治理與安全**：AI Command and Control 架構提供安全管理層、零信任安全實踐、AI Telemetry Collector 標準化 TPU 監控
- **開發者工具**：VS Code 新增 Google Cloud Workbench Notebooks 擴充套件、Cloud Run Worker Pools 支援無伺服器 AI 大規模處理
- **數據與分析**：BigQuery Graph 建立數位孿生支援供應鏈建模、Datastream 與 Knowledge Catalog 整合提供單一視圖
- **商業價值報告**：83% 組織需要基礎設施升級以支援 AI 代理、AI Agent Clinic 展示延遲優化案例（80% 延遲降低）

## 結論
Google Cloud 持續強化 AI 能力、API 治理與雲端基礎設施，並提供豐富學習資源協助企業轉型。
