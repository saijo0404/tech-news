# What's new in AI infrastructure and orchestration this month

- **來源**: Google Cloud Blog
- **發布日期**: 2026-08-01
- **原文連結**: https://cloud.google.com/blog/topics/ai-infrastructure/whats-new-in-ai-infrastructure-this-month/

## 核心主題
Google Cloud 每月更新 AI 基礎設施與編排進展，涵蓋新產品、功能、實作指南與技術報告，協助企業在代理 AI 時代優化基礎設施。

## 關鍵重點
- **7 月重點**：Google Cloud Managed Lustre 正式通用化，提供 125-1000 MB/s 四階儲存效能；C4N 網路與儲存優化 VM 系列推出；GKE Dataplane V2 支援 15K 節點；llm-d 支援協作時間切片，RL 工作載荷加速器佔用率從 40% 提升至 70%；開源 k8s-aibom 工具監控 AI 供應鏈。
- **6 月重點**：Confidential Computing 支援 G4 機系列，提供資料在運加密；TPU Developer Hub 新開發者資源；OpenTelemetry 基 TPU 遥測收集器；GKE Inference Gateway 性能領先競爭對手。
- **5 月重點**：GKE Agent Sandbox 正式通用化；Agent Substrate 開源專案；Google AI Edge Portal 支援裝置端 LLM 測試；Cloud Storage Rapid 高效能儲存解決方案。

## 結論
Google Cloud 持續擴展 AI 基礎設施能力，從儲存、計算到編排全面優化，協助企業在代理 AI 時代提升效能、降低成本並確保安全。
