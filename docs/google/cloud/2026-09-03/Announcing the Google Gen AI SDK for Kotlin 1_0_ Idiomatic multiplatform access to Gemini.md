# Announcing the Google Gen AI SDK for Kotlin 1.0: Idiomatic multiplatform access to Gemini

- **來源**: Google Cloud Blog
- **發布日期**: 2026-09-04
- **原文連結**: https://cloud.google.com/blog/topics/developers-practitioners/announcing-the-google-gen-ai-sdk-for-kotlin-10-idiomatic-multiplatform-access-to-gemini/

## 核心主題
Google 正式推出 Google Gen AI SDK for Kotlin 1.0，提供跨平台（JVM 和 Android）的 Gemini AI 開發工具，支持多模態、即時互動和工具調用等功能。

## 關鍵重點
- 支持 Kotlin Multiplatform (KMP)，可同時用於 JVM 後端服務和 Android 應用
- 提供統一的 API 介面，可輕鬆與 Gemini Developer API 和 Gemini Enterprise Agent Platform 互動
- 支援單次請求、流式輸出、多輪對話、多模態分析、圖像生成、實時互動和工具調用等功能
- 使用 Kotlin 原生特性（如 Coroutines、Flow）實現現代化開發體驗

## 結論
此 SDK 為 Kotlin 開發者提供了乾淨、跨平台的基礎，可輕鬆構建生成式 AI 應用，無需處理原始 HTTP 客戶端或橋接不同的 Java 庫。
