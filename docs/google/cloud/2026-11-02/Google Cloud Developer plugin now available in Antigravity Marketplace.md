# Google Cloud Developer plugin now available in Antigravity Marketplace

- **來源**: Google Cloud Blog
- **發布日期**: 2026-11-03
- **原文連結**: https://cloud.google.com/blog/topics/developers-practitioners/google-cloud-developer-plugin-now-available-in-antigravity-marketplace/

## 核心主題
Google Cloud 推出 Developer plugin，讓 AI 代理能更安全、準確地建構 Google Cloud 解決方案，解決傳統編碼代理缺乏雲端上下文、易產生過時代碼或未經授權操作的問題。

## 關鍵重點
- **即時文件 grounding**：代理可透過流式 HTTP 查詢官方 Google Cloud 文件，確保資訊最新準確
- **安全與成本防護**：強制最小權限 IAM 模式，啟用收費 API 或修改雲端基礎設施前需取得使用者同意
- **環境感知能力**：自動檢測本地環境和 CLI 配置，設計安全執行路線圖後才執行命令
- **內建技能包**：包含 finding-google-skills、retrieving-developer-knowledge、gcloud 等核心技能，提供即時技能發現
- **單一指令安裝**：透過 Antigravity Marketplace UI 或終端機單一命令即可安裝，無需手動配置 API 金鑰或 OAuth 權限

## 結論
此插件為開發者提供了快速、安全且可靠的 Google Cloud 開發體驗，透過單一命令即可安裝並立即使用，大幅降低雲端開發的門檻與風險。
