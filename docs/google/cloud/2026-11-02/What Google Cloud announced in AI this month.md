# What Google Cloud announced in AI this month

- **來源**: Google Cloud Blog
- **發布日期**: 2026-11-02
- **原文連結**: https://cloud.google.com/blog/products/ai-machine-learning/what-google-cloud-announced-in-ai-this-month/

## 核心主題
Google Cloud 本月在 AI 領域推出重大平台升級與新模型發布，整合超過 200 種模型於統一企業 AI 平台，並強化 AI 安全與治理能力。

## 關鍵重點
- **新模型發布**：推出 Gemini 4 Argon（深度長任務處理）、Gemini 3.5、Gemini Omni（世界理解多模態）、Gemini Spark（24/7 個人 AI 代理）、Claude Opus 5.5 與 Sonnet 5.5
- **平台升級**：Gemini Enterprise Agent Platform 整合四大核心支柱（build、scale、govern、optimize），新增 Agent Designer、Projects 等功能
- **硬體升級**：AI Hypercomputer 推出 TPU 8t（訓練性能提升 3 倍）與 TPU 8i（推理性能每美元提升 80%）
- **安全解決方案**：Google AI Threat Defense 自主安全平台、Model Armor 保護 GKE AI 推理、收購 Wiz 團隊重新定義安全標準
- **開發者工具**：Mantis（漏洞發現）、CodeMender（自動修復漏洞）、AlphaEvolve（程式碼優化）、Open Knowledge Format (OKF) 標準
- **客戶應用案例**：Cloud Atelier（虛擬購物體驗）、Agent Factory（工程效率提升 100X）、已記錄超過 1,300 個客戶 AI 應用案例

## 結論
Google Cloud 持續強化 AI 平台能力，提供從基礎設施到應用層的全方位解決方案，並透過安全治理與成本優化幫助企業安全高效地部署 AI 工作負載。
