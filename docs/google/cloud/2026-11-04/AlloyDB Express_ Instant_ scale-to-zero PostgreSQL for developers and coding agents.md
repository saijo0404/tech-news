# AlloyDB Express: Instant, scale-to-zero PostgreSQL for developers and coding agents

- **來源**: Google Cloud Blog
- **發布日期**: 2026-11-05
- **原文連結**: https://cloud.google.com/blog/products/databases/introducing-alloydb-express-for-rapid-testing-and-prototyping/

## 核心主題
Google Cloud 推出 AlloyDB Express，一款專為開發者和 AI 編碼代理設計的 PostgreSQL 服務，提供秒級啟動、自動暫停和企業級安全功能。

## 關鍵重點
- **秒級啟動**：使用 gcloud CLI、REST API、MCP、Terraform 或 Console 可在兩秒內創建 PostgreSQL 數據庫
- **自動縮零**：數據庫在閒置 15 分鐘後自動暫停，避免閒置時產生費用，有新查詢時秒級喚醒
- **內建 AI 能力**：包含向量搜索、Gemini 模型直接訪問和自然語言轉 SQL 功能
- **企業級安全**：內建安全防護機制，包括安全默認連接、私有 VPC 網絡和最小權限原則
- **免費起步**：提供每月 50 個免費計算單元，僅支付實際使用量
- **一鍵升級**：可將現有數據庫升級為 AlloyDB，保留數據、模式、用戶和連接字符串

## 結論
AlloyDB Express 為開發者和 AI 代理提供了快速、安全且成本效益高的 PostgreSQL 解決方案，可加速應用開發並輕鬆擴展至生產規模。
