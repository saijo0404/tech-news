# Helping you build and defend at machine-speed in the agentic era

- **來源**: Google Cloud Blog
- **發布日期**: 2026-11-05
- **原文連結**: https://cloud.google.com/blog/products/identity-security/helping-you-build-and-defend-at-machine-speed-in-the-agentic-era/

## 核心主題
Google 分享如何在代理時代以機器速度安全地構建和防禦系統，包括 CodeMender 工具、Auth Manager 等安全功能。

## 關鍵重點
- **CodeMender 自主代碼安全代理**：可幫助組織以機器速度發現和修復代碼漏洞，與 Gemini 4 Argon 合作識別先前未知的漏洞並生成測試過的修復方案。
- **集中化憑證管理**：Auth Manager 和 Agent Identity 提供集中化的憑證管理，自動化 OAuth 2.0/PKCE 流程，減少憑證洩漏風險。
- **Wiz 和 Google Cloud 合作**：提供端到端防禦，包括 Wiz AI SAST 使用代理推理識別複雜業務邏輯漏洞，以及 Wiz Defend 與 Google Security Operations 共享數據模型。
- **機器速度防禦操作**：現代化 SOC 需要自主調查、檢測和響應，利用行星級基礎設施在分鐘內中斷敵對行為。
- **Secure-by-design 管道**：建立原生管道防禦、拆除扁平信任架構，並部署機器速度操作，企業可將 AI 優勢轉回防禦者。

## 結論
通過建立原生管道防禦、拆除扁平信任架構和部署機器速度操作，企業可以將 AI 優勢轉回防禦者，在代理時代安全地構建和防禦系統。
