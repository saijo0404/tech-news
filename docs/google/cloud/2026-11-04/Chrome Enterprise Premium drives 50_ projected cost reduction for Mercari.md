# Chrome Enterprise Premium drives 50%+ projected cost reduction for Mercari

- **來源**: Google Cloud Blog
- **發布日期**: 2026-11-05
- **原文連結**: https://cloud.google.com/blog/products/chrome-enterprise/chrome-enterprise-premium-drives-50-projected-cost-reduction-for-mercari/

## 核心主題
Mercari 透過採用 Chrome Enterprise Premium 取代傳統 VDI 架構，成功實現了更高的安全性與成本效益。

## 關鍵重點
- 實施嚴格的 DLP（數據防洩漏）規則，限制用戶將文件複製或上傳到 Mercari 未批准的業務工具，防止敏感數據洩漏
- 透過零接觸設備註冊和減少對 VDI 的依賴，大幅簡化 IT 運營，無需手動設定每台設備
- 預計在三年內節省超過 50% 的成本，涵蓋設備成本、VDI 運行成本和各種安全許可證
- 能夠安全地採用 AI 功能（如 Gemini），同時保持數據邊界，員工可安全使用多頁面上下文和側邊欄互動

## 結論
Chrome Enterprise Premium 為 Mercari 提供了零信任、基於設備的安全方法，有效保護數據、削減 IT 成本並顯著提升安全性，同時為未來 AI 生產力開闢了安全路徑。
