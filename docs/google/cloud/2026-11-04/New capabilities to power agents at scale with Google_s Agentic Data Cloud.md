# New capabilities to power agents at scale with Google's Agentic Data Cloud

- **來源**: Google Cloud Blog
- **發布日期**: 2026-11-05
- **原文連結**: https://cloud.google.com/blog/products/databases/whats-new-across-googles-agentic-data-cloud/

## 核心主題
Google 推出 Agentic Data Cloud 重大更新，透過整合全域數據、強化企業語境與大規模代理基礎設施，幫助企業以更準確、可信的方式部署 AI 代理。

## 關鍵重點
- **Borderless Lakehouse 增強**：Gemini 可直接在跨雲湖倉上查詢數據，支援 AWS/Azure 跨雲互連與零費用數據存取，並自動快取數據塊。
- **Knowledge Catalog 升級**：引入自學習語境豐富功能，自動從 Google Workspace、GitHub 等來源學習業務語境，使 AI 代理準確度提升近 4 倍。
- **AlloyDB 與 Lakehouse 整合**：支援直接查詢 Iceberg 表，無需 ETL 即可將即時交易數據與歷史分析數據結合，聚合查詢速度快 7 倍。
- **Spanner Omni 推出**：提供 Google 級一致性、擴展性與多模型能力，支援混合代理應用。
- **Gemini 功能擴展**：為數據工程師提供 ML 技能自動生成 PySpark 代碼，為業務用戶提供即時報表生成能力。
- **Data Agent Kit 正式推出**：將 Google 數據工具直接整合至開發者首選 IDE，無需切換控制台。
- **AlloyDB Express 推出**：提供秒級部署、可縮放至零的開發環境，適合快速原型開發。
- **PostgreSQL for Agents**：支援數千個代理同時查詢即時交易數據，支援每秒百萬級查詢。
- **BigQuery Graph 正式推出**：在關聯表中直接進行 PB 級圖分析，無需 ETL。
- **TimesFM 3.0 與 TabFM 模型**：可在 BigQuery 中直接生成預測模型。

## 結論
Google 透過 Agentic Data Cloud 的各項創新，幫助企業打破數據壁壘、強化語境理解，並提供大規模代理所需的基礎設施，使 AI 代理能更準確、高效地驅動業務成果。
