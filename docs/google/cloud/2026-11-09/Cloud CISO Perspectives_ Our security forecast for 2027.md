# Cloud CISO Perspectives: Our security forecast for 2027

- **來源**: Google Cloud Blog
- **發布日期**: 2026-11-10
- **原文連結**: https://cloud.google.com/blog/products/identity-security/cloud-ciso-perspectives-our-security-forecast-2027/

## 核心主題
Google Cloud CISO Chris Betz 與 Google、Mandiant 高層分享 2027 年安全預測，涵蓋代理威脅、攻擊戰術變化及新安全防禦方法。

## 關鍵重點
- **代理威脅與決策可追溯性**：自主系統需要完整的決策追蹤記錄，包括輸入、推理過程、調用的工具及參數，否則無法驗證與信任。
- **警報疲勞消失**：2027 年分析師將從追蹤警報轉向塑造結果，自主防禦代理自動處理數據豐富化、關聯與分級，人類專注於戰略決策。
- **超越零信任**：需要擴展至交易層級，每個自主代理視為第一級身份，擁有可驗證憑證、嚴格最小權限範圍及開放通訊標準。
- **閉環安全**：安全成為嵌入軟體交付管道的連續系統，將代理推理置於開發工具中進行威脅建模，並連結生產環境回來源代碼。
- **內部真實數據優勢**：防禦者擁有攻擊者無法獲得的完整內部真實數據，包括身份權限圖、內部網路架構、代碼線性與即時運行活動。
- **對抗威脅速度**：網路犯罪者轉向快速高量數據盜取與勒索（如 LLMJacking），需消除安全孤島，建立單一智能導向治理框架。
- **紅隊測試自主企業**：部署前必須進行持續主動的敵對紅隊測試，系統性嘗試突破安全控制與操弄模型行為。
- **專員化代理團隊**：需要建立治理與協調層，建立漸進式自主性、共享狀態、乾淨交接及中央協調者，防止代理濫用。

## 結論
2027 年安全將從靜態應用轉向自主代理生態，需要新的治理架構、決策可追溯性、交易級信任及持續紅隊測試。防禦者應利用完整內部真實數據優勢，建立專員化代理團隊以應對快速演變的威脅。
