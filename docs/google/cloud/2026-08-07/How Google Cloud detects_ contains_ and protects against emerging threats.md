# How Google Cloud detects, contains, and protects against emerging threats

- **來源**: Google Cloud Blog
- **發布日期**: 2026-08-08
- **原文連結**: https://cloud.google.com/blog/products/identity-security/how-google-cloud-detects-contains-and-protects-against-emerging-threats/

## 核心主題
Google Cloud 透過共享命運模式，主動監控並防禦各種新興威脅，包括 AI 工作負載濫用、加密貨幣挖礦、洩露憑證及帳號接管等攻擊。

## 關鍵重點
- **威脅偵測**：監控 AI 工作負載濫用、加密貨幣挖礦活動、洩露憑證和供應鏈攻擊、帳號接管等攻擊模式
- **隔離措施**：針對性限流、協同排查、本地化身份隔離、最後手段暫停專案以最小化業務中斷
- **風險溝通**：提供 30 天安全事件日誌、主動支援案例、審計日誌和異常支出警報，確保即時通知
- **客戶行動方案**：強制 MFA、安全 API 金鑰管理、最小權限原則、定期資源衛生檢查

## 結論
Google Cloud 與客戶共同建立「共享命運」的安全夥伴關係，透過持續監控和客戶端主動防護措施，共同維護安全環境。
