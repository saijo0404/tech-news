# Unifying Structured and Unstructured Data Insights with BQ Search Innovations

- **來源**: Google Cloud Blog Data Analytics
- **發布日期**: 2026-08-08
- **原文連結**: https://cloud.google.com/blog/products/data-analytics/bigquery-search-innovations-unify-structured-unstructured-data/

## 核心主題
BigQuery 推出三大創新功能，統一結構化與非結構化數據的洞察，簡化 AI 架構。

## 關鍵重點
- **自主嵌入生成 (Autonomous Embedding Generation)**：大規模推出，自動生成數據嵌入，無需管理複雜的異步嵌入基礎設施，支援外部模型（如 Vertex AI text-embeddings）或原生 Gemma 嵌入模型，並新增對圖片的嵌入支援。
- **AI.SEARCH 功能推出**：提供流暢的自然語言搜索體驗，單次查詢性能提升高達 133 倍，使高併發用戶端自然語言搜索更快速、更具成本效益。
- **混合搜索 (Hybrid Search) 進入公開預覽**：結合語義向量搜索與關鍵字搜索，利用 Reciprocal Rank Fusion 和 BM25 算法，提升搜索精度並降低 LLM 幻覺成本。
- **完整的非結構化數據分析平台**：涵蓋 Access（零 ETL 工作流）、Process（嵌入式 AI 能力）、Ground（自主嵌入與混合搜索）、Relate（BigQuery Graph）、Activate（大規模分析代理）五步驟。

## 結論
這些創新讓企業可以更輕鬆地在 BigQuery 中管理非結構化數據，減少對複雜第三方向量數據庫的需求，並通過混合搜索降低 LLM 幻覺成本，實現從原始文檔到對話式 AI 的完整橋接。
