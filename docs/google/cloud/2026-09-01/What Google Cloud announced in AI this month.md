# What Google Cloud announced in AI this month

- **來源**: Google Cloud Blog
- **發布日期**: 2026-09-01
- **原文連結**: https://cloud.google.com/blog/products/ai-machine-learning/what-google-cloud-announced-in-ai-this-month/

## 核心主題
Google Cloud 本月聚焦於 AI 實用化、成本控制、垂直產業應用（金融/法律）、安全防護及開發工具擴展。

## 關鍵重點
- **Agent Platform 全新架構**：推出四大核心支柱（Build、Scale、Govern、Optimize），提供無代碼 Agent Designer 與長運行代理能力
- **Gemini Enterprise 功能擴展**：新增中央監控 Inbox、Projects 空間隔離、Canvas 互動編輯器及第三方代理整合
- **AI Hypercomputer 硬體升級**：TPU 8t 訓練優化、TPU 8i 推理優化，採用 Boardfly 拓扑結構提升 KV Cache 效率
- **Agentic Data Cloud 數據架構**：跨雲 Lakehouse、統一知識目錄、智能儲存與自主標記功能
- **安全性全面強化**：收購 Wiz 團隊、Agentic defense 三項新安全代理、Model Armor 整合 Agent Gateway
- **模型持續迭代**：Gemini 3.1 Pro 推理能力提升、Veo 3.1 Lite 成本降低 50%、Nano Banana 2 創意生成加速
- **GEAR 計劃開放**：Gemini Enterprise Agent Ready 計劃已開放給所有人，協助構建企業級 AI 代理
- **Universal Commerce Protocol (UCP)**：通用商業協議支持 AI 代理與零售系統間的全流程溝通
- **Comments to SQL**：BigQuery 推出自然語言查詢功能，工程師可用英文描述直接生成 SQL
- **Gemini Enterprise for CX**：專為代理零售設計的客戶體驗平台
- **FinOps for AI**：靈活計費與成本控制工具，適用於 Gemini Enterprise 及開發工具
- **AI 幻覺研究**：大語言模型錯誤生成問題研究

## 結論
Google Cloud 持續強化 AI 平台能力，從基礎設施到應用層面全面升級，同時聚焦成本控制與安全防護，為企業提供完整的 AI 解決方案。
