# Introducing TabFM in BigQuery: Predictive analytics reimagined

- **來源**: Google Cloud Blog Data Analytics
- **發布日期**: 2026-09-02
- **原文連結**: https://cloud.google.com/blog/products/data-analytics/tabfm-adds-predictive-ml-to-bigquery/

## 核心主題
Google 推出 TabFM 模型，將預測機器學習直接整合到 BigQuery 中，透過單一 SQL 語句即可實現高準確度的預測分析。

## 關鍵重點
- **零樣本預測**：無需訓練、調優和部署，只需將標記歷史資料和預測資料表傳入單一 SQL 函數即可獲得即時高品質預測
- **預測 ML 用於代理應用**：可為業務代理添加預測能力，無需管理運行時或基礎設施
- **業界領先的準確性**：在複雜資料集上表現優於自訂訓練的傳統模型
- **簡單的開發者體驗**：原生運行於 BigQuery，透過簡單 SQL 語法即可訪問，自動處理缺失值、類別編碼等特徵工程任務
- **可擴展性**：利用 BigQuery 的分佈式推理架構，可在數分鐘內處理百萬行資料

## 結論
TabFM 模型透過在 BigQuery 中內建預測機器學習，大幅簡化了開發者、資料科學家和分析師的工作流程，使他們能夠在數秒內從原始資料獲得豐富的預測洞察。
