# How Box is unlocking multimodal enterprise agents with Gemini Embeddings 2

- **來源**: Google Cloud Blog
- **發布日期**: 2026-08-19
- **原文連結**: https://cloud.google.com/blog/topics/partners/box-ai-agents-gemini-embeddings-multimodal-enterprise-ai/

## 核心主題
Box 與 Google Cloud 合作，利用 Gemini Multimodal Embeddings 2 技術，將多模態能力整合至 Box 的代理平台，使企業 AI 能處理文本、表格、圖表、影像等多種格式的企業內容。

## 關鍵重點
- **保留視覺與空間結構**：多模態嵌入能保留複雜文件元素（如多欄表格、財務矩陣）的空間佈局，避免將行列關係扁平化時造成的資訊斷裂。
- **跨模態檢索能力**：系統可同時查詢圖像與文本內容，讓用戶無需手動標記即可定位特定圖表或圖形。
- **跨格式統一理解**：支援 PDF、Excel、PPT、圖片等多種文件格式的橋接，實現跨格式內容的統一理解。
- **三大應用場景**：
  - **金融分析報告**：自動比對文字摘要與圖表趨勢，識別數據差異
  - **醫療診斷支援**：同時分析臨床照片與病理切片，識別罕見異常
  - **跨文件數據對帳**：跨 PDF、Excel、郵件等文件驗證數據一致性

## 結論
Gemini Multimodal Embeddings 2 的整合標誌著企業內容管理架構的重大轉變，使 Box 從被動存儲轉向主動的智能協作。對於金融、生命科學和法律等複雜行業，多模態理解能力已成競爭關鍵，能幫助企業從非結構化內容中挖掘前所未有的價值。
