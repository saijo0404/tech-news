# Building operational resilience with agentic AI in financial services

- **來源**: Google Cloud Blog
- **發布日期**: 2026-08-19
- **原文連結**: https://cloud.google.com/blog/topics/financial-services/building-operational-resilience-with-agentic-ai-in-financial-services/

## 核心主題
Deutsche Bank 利用 Google Cloud 的代理 AI 工具，建立了一個 AI 驅動的韌性平台，將傳統的桌面演習轉化為基於真實企業情境的持續智能模型，以符合 DORA 法規要求。

## 關鍵重點
- 利用 Gemini Enterprise Agent Platform 和 Google ADK 實現雙重編排架構，結合監管合規控制與靈活性
- 從手動準備轉向基於真實企業信號的持續智能模型，產生可審計的證據
- 使用 Google Cloud 服務（Cloud Run、Cloud SQL 等）支持可追溯生成、受控執行和持久化證據記錄
- 將韌性測試擴展到實際運營事件，建立可複製的韌性範式供金融業參考

## 結論
Deutsche Bank 通過此平台實現了從定期韌性測試到持續、智能驅動的能力的戰略轉變，為金融機構提供了可複製的韌性藍圖。
