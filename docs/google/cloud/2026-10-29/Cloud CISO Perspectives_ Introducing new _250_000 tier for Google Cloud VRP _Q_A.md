# Cloud CISO Perspectives: Introducing new $250,000 tier for Google Cloud VRP (Q&A)

- **來源**: Google Cloud Blog
- **發布日期**: 2026-10-30
- **原文連結**: https://cloud.google.com/blog/products/identity-security/cloud-ciso-perspectives-introducing-new-tier-for-google-cloud-vrp/

## 核心主題
Google Cloud VRP 推出新的 $250,000 Root-in-Cloud 獎勵層級，以鼓勵高影響力的架構研究，同時應對自動化漏洞發現帶來的挑戰。

## 關鍵重點
- 新增 $250,000 Root-in-Cloud 獎勵層級，要求研究者證明對任意 Google Cloud 組織或專案擁有完整管理權限，且不得依賴預先存在的訪問、洩露憑證或用戶互動。
- 自動化工具普及導致漏洞報告量激增，但有效報告數量穩定，促使研究者需更快發現高價值漏洞。
- 強調協調披露的重要性，避免搶先公開未修復漏洞，以保護用戶安全。
- 建立明確的安全測試規則，使用指定服務帳戶驗證根權限，禁止對生產環境進行探索、提權或橫向移動。
- 企業 CISO 應準備應對 AI 生成報告，縮短修復週期，並對安全合規夥伴提出協調披露標準。

## 結論
Google Cloud VRP 透過高額獎勵與嚴格規則，平衡鼓勵安全研究與保護用戶安全的需求，在 AI 時代重塑漏洞管理生態。
