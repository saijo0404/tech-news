# Expanded semantic model support in Knowledge Catalog

- **來源**: Google Cloud Blog Data Analytics
- **發布日期**: 2026-10-30
- **原文連結**: https://cloud.google.com/blog/products/data-analytics/expanded-semantic-model-support-in-knowledge-catalog/

## 核心主題
Knowledge Catalog 現在支援將來自多個數據源（如 Looker、BigQuery、dbt 等）的語義模型整合到單一上下文圖中，使 AI 代理能基於可信的業務定義工作。

## 關鍵重點
- Knowledge Catalog 原生支援從 Looker LookML、BigQuery Graph、dbt MetricFlow、Snowflake Semantic Views、Databricks Metric Views 和 SAP Core Schema Notation 等來源導入語義模型和指標定義。
- 將 AI 代理基於 Knowledge Catalog 可使準確度提高近 4 倍，延遲降低最多 33%，並減少最多 75% 的 token 使用量。
- 單一上下文圖整合所有語義模型，使 AI 代理能使用相同的可信定義，並解決不同工具間指標定義不一致的問題。

## 結論
通過將 AI 代理「錨定」在知識庫中已有的語義模型上，企業可以確保 AI 回答與業務分析一致，同時提升準確性、降低延遲並減少資源消耗。
