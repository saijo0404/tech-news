# How ISVs are unlocking European workloads using Google Cloud Dedicated technology

- **來源**: Google Cloud Blog
- **發布日期**: 2026-11-17
- **原文連結**: https://cloud.google.com/blog/products/identity-security/how-isvs-are-unlocking-european-workloads-on-google-cloud-dedicated/

## 核心主題
歐洲受監管機構透過 Google Cloud Dedicated 部署獨立軟體供應商 (ISV) 解決方案，在符合當地數據治理法規的同時，保留主流企業軟體選擇權。

## 關鍵重點
- **本地化運營託管**: 法國 S3NS 和德國新實體等本地合作伙伴管理基礎設施運營、軟體隔離程序及日常行政訪問，提供受嚴格控制的遠端技術支援。
- **廣泛軟體選擇**: 受監管機構可在主權邊境內直接部署身份治理、網絡韌性、模擬和數據流傳等行業標準工具，無需重新架構。
- **簡化合規性**: 符合 SecNumCloud（法國）和 BSI C3A（德國）等國家框架，同時保留熟悉的 CI/CD 管道、API 和開發工作流。
- **驗證 ISV 生態系統**: Cohesity（網絡韌性）、GitLab（安全合規軟體交付）、Ansys/Synopsys（高性能模擬）、Memority（審計合規身份治理）、RackWare（雲端遷移）、Striim（實時數據流傳）、Red Hat、Saviynt、Tsuga、MongoDB、Ispirer、Splunk、Solo.io、Pelico 等 ISV 解決方案已驗證可部署。
- **解決軟體瓶頸**: 歐洲機構遷移至主權雲的主要障礙是軟體而非基礎設施，Google Cloud Dedicated 允許全球和歐洲軟體提供商將其驗證平台直接部署在國家級主權邊境內。

## 結論
Google Cloud Dedicated 透過提供與 Google Cloud 一致的架構和 API，使歐洲受監管機構能在符合 SecNumCloud、BSI C3A 等法規要求的主權雲環境中，直接運行經過驗證的企業級 ISV 解決方案，無需重新架構應用程序或犧牲軟體選擇權，同時保持本地運營託管和數據主權。
