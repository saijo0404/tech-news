# Power your agents: Gemini 3.8 Live with Live Avatar is now generally available

- **來源**: Google Cloud Blog
- **發布日期**: 2026-09-25
- **原文連結**: https://cloud.google.com/blog/products/ai-machine-learning/gemini-3-8-live-with-live-avatar-is-now-generally-available/

## 核心主題
Gemini 3.8 Live 與 Live Avatar 功能正式在 Gemini Enterprise 中一般可用，提供更高品質的企業語音 AI 互動體驗。

## 關鍵重點
- **視頻頭像**: 支援同步口型同步的會話視頻，可生成互動式視頻頭像（自訂頭像需通過白名單）
- **流暢對話**: 原生語音到語音技術，自然恢復中斷，不丟失對話上下文或後端交易
- **工具調用**: 背景執行工具/API調用，模型可同時繼續對話並處理任務
- **打破語言障礙**: 支援97種語言，具備自動語言檢測功能
- **即時視覺理解**: 可同時處理即時相機畫面、螢幕共享與音訊，讓代理更容易理解用戶所見

## 結論
Gemini 3.8 Live with Live Avatar 已可在 Gemini Enterprise 中試用，並提供 API 整合指南。所有生成的音頻和視頻流都帶有不可察覺的 SynthID 水印，確保 AI 生成內容的透明度和可驗證性。
