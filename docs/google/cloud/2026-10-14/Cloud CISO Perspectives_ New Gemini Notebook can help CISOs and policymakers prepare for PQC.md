# Cloud CISO Perspectives: New Gemini Notebook can help CISOs and policymakers prepare for PQC

- **來源**: Google Cloud Blog
- **發布日期**: 2026-10-15
- **原文連結**: https://cloud.google.com/blog/products/identity-security/cloud-ciso-perspectives-new-gemini-notebook-can-help-cisos-policymakers-prepare-for-pqc/

## 核心主題
Google 推出新的 Gemini Notebook 工具，幫助 CISOs 和政策制定者快速了解後量子密碼學（PQC）威脅並制定準備計劃。

## 關鍵重點
- 量子計算技術快速發展，Willow 晶片和 Quantum Echoes 算法顯示重大進展，現有加密系統面臨被破解風險
- 攻擊者可能採取「現在偷取、未來解密」策略，健康記錄、金融數據等敏感信息已處於風險中
- Google 計劃於 2029 年遷移至 PQC，建議其他組織採取相同時間表
- 新 Gemini Notebook 提供互動式學習工具，包括問答、音頻概述、閃卡測試和視覺化圖表
- 組織應優先識別脆弱加密位置、評估風險並建立遷移路徑

## 結論
後量子遷移已開始，組織應立即開始評估加密庫存並制定遷移路徑，而非等待白皮書。
