# What's new in OKF v0.3: enterprise-ready knowledge, use cases, and skills

- **來源**: Google Cloud Blog
- **發布日期**: 2026-11-19
- **原文連結**: https://cloud.google.com/blog/products/data-analytics/introducing-okf-v0-3/

## 核心主題
Google Cloud 推出 Open Knowledge Format (OKF) v0.3，強化信任機制、使用案例指南與代理技能，使知識庫更適合企業級應用與跨組織協作。

## 關鍵重點
- **正式合規規則與信任等級**：v0.3 引入精確合規規則與信任等級機制，確保信任狀態與代理編輯同步更新，僅計算當前驗證。
- **OKF 使用案例指南**：發布社區指南，說明如何將 OKF 與其他行業標準（如 Avro、Protobuf）結合使用，明確邊界與連結方式。
- **跨組織協作支援**：OKF 移至獨立 GitHub 組織，提供穩定擴展模型與明確版本政策，支援檔案遺棄與重定向機制。
- **代理技能發布**：推出 okf-generate 與 okf-consume 兩項代理技能，使編碼代理能撰寫、讀取與驗證 OKF 束集。
- **相容性保證**：v0.2 束集仍可讀取，僅有當前驗證計入信任等級，路徑解析方式更明確。

## 結論
OKF v0.3 透過強化信任機制、擴展使用案例與提供代理技能，為企業打造更可靠、可擴展且易於協作的知識管理基礎設施，同時保持與現有束集的相容性。
