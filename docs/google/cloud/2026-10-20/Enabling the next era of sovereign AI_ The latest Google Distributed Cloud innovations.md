# Enabling the next era of sovereign AI: The latest Google Distributed Cloud innovations

- **來源**: Google Cloud Blog
- **發布日期**: 2026-10-21
- **原文連結**: https://cloud.google.com/blog/topics/hybrid-cloud/new-innovations-in-google-distributed-cloud/

## 核心主題
Google 推出 Google 分布式雲 (GDC) 的新創新，使組織能在封閉環境中部署前沿 AI 模型和企業級應用，無需妥協數據主權和安全性。

## 關鍵重點
- **Gemini 企業搜索**：提供多模態（文本、音頻、視頻）的企業搜索能力，支持 RAG，數據完全在封閉環境內處理
- **前沿模型支持**：Gemini 3.5 Flash 和開源模型（Gemma、Mistral）可在封閉環境中運行
- **下一代基礎設施**：NVIDIA HGX B300 系統、32 Gbps 網絡、Cloud DNS 和 Elastic Security 集成
- **ISV 合作伙伴生態**：Teradata、Solo.io 和 Mattermost 等應用可原生運行於 GDC

## 結論
Google 分布式雲使組織能在保持數據主權和安全性的同時，利用生成式 AI 的創新能力，將敏感數據轉化為可行動的洞察。
