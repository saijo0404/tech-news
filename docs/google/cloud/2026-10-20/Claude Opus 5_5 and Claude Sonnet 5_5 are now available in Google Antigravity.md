# Claude Opus 5.5 and Claude Sonnet 5.5 are now available in Google Antigravity

- **來源**: Google Cloud Blog
- **發布日期**: 2026-10-21
- **原文連結**: https://cloud.google.com/blog/products/ai-machine-learning/claude-opus-55-and-claude-sonnet-55-available-in-antigravity/

## 核心主題
Google Cloud 在 Antigravity 平台上推出了 Claude Opus 5.5 和 Claude Sonnet 5.5 模型，讓開發者可以根據任務需求選擇合適的模型。

## 關鍵重點
- Claude Opus 5.5 適合複雜工作，Claude Sonnet 5.5 則更快、成本更低
- 支援多模型工程模式，包括跨模型驗證（LLM-as-a-Judge）和搭配 Flash 子代理
- 可透過 Antigravity 2.0、CLI 和 IDE 擴展使用，並有統一企業計費與安全邊界

## 結論
開發者可以根據任務需求選擇合適模型，並透過多模型工程模式提升程式碼品質同時控制延遲與成本。
