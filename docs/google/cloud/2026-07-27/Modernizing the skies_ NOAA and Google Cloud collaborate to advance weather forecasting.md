# Modernizing the skies: NOAA and Google Cloud collaborate to advance weather forecasting

- **來源**: Google Cloud Blog
- **發布日期**: 2026-07-28
- **原文連結**: https://cloud.google.com/blog/topics/public-sector/modernizing-the-skies-noaa-google-cloud-collaborate-advance-weather-forecasting/

## 核心主題
NOAA 與 Google Cloud 合作，將氣象預報超級電腦系統遷移至雲端，以改進天氣預報準確性。

## 關鍵重點
- Google Cloud 被選為 NOAA 氣象預報超級電腦系統 (WCOSS) 的主要高性能計算基礎設施提供商
- 使用 Google Cloud H4D VMs（搭載第五代 AMD EPYC 處理器）作為主要計算平台
- 這是全球第一個將數值天氣預報中心遷移至公有雲的運營中心之一
- 基於多年合作基礎，NOAA 此前已使用 Google DeepMind 和 WeatherNext 模型成功預測颶風 Melissa
- 這項合作將提升預報準確性，改善公共安全，並確保美國在全球天氣建模領域保持領先

## 結論
NOAA 與 Google Cloud 的長期合作標誌著政府機構與產業界在共享願景下協作的成功範例，將為天氣預報帶來重大突破。
