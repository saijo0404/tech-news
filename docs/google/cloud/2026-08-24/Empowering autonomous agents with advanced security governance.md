# Empowering autonomous agents with advanced security governance

- **來源**: Google Cloud Blog
- **發布日期**: 2026-08-25
- **原文連結**: https://cloud.google.com/blog/topics/ai-infrastructure/state-of-ai-infrastructure-report-agent-governance-and-security/

## 核心主題
這篇文章探討了自主 AI 代理（AI agents）在企業中的應用所帶來的安全治理挑戰，並提出以治理驅動創新、採用全棧雲端平台和強化鏈式思考安全的解決方案。

## 關鍵重點
- 79% 的科技主管將安全、治理或營運視為擴展推理能力的最大挑戰，35% 的高階 IT 決策者將多系統存取的安全不足視為主要問題。
- 自主工作流重新定義了企業風險，需要平衡給予代理所需存取權限與保障安全，同時管理動態權限。
- 安全重點從防止洩漏轉向驗證來源，以抵禦誤用，包括間接提示注入。
- 組織轉向整合的全棧雲端平台，69% 的執行長將其視為關鍵需求，80% 表示資料合規是主要決定因素。
- 採用 Secure AI Framework (SAIF) 和中央控制平面，透過預設安全設計、代理治理與監督、以及人類介入控制來管理風險。

## 結論
將堅固的治理直接整合到統一基礎設施中，組織可以自信地在最敏感、關鍵業務工作負載上部署代理，將安全作為創新發射台，安全地創新並比競爭對手更快地擴展。
