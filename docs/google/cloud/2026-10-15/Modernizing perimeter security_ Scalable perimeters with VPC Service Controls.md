# Modernizing perimeter security: Scalable perimeters with VPC Service Controls

- **來源**: Google Cloud Blog
- **發布日期**: 2026-10-16
- **原文連結**: https://cloud.google.com/blog/products/identity-security/introducing-new-scalable-perimeter-options-with-vpc-service-controls/

## 核心主題
Google Cloud 推出 VPC Service Controls (VPC-SC) 的新功能，使 perimeter 更安全、更易管理，特別適合自主代理 (agents) 的擴展。

## 關鍵重點
- 支援將 Google Cloud 資料夾 (folders) 加入 perimeter 成員資格，新工作負載自動繼承保護政策。
- 支援在入站和出站規則中指定資料夾和組織，簡化多專案環境的規則管理。
- 支援 Private Service Connect 終端點，允許使用私人路徑訪問 Google API。
- 提供 Guided Violation Remediation，自動生成修復建議，將違規解決時間從天數縮短至分鐘。
- 支援 Dry-run 模式，讓管理員在正式執行前評估 perimeter 的影響。

## 結論
這些更新使 VPC-SC 更容易部署和維護，無需額外費用，並為自主代理提供可擴展的 perimeter 保護。
