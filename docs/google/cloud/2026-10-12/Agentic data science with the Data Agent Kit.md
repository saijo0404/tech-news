# Agentic data science with the Data Agent Kit

- **來源**: Google Cloud Blog
- **發布日期**: 2026-10-13
- **原文連結**: https://cloud.google.com/blog/products/data-analytics/bringing-you-the-data-agent-kit/

## 核心主題
這篇文章介紹了如何使用 Data Agent Kit 在 IDE 中自動化數據科學工作流，從數據加載、清洗、模型訓練到自動化部署。

## 關鍵重點
- Data Agent Kit 提供 MCP 工具和技能，讓代理能與 Google Cloud 數據服務互動，包括 BigQuery、Spark Serverless、dbt 和 Airflow 等
- 支持在 IDE 中直接創建和運行 PySpark 筆記本、dbt 項目和 Airflow 管道，無需離開編輯器
- 完整自動化數據科學工作流：從原始數據加載到模型訓練、評分和自動化部署，例如 fraud detection 案例
- 支持多種 Google Cloud 服務：BigQuery、Spark Serverless、dbt、Airflow、Spanner 等，可構建端到端的工作流

## 結論
Data Agent Kit 讓數據科學家能在 IDE 中輕鬆構建和自動化複雜的數據工作流，大幅提高生產效率，特別適合需要處理大量數據和複雜流程的場景。
