# Introducing the Developer Device Platform for agentic mobile app development

- **來源**: Google Cloud Blog
- **發布日期**: 2026-08-11
- **原文連結**: https://cloud.google.com/blog/topics/developers-practitioners/announcing-developer-device-platform-on-google-cloud/

## 核心主題
Google Cloud 正式推出 Developer Device Platform (DDP)，提供即時存取實體裝置與虛擬模擬器的雲端平台，支援 AI 程式碼代理開發。

## 關鍵重點
- **互動式除錯 (Device Streaming)**：開發者可透過 Device Streaming API 直接存取模擬器或實體裝置，進行即時互動測試與除錯。
- **平行測試 (Device Run)**：透過 Device Run API，可在 CI/CD 流程中平行測試數百台不同裝置，快速定位問題。
- **AI 程式碼代理整合**：支援 AI 代理執行多步驟使用者旅程、視覺化錯誤分析、硬體效能分析與硬體特定錯誤驗證。
- **智能測試優化**：提供智能分片測試與自動重試機制，加速測試流程並減少失敗重跑。

## 結論
自 8 月 12 日起進入公開預覽階段，採用按分鐘付費模式，協助開發者加速移動應用開發並充分利用獨特裝置功能與裝置端 AI 能力。
