# Unify public and private data with Data Commons on Spanner Graph

- **來源**: Google Cloud Blog
- **發布日期**: 2026-08-04
- **原文連結**: https://cloud.google.com/blog/products/databases/unify-public-and-private-data-with-data-commons-on-spanner-graph/

## 核心主題
這篇文章介紹了 Google 推出的 Data Commons on Spanner Graph，用於統一公共和私人數據，建立可擴展的知識圖譜。

## 關鍵重點
- Data Commons 整合了來自 100+ 權威機構（如聯合國、世界銀行、WHO 等）的 4000 億+ 數據點，使用標準化 Schema.org 定義
- 架構從 Bigtable 升級至 Spanner Graph，提供 SQL 介面、高可用性、水平擴展和多區域一致性，並支援 GQL 語法
- 支援 SDMX 3.0 標準，可與 Tableau、Flourish、Observable 等第三方工具整合，提供可用性 API 和數據 API 端點
- 企業可建立私人實例，將私人數據與 Google 公共知識圖譜結合，實現自然語言查詢並保持數據隔離
- 提供數據探索工具、MCP 工具和雲端 API，支援農業、人口統計、經濟、環境、健康等多領域分析

## 結論
Data Commons 透過 Spanner Graph 架構，讓企業能輕鬆整合公共參考數據與內部數據，建立更完整的知識圖譜，從而支持更明智的商業決策。
