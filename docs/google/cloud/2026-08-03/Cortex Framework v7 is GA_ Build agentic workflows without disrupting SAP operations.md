# Cortex Framework v7 is GA: Build agentic workflows without disrupting SAP operations

- **來源**: Google Cloud Blog
- **發布日期**: 2026-08-04
- **原文連結**: https://cloud.google.com/blog/products/sap-google-cloud/cortex-framework-v7-power-ai-agents-with-sap-data-faster/

## 核心主題
Google Cloud 正式推出 Cortex Framework v7，讓企業能將 SAP 數據轉化為 AI 準備好的數據產品，在不影響核心 ERP 系統運作的前提下，加速部署 AI 代理工作流。

## 關鍵重點
- 提供 SAP 專用數據產品加速器，將原始 SAP 表轉換為清晰的業務術語，並包含 AI 友好的元數據，使 AI 代理能更準確地理解業務上下文
- 支援模組化部署，使用 Dataform 提供版本控制的 SQL 和原生依賴管理，可同時處理 SAP ECC、S/4HANA 和 BDC 系統，並自動處理 Z 欄位等自訂欄位
- 採用 BigQuery 增量載入和無破壞式結構更新，只處理新增或修改的數據，顯著降低運算時間和運營成本
- 與 SAP Business Data Cloud Connect for BigQuery 整合，支援 SAP BDC 標準和自訂數據產品，可快速回答銷售管道健康度評估或採購效率分析等關鍵問題
- 包含代理數據產品構建器技能，讓數據工程師可用自然語言生成自訂數據產品，並自動處理構建和部署流程

## 結論
Cortex Framework v7 結合無伺服器執行、AI 準備好的語義和原生 SAP 整合，幫助企業將複雜企業數據轉為戰略資產，加速數據到 AI 的旅程，同時確保核心業務運作不受影響。
