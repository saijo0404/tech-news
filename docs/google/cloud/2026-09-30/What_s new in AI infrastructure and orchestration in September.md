# What's new in AI infrastructure and orchestration in September

- **來源**: Google Cloud Blog
- **發布日期**: 2026-10-01
- **原文連結**: https://cloud.google.com/blog/topics/ai-infrastructure/whats-new-in-ai-infrastructure-this-month/

## 核心主題
Google Cloud 在 2026 年 9 月推出多项 AI 基礎設施升級，聚焦可擴展性、效能優化與客戶案例，以應對代理fleet需求。

## 關鍵重點
- **GKE Agent Substrate**：支援百萬沙盒運行，密度提升 10 倍，內建 scale-to-zero 功能
- **GKE Pod snapshots**：減少 AI 推理啟動時間達 89%
- **GKE agentic migration**：協助從 AWS EKS 遷移至 GKE
- **儲存解決方案**：Filestore agent volumes、M4N 系列 VM、Z4D 裸金屬實例
- **GKE Agent Sandbox**：優化用於 RL 工作負載，一般可用性提升
- **客戶案例**：SeaVerse 降低基礎設施成本 60%、Replenit 降低 90% 管道成本、UiPath 獲得更可預測的成本
- **Gartner 和 Forrester 報告**：Google 獲得領導者地位，Forrester Wave 最高分

## 結論
Google Cloud 透過持續的基礎設施創新與客戶成功案例，在 AI 基礎設施領域鞏固其市場領導地位，並為客戶提供可擴展、高效能且具成本效益的解決方案。
