# Spanner Omni, now GA: A distributed, multi-model database that you can deploy anywhere

- **來源**: Google Cloud Blog
- **發布日期**: 2026-10-01
- **原文連結**: https://cloud.google.com/blog/products/databases/spanner-omni-deploy-anywhere-version-of-spanner-is-now-ga/

## 核心主題
Google 宣布 Spanner Omni 正式一般化可用，這是一個可部署在任何地方的分佈式多模型資料庫，提供與完全管理式 Spanner 相同的核心功能。

## 關鍵重點
- **跨環境部署自由**：Spanner Omni 可部署在本地數據中心、多雲環境或測試環境中，提供應用可移植性
- **多模型資料庫能力**：支援 SQL、圖形、鍵值、全文搜尋、向量搜尋和分析處理，並內建向量搜尋和 Spanner Graph 功能
- **企業級功能**：提供完整的企業功能，包括安全治理、資料保護、工作節點和企業級支援
- **授權模式**：提供開發者版（免費，90天預設授權）和商業版（付費，基於 vCPU 的年度訂閱）
- **AI 整合**：支援 Model Context Protocol (MCP)，可與代理系統直接整合，作為多雲部署的運營記憶層

## 結論
Spanner Omni 為企業提供了在本地數據中心或多雲環境中部署 Google 級一致性資料庫的能力，特別適合需要跨環境部署的 AI 應用，並已獲得超過 200 萬次下載。
