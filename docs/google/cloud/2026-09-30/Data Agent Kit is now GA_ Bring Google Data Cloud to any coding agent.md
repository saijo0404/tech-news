# Data Agent Kit is now GA: Bring Google Data Cloud to any coding agent

- **來源**: Google Cloud Blog Developers & Practitioners
- **發布日期**: 2026-10-01
- **原文連結**: https://cloud.google.com/blog/topics/developers-practitioners/data-agent-kit-is-now-ga-bring-google-data-cloud-to-any-coding-agent/

## 核心主題
Google 正式推出 Data Agent Kit，讓程式碼代理能直接與 Google Cloud 資料產品整合，無需手動設定。

## 關鍵重點
- **MCP 工具與技能**：提供超過 15 個 Google Data Cloud 服務的 MCP 工具，以及 Google 工程師撰寫的資料最佳實踐技能
- **支援的服務**：新增 BigQuery Graph、Bigtable、Managed Service for Apache Spark 等服務支援
- **多平台整合**：支援 VS Code、Antigravity IDE、Claude Code、Codex 等多個開發工具
- **自動化最佳實踐**：自動優化 BigQuery SQL、設計 Bigtable 行鍵、建立 dbt 管道等
- **企業級安全**：支援 IAM 權限控制、Model Armor 流量篩選、VPC 服務控制等企業功能

## 結論
Data Agent Kit 的推出大幅降低程式碼代理與 Google Cloud 資料服務的整合門檻，讓開發者能更輕鬆地利用 AI 代理進行資料分析、資料庫管理與資料管道自動化，同時保持企業級安全與最佳實踐。
