# Sovereign AI in Europe: New ways to control your AI stack

- **來源**: Google Cloud Blog
- **發布日期**: 2026-11-18
- **原文連結**: https://cloud.google.com/blog/products/identity-security/sovereign-ai-on-your-terms-made-with-europe/

## 核心主題
Google Cloud 在歐洲布魯塞爾的 Sovereign AI 峰會上宣布，將 Gemini 模型擴展至 Google Cloud Dedicated，並推出新的加密鍵控制與合規功能，幫助歐洲組織在保持 AI 能力同時實現數據主權控制。

## 關鍵重點
- **三種主權雲解決方案**：Google Cloud Data Boundary（公共雲上的數據邊界）、Google Cloud Dedicated（獨立合作伙伴運作的隔離基礎設施）、Google Distributed Cloud（客戶自營數據中心）。
- **Gemini 模型擴展**：Gemini 模型現在可於 Google Cloud Dedicated 使用，支持在歐盟境內進行機器學習處理。
- **加密鍵控制升級**：推出 Confidential External Key Management (cEKM)，允許客戶在外部持有加密根鍵，同時透過硬體驗證的保密計算環境降低延遲風險。
- **歐洲合作夥伴擴展**：與西班牙 Telefónica 建立新夥伴關係，並在法國、德國、意大利等地擴展主權雲服務。
- **合規框架**：推出瑞士數據邊界框架，並計劃為歐盟 DORA 法案提供金融服務組織的合規框架。
- **歐洲本地化運營**：與歐洲軟件供應商和起點公司合作，確保技術運營和價值創造留在歐洲。

## 結論
Google Cloud 透過提供可驗證的控制權、多樣的部署選擇以及與歐洲合作伙伴的深度合作，幫助歐洲組織在符合當地法規的前提下，安全地部署和使用 AI 技術，同時確保數據主權和價值留在歐洲。
