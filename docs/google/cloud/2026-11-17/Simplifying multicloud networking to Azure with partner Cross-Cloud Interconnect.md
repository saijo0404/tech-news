# Simplifying multicloud networking to Azure with partner Cross-Cloud Interconnect

- **來源**: Google Cloud Blog
- **發布日期**: 2026-11-18
- **原文連結**: https://cloud.google.com/blog/products/networking/cross-cloud-interconnect-for-microsoft-azure/

## 核心主題
Google Cloud 與 Microsoft 合作推出 Cross-Cloud Interconnect 服務，將多雲網路連接簡化至分鐘級別，無需管理實體基礎設施。

## 關鍵重點
- **分鐘級設定**: 透過 Google Cloud 控制台或 API 即可在分鐘內建立連接，無需訂購硬體或進行手動網路配置。
- **內建可靠性**: 連接跨物理隔離位置運行，提供冗餘性，Google Cloud 和 Azure 共同監控並處理維護與恢復。
- **私密與安全**: 流量不經過公共互聯網，自動在 Google Cloud 和 Azure 邊緣路由器之間加密，無需客戶端配置。
- **可預測的定價**: 按連接頻寬支付固定費用，使 Google Cloud 成本更容易規劃和管理。

## 結論
Cross-Cloud Interconnect 為企業提供了連接 Google Cloud 和 Azure 環境的私密、高頻寬連接，消除了傳統基礎設施複雜性，為跨不同雲環境的工作負載提供可靠、可擴展的基礎。此服務目前處於預覽階段，並將逐步擴展至更多區域。
