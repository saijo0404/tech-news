# Your chance to start building AI agents from the absolute basics

- **來源**: Google Cloud Blog Developers & Practitioners
- **發布日期**: 2026-08-27
- **原文連結**: https://cloud.google.com/blog/topics/developers-practitioners/your-chance-to-start-building-ai-agents-from-the-absolute-basics/

## 核心主題
Google 推出 Agent Valley 免費課程，讓初學者透過遊戲化方式學習建立 AI 代理系統。

## 關鍵重點
- Agent Valley 是 5 週免費實作課程，透過低多邊形虛擬世界遊戲化學習
- 由 Annie Wang 設計，適合零基礎者，無需機器學習背景
- 5 個模組化週期涵蓋控制、分解、協調、記憶與即時反應等核心能力
- 提供即時 Runtime 檢視器，可觀察 AI 思考過程與成本

## 結論
透過遊戲化實作學習，降低 AI 代理開發門檻，讓更多人能掌握 AI 系統開發。
