# How Uber improves network reliability while unblocking cloud migration

- **來源**: Google Cloud Blog
- **發布日期**: 2026-08-27
- **原文連結**: https://cloud.google.com/blog/products/networking/uber-de-risks-hybrid-ai-with-cloud-interconnect/

## 核心主題
Uber 透過 Google Cloud 的應用感知功能，在混合雲環境中實現關鍵流量優先級管理，從而提升網路可靠性並支持雲端遷移。

## 關鍵重點
- 應用感知功能透過 DSCP 標記和排程配置，將流量分類為六個類別，確保關鍵業務應用在網路擁塞時仍能優先運行
- 相比傳統解決方案，此功能提供更低的總擁有成本，無需盲目超額 provision 網路容量
- Uber 將此功能視為關鍵，成功支持了向 Google Cloud 遷移重要工作負載，並大幅降低營運成本

## 結論
Uber 的經驗證明，透過應用感知技術管理混合雲網路，不僅能確保業務連續性，還能為其他企業提供可複製的雲端遷移藍圖。
