# Bringing conversational analytics to Gemini with Agentic Data Cloud connectors

- **來源**: Google Cloud Blog
- **發布日期**: 2026-11-06
- **原文連結**: https://cloud.google.com/blog/products/data-analytics/query-enterprise-data-in-gemini-with-data-cloud-connectors/

## 核心主題
Google 推出 Data Cloud connectors，讓企業使用者能透過自然語言直接在 Gemini 中查詢企業數據，提供兩種主要方式：Conversational Analytics agents 和 Data Cloud connectors。

## 關鍵重點
- Data Cloud connectors 支援 BigQuery、Spanner、AlloyDB、Cloud SQL 和 Looker 等數據源，讓使用者無需掌握 SQL 即可查詢數據
- 系統透過 Knowledge Catalog 進行語意發現和上下文映射，自動解析自然語言問題並執行權限範圍內的查詢
- 支援跨雲環境查詢，包括 BigQuery 和 AWS/Azure 的數據湖格式（Apache Iceberg、Delta Lake、Parquet），實現無邊界數據分析
- 提供兩種使用方式：Data Cloud connectors 適合探索性分析，Conversational Analytics agents 適合高度治理的多步驟戰略分析
- 內建行級和欄級權限控制，確保符合合規要求，使用者只能查詢其帳號有權限的數據

## 結論
Data Cloud connectors 為企業提供了更便捷、安全且治理完善的自然語言數據查詢解決方案，無需等待分析師排程，讓數據分析直接融入日常工作流程。
