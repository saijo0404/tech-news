# What's new in Managed Service for Apache Spark 4.0

- **來源**: Google Cloud Blog Data Analytics
- **發布日期**: 2026-11-21
- **原文連結**: https://cloud.google.com/blog/products/data-analytics/whats-new-in-managed-service-for-apache-spark-4-0/

## 核心主題
Google Cloud 正式推出 Managed Service for Apache Spark 4.0，帶來新一代運時基礎設施，整合 Apache Spark 4.2、AI 代理式診斷、跨 IDE 開發工具及 Lakehouse 整合能力。

## 關鍵重點
- **新 4.0 運時**：基於 Apache Spark 4.2，支援 Java 25、Python 3.13 與 Apache Iceberg 1.12，適用於 serverless 與 managed cluster，統一工作負載管理
- **代碼優先控制台**：重新設計的 Google Cloud 控制台提供一鍵 VS Code 編寫、統一工作負載視圖與 AI 代理式故障診斷，減少基礎設施配置時間
- **Data Agent Kit**：支援從 VS Code、Claude Code、Antigravity 等 IDE 直接建置 Apache Spark 工作負載，透過 MCP 工具鏈整合 AI 代理，無需離開編輯器
- **性能加速**：更快的啟動速度（Premium tier 預設 Gen4 硬體），Lightning Engine 加速價格效能達 3.25 倍，性能提升達 4.9 倍，Iceberg 掃描加速 50%
- **Lakehouse 整合**：Apache Iceberg 直接內建於運時，工作負載自動附著至 Lakehouse 運時目錄，消除 legacy Hive Metastore 依賴，與 BigQuery 共享資料表

## 結論
Managed Service for Apache Spark 4.0 透過現代化運時、AI 增強的開發體驗與 Lakehouse 生態系整合，協助企業從反應式分析轉向主動式行動系統，並與 Agentic Data Cloud 緊密合作，成為 AI 時代的戰略業務加速器。
