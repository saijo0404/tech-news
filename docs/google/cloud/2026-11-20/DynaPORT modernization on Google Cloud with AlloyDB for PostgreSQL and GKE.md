# DynaPORT modernizes with AlloyDB

- **來源**: Google Cloud Blog
- **發布日期**: 2026-11-21
- **原文連結**: https://cloud.google.com/blog/products/databases/dynaport-modernizes-with-alloydb/

## 核心主題
TCS 與印度最大港口開發商合作，將 DynaPORT 終端操作系統從傳統本地化架構遷移至 Google Cloud 的現代化雲端架構，採用 AlloyDB for PostgreSQL 與 GKE 實現高效能與高可用性。

## 關鍵重點
- **技術債清理**: 將 120 萬行 Oracle PL/SQL 程式碼遷移至 PostgreSQL PL/pgSQL，保留核心業務邏輯同時現代化架構。
- **架構轉型**: 從單體 JEE 應用伺服器遷移至容器化微服務架構，部署於 Google Kubernetes Engine (GKE)。
- **效能提升**: 交易處理吞吐量提升 2 倍，查詢響應時間降至毫秒級，並具備次秒級自動故障轉移能力。
- **成本優化**: 資料庫總擁有成本 (TCO) 降低約 50%，並獲得開源相容性，消除企業授權費用。

## 結論
DynaPORT 的成功現代化證明：保留經過驗證的業務邏輯、選擇適合雲端環境的資料庫引擎、以及將應用工作負載容器化，是企業雲端轉型三大關鍵原則。此案例為其他企業提供了低風險、高績效的遷移路徑參考。
